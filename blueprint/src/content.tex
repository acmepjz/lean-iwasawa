\subsection{Iwasawa's theorem on growth of class groups}

Iwasawa theory is a branch of modern number theory,
initiated by Kenkichi Iwasawa in 1959 \cite{Iwa59},
which studies arithmetic objects
over infinite towers of number fields.
It was motivated by the study of
class groups of cyclotomic fields, which are very important in number theory.

\begin{thm}[Fermat's Last Theorem, regular prime case]
\label{flt-regular}
If a prime $p\geq 3$ does not divide the class number of $\BQ(\mu_p)$, then
$x^p+y^p=z^p$, $xyz\neq 0$ does not have integral solution.
\end{thm}

The class group of $\BQ(\mu_p)$ is studied via
infinite tower of cyclotomic fields
$$
\BQ(\mu_p)\subset\BQ(\mu_{p^2})\subset\BQ(\mu_{p^3})\subset\cdots
\subset\BQ(\mu_{p^\infty}),
$$
which is an example of a $\BZ_p$-extension.

\begin{definition}
\label{Zp-ext-def}
\lean{MvZpExtension,MvZpExtension.Kn}
\leanok
Let $K$ be a field, $p$ be a prime.

{\rm(i)} An extension $K_\infty/K$ is called a $\BZ_p$-extension,
if it is Galois with $\Gamma=\Gal(K_\infty/K)\cong\BZ_p$
as topological groups.

{\rm(ii)} If $K_\infty/K$ is a $\BZ_p$-extension, then for any
$n\geq 0$, define $K_n:=K_\infty^{\Gamma^{p^n}}$.
\end{definition}

The $K_n$ form an infinite tower
$$
K=K_0\subset K_1\subset K_2\subset\cdots\subset K_\infty.
$$
Iwasawa in 1959 \cite{Iwa59}
studied the growth of class groups of $K_n$ in a $\BZ_p$-extension.

\begin{thm}[Iwasawa's theorem, \cite{Was97}, Theorem 13.13,
\cite{Iwa59}, Theorem 11]
\label{clgp-growth}
\uses{Zp-ext-def,Xn-isom-qout,coinvariant-growth-2,Xn-isom-An,
finite-index-submodule-growth,hilbert-p-class-field,exists-totally-ramified,
iwasawa-mod-invariants,Zp-ext-Ln,Zp-ext-An}
\lean{MvZpExtension.multiplicity_classNumber_Kn_eq₁,
MvZpExtension.multiplicity_classNumber_Kn_eq₁_of_cft}
\leanok
Let $K$ be a number field, $p$ be a prime,
$K_\infty/K$ be a $\BZ_p$-extension.
Then there exist integers $\lambda\geq 0,\mu\geq 0,\nu$
such that for all sufficiently large $n$,
$\ord_p(\#\Cl(K_n))=\mu p^n+\lambda n+\nu$.
\end{thm}

\begin{proof}
\leanok
For each $n$ let $L_n$ be the maximal unramified abelian $p$-extension of $K_n$
(i.e.~the $p$-Hilbert class field of $K_n$, Definition \ref{Zp-ext-Ln}), let
$X_n:=\Gal(L_n/K_n)$ and $A_n:=\Cl(K_n)(p)$ (Definition \ref{Zp-ext-An}).
Let $L_\infty=\bigcup_nL_n$ and $X_\infty=\Gal(L_\infty/K_\infty)$, a
$\Lambda$-module, where $\Lambda:=\BZ_p[[\Gamma]]$.

\emph{Step 1 (class field theory).}
For every $n$,
$$\ord_p\#\Cl(K_n)=\ord_p\#A_n=\ord_p\#X_n .$$
The first equality holds because $A_n$ is the $p$-primary part of the finite
abelian group $\Cl(K_n)$, and the second is
Proposition \ref{Xn-isom-An} (i.e.~Corollary \ref{hilbert-p-class-field}
applied to the number field $K_n$).
In particular each $X_n$ is finite.

\emph{Step 2 (structure of $X_\infty$).}
Choose $e\geq 0$ such that $K_\infty/K_e$ is totally ramified
(Lemma \ref{exists-totally-ramified}).
By Theorem \ref{Xn-isom-qout}, $X_\infty$ is a finitely generated torsion
$\Lambda$-module and there is a $\Lambda$-submodule $Y\subset X_\infty$ of
finite index with
$$X_n\cong X_\infty/\nu_{n,e}Y\qquad\text{for all }n\geq e .$$

\emph{Step 3 (growth).}
By Step 1 the modules $X_\infty/\nu_{n,e}Y\cong X_n$ are finite for all
$n\geq e$, so Lemma \ref{finite-index-submodule-growth} applies to the pair
$Y\subset X_\infty$ and yields an integer $\nu$ with
$$\ord_p\#\big(X_\infty/\nu_{n,e}Y\big)
=\mu(X_\infty)p^n+\lambda(X_\infty)n+\nu$$
for all sufficiently large $n$.
Put $\mu:=\mu(X_\infty)\geq 0$ and $\lambda:=\lambda(X_\infty)\geq 0$; these
are non-negative integers by Definition \ref{iwasawa-mod-invariants}.
Combining with Steps 1 and 2,
$$\ord_p\#\Cl(K_n)=\ord_p\#X_n=\mu p^n+\lambda n+\nu$$
for all sufficiently large $n$.

Note that it is \emph{not} Proposition \ref{coinvariant-growth-2} itself that
is applied to $X_\infty$: the quotients occurring here are
$X_\infty/\nu_{n,e}Y$ with $Y$ a proper submodule in general, which is why
Lemma \ref{finite-index-submodule-growth} (which reduces to
Proposition \ref{coinvariant-growth-2} applied to $Y$, and compares the
invariants of $Y$ and of $X_\infty$) is needed.
\end{proof}

\begin{remark}
The {\Lean} proof does not construct the isomorphism $X_n\cong
X_\infty/\nu_{n,e}Y$ of Theorem \ref{Xn-isom-qout}. It works instead with
$Y_n:=\Gal(L_\infty/K_\infty L_n)\subset X_\infty$, for which
$X_\infty/Y_n\cong\Gal(K_\infty L_n/K_\infty)$. It proves that there are
$e_1\geq 0$ and a $\Lambda$-submodule $Y$ of $X_\infty$ with $Y_n=\nu_{n,e_1}Y$
for all $n\geq e_1$. It also proves that there is $e_2\geq 0$ with
$\#\Gal(K_\infty L_n/K_\infty)=[L_n:K_n]=p^{\ord_p(h_{K_n})}$ for all $n\geq
e_2$, because $L_n$ and $K_\infty$ are linearly disjoint over $K_n$ as soon as
$K_\infty/K_n$ is totally ramified at some place. It then applies Lemma
\ref{finite-index-submodule-growth} (in the form for a module already known to be torsion) for
$n\geq\max(e_1,e_2)$. Class field theory
enters only through the Artin map of Theorem \ref{artin-map}, used for
$[L_n:K_n]=p^{\ord_p(h_{K_n})}$ and the finiteness of $L_n/K_n$, and through the
existence of a ramified place (Lemma \ref{exists-totally-ramified}).
These class field theory inputs are isolated in Lean as two statements, the
upper bound $[E:F]\leq h_F$ for finite abelian everywhere unramified $E/F$ and
the existence of the Hilbert class field of degree $h_F$
(\texttt{NumberField.HilbertClassFieldUpperBound},
\texttt{NumberField.HilbertClassFieldExistence}), from which the theorem is
proved without any \texttt{sorry}
(\texttt{MvZpExtension.multiplicity\_classNumber\_Kn\_eq\textsubscript{1}\_of\_hcf}).
The separate leaf library \texttt{IwasawalibCFT} proves both statements from the
external \texttt{sorry}-free class field theory library
\texttt{n-yamaguchi-0729/ClassFieldTheory} and obtains the theorem with no
\texttt{sorry} at all.
\end{remark}

The first goal of our project is formalize the proof of the above
Iwasawa's theorem on growth of class groups in a $\BZ_p$-extension tower
in {\Lean}.

\section{Preliminaries in commutative algebra}

\subsection{Noetherian}

\begin{prop}
\label{noeth-ring-filtration}
\lean{IsNoetherianRing.exists_relSeries_isQuotientEquivQuotientPrime}
\leanok
Let $A$ be a Noetherian ring and $M$ be a finitely generated $A$-module.
Then there exists a chain of submodules of $M$
\[0 = M_0 \subset M_1 \subset \cdots \subset M_n = M\]
such that for each $1\leq i\leq n$, $M_i/M_{i-1} \cong A/\fp_i$ for some prime ideal $\fp_i\in\Spec(A)$.
\end{prop}

\begin{proof}
\leanok
When $M=0$ we take $n=0$ and there is nothing to prove.
When $M\neq 0$ we have $\Ass(M)\neq\varnothing$
and we can take $\fp_1$ be any element in $\Ass(M)$
and we obtain $M_1:=A/\fp_1\hookrightarrow M$.
If $M_1\neq M$, do the same for $M/M_1$ to get $M_2/M_1\cong A/\fp_2\hookrightarrow M/M_1$.
Since $M$ is a Noetherian $A$-module,
the chain $M_1\subset M_2\subset\cdots$ must stop after a finite number of steps.
\end{proof}

\begin{thm}[Krull's Hauptidealsatz]
\leanok
\label{krull-principal-ideal-thm}
\lean{Ideal.height_le_spanRank_toENat_of_mem_minimalPrimes,
Ideal.height_le_iff_exists_minimalPrimes}
Let $A$ be a Noetherian ring.
If $\fa=(a_1,\cdots,a_n)$ is an ideal of $A$ generated by $n$ elements,
and $\fp$ is a minimal prime over-ideal of $\fa$, then $\height(\fp)\leq n$.

(Mathlib: \docs{Ideal.height_le_spanRank_toENat_of_mem_minimalPrimes}.)

Conversely, if $\fp$ is a prime ideal of $A$ of height $\leq n$,
then there exists an ideal $\fa$ of $A$ generated by $n$ elements, such that
$\overline\fp$ is a minimal prime in $A/\fa$.

(Mathlib: \docs{Ideal.exists_spanRank_eq_and_height_eq},
\docs{Ideal.height_le_iff_exists_minimalPrimes}.)
\end{thm}

\begin{proof}
\leanok
If $\fp$ is a minimal prime over-ideal of $\fa$, then $\fa A_\fp\subset\fp A_\fp$,
and $\fp(A_\fp/\fa A_\fp)$, which is the only maximal ideal of
$A_\fp/\fa A_\fp$, is also a minimal prime ideal.
Therefore $A_\fp/\fa A_\fp$ is Artinian, and so
$\fa A_\fp$ is an open ideal. It follows that $\height(\fp)=\dim(A_\fp)\leq n$.

Conversely, if $\fp$ is a prime ideal of height $\leq n$,
then $\dim(A_\fp)\leq n$, so there exists an \emph{ideal of definition}
$IA_\fp$ of $A_\fp$
(i.e.~an open ideal with respect to $\fp A_\fp$-adic topology),
generated by $n$ elements.
Clearing their denominators we may assume that the generators take the form
$\frac{x_1}s,\cdots,\frac{x_n}s$ for some $x_1,\cdots,x_n\in I$
and $s\in A\setminus\fp$.
Since $\fp^NA_\fp\subset IA_\fp\subset\fp A_\fp$ for some integer $N\geq 1$,
we obtain $\fp^N\subset I\subset\fp$, and
$IA_\fp=(x_1,\cdots,x_n)A_\fp$
(hence we may replace $I$ by $(x_1,\cdots,x_n)$), and that $\fp$ is a minimal prime over-ideal of $I$
(since if $I\subset\fp'\subset\fp$ for some prime ideal $\fp'$,
then $\fp^N\subset\fp'$, hence $\fp\subset\fp'$, so $\fp=\fp'$).
\end{proof}

\begin{thm}
\label{UFD-iff-ht-1-principal}
\uses{krull-principal-ideal-thm}
\lean{UniqueFactorizationMonoid.iff_forall_isPrincipal_of_height_eq_one}
\leanok
Let $A$ be a Noetherian domain. Then $A$ is a UFD if and only if every prime ideal of height $1$ is principal
(recall that a prime ideal $\fp$ is of height $1$ if $\fp \neq 0$ and there is no prime ideal lies in between $0$ and $\fp$).

(We only need ``$\Rightarrow$'' in our project.)
\end{thm}

\begin{proof}
\leanok
``$\Rightarrow$'':
Let $\fp$ be a prime ideal of height $1$,
and let $a\in\fp$ be a non-zero element.
Factor $a$ into a product of irreducible elements
(= prime elements) $a=p_1\cdots p_r$.
Then by $a\in\fp$ we obtain $p_i\in\fp$ for some $i$,
since $(p_i)\neq 0$ is a prime ideal contained in $\fp$, we have $\fp=(p_i)$.

``$\Leftarrow$'':
It suffices to show that every irreducible element is prime.
Let $p\in A$ be irreducible, and $\fp$ be a prime ideal of $A$ minimal containing $p$.
Then $\fp$ is of height $1$ by Krull's Hauptidealsatz
(Theorem \ref{krull-principal-ideal-thm}),
so $\fp=(\pi)$ is principal.
Since $p\in\fp=(\pi)$, $\pi\mid p$, and since $p$ is irreducible,
$p=u\pi$ for some unit $u$, therefore $p$ is prime (which generates $\fp$).
\end{proof}

\begin{lem}[Nagata's lemma]
\label{nagata-lemma}
\uses{UFD-iff-ht-1-principal}
\lean{UniqueFactorizationMonoid.iff_localizationAway_of_prime}
\leanok
Let $A$ be a Noetherian domain and let $x\in A$ be a prime element
(i.e.~$x\neq 0$ and $(x)$ is a prime ideal).
If the localization $A[1/x]$ is a UFD, then $A$ is a UFD.
\end{lem}

\begin{proof}
\leanok
By Theorem \ref{UFD-iff-ht-1-principal} it suffices to show that every height one
prime $\fp$ of $A$ is principal.

If $x\in\fp$, then $0\neq(x)\subset\fp$ with $(x)$ prime, so $\fp=(x)$ because
$\height(\fp)=1$.

Assume now $x\notin\fp$, and put $S:=\{x^k\mid k\geq 0\}$ and $B:=S^{-1}A=A[1/x]$.
Prime ideals of $B$ correspond to prime ideals of $A$ disjoint from $S$, so
$S^{-1}\fp$ is a height one prime of $B$; since $B$ is a UFD, it is principal.
A generator may be written as $a/x^k$ with $a\in\fp$, and $x$ is a unit of $B$,
so $S^{-1}\fp=aB$ with $a\in\fp$.
By Krull's intersection theorem $\bigcap_{k\geq 0}(x^k)=0$ in the Noetherian
domain $A$, so only finitely many powers of $x$ divide $a$; moreover, if $a=xa'$
then $a'\in\fp$ (because $xa'\in\fp$, $x\notin\fp$ and $\fp$ is prime) and
$a'B=aB$. Replacing $a$ by $a'$ finitely many times, we may assume $x\nmid a$.

We claim $\fp=(a)$; the inclusion $(a)\subset\fp$ is clear.
Let $c\in\fp$. Then $c\in S^{-1}\fp=aB$, so $x^kc=ad$ for some $d\in A$ and
$k\geq 0$; choose such an expression with $k$ minimal.
If $k\geq 1$, then $x\mid ad$; since $x$ is prime and $x\nmid a$, we get $x\mid d$
and we may cancel one factor $x$, contradicting the minimality of $k$.
Hence $k=0$ and $c=ad\in(a)$.
\end{proof}

\begin{thm}[Auslander--Buchsbaum]
\label{regular-local-ring-is-UFD}
\uses{nagata-lemma,UFD-iff-ht-1-principal,krull-principal-ideal-thm,noeth-local-domain-is-icd-iff}
A regular local ring is a UFD.

(We try to avoid this result since regular local ring is still WIP in mathlib.)
\end{thm}

\begin{proof}
We follow Kaplansky's proof.
Two standard facts about regular local rings are used without proof here
(see Matsumura, \emph{Commutative ring theory}, Chapters 6 and 7, or
Eisenbud, \emph{Commutative algebra}, Chapters 18--19):
\begin{itemize}
\item[(R1)]
a regular local ring is an integral domain, and every localization $A_\fp$ of a
regular local ring $A$ at a prime ideal $\fp$ is again a regular local ring
(the latter is a consequence of Serre's homological characterization: $A$ is
regular if and only if $A$ has finite global dimension);
\item[(R2)]
if $A$ is regular local of dimension $d$, then every finitely generated
$A$-module admits a resolution of length $\leq d$ by finitely generated free
$A$-modules.
\end{itemize}

We induct on $d:=\dim(A)$; let $\fm$ be the maximal ideal of $A$ and $k=A/\fm$.
If $d=0$ then $\fm=\fm^2$ hence $\fm=0$ and $A$ is a field.
If $d=1$ then $\fm$ is generated by one element and $A$ is a Noetherian local
domain of dimension one whose maximal ideal is principal, hence a discrete
valuation ring (Proposition \ref{noeth-local-domain-is-icd-iff}), hence a PID and
a UFD.

Let $d\geq 2$ and choose $x\in\fm\setminus\fm^2$.
Then $\dim_k\fm/(\fm^2+(x))=d-1$, so the maximal ideal of $A/(x)$ is generated by
$d-1$ elements and $\dim(A/(x))\leq d-1$ by Krull's Hauptidealsatz
(Theorem \ref{krull-principal-ideal-thm}).
Conversely, put $e:=\dim(A/(x))$; by the second part of
Theorem \ref{krull-principal-ideal-thm} applied to $A/(x)$, the maximal ideal of
$A/(x)$ is a minimal prime over-ideal of an ideal generated by $e$ elements;
lifting those $e$ elements to $A$ and adjoining $x$ we see that $\fm$ is a minimal
prime over-ideal of an ideal generated by $e+1$ elements, so $d\leq e+1$ by the
first part of Theorem \ref{krull-principal-ideal-thm}.
Hence $\dim(A/(x))=d-1$ and $A/(x)$ is a regular local ring.
By (R1) it is a domain, so $(x)$ is prime and $x$ is a prime element of $A$.

By Nagata's lemma (Lemma \ref{nagata-lemma}) it suffices to prove that
$B:=A[1/x]$ is a UFD, and by Theorem \ref{UFD-iff-ht-1-principal} it suffices to
prove that every height one prime $\fq$ of $B$ is principal.

\emph{Step 1: $\fq$ is a projective $B$-module of rank one.}
Let $\fn$ be a maximal ideal of $B$ and $\fp:=\fn\cap A$, so that
$B_\fn=A_\fp$. Since $x\notin\fp$ while $x\in\fm$, we have $\fp\neq\fm$, hence
$\height(\fp)\leq d-1$ and $A_\fp$ is a regular local ring of dimension $<d$ by
(R1); by the induction hypothesis $A_\fp$ is a UFD.
Now $\fq B_\fn$ is either the unit ideal, or a height one prime of $B_\fn$, which
is principal by Theorem \ref{UFD-iff-ht-1-principal};
in both cases $\fq B_\fn$ is a nonzero principal ideal of the domain $B_\fn$, so
$\fq_\fn\cong B_\fn$ as a $B_\fn$-module.
Thus $\fq$ is a finitely generated $B$-module which is free of rank one at every
maximal ideal, hence projective of rank one.

\emph{Step 2: $\fq$ admits a finite free resolution over $B$.}
Let $M:=\fq\cap A$, a finitely generated $A$-module with $S^{-1}M=\fq$ where
$S=\{x^k\}$. By (R2), $M$ has a resolution
$0\to F_r\to\cdots\to F_0\to M\to 0$ by finitely generated free $A$-modules.
Localizing at $S$ (which is exact) gives a resolution of $\fq$ by finitely
generated free $B$-modules.

\emph{Step 3: conclusion.}
Since $\fq$ is projective, the resolution
$0\to G_r\to\cdots\to G_0\to\fq\to 0$ splits into split short exact sequences
(each syzygy is projective, by descending induction), so
$\fq\oplus G_1\oplus G_3\oplus\cdots\cong G_0\oplus G_2\oplus\cdots$;
comparing ranks, $\fq\oplus B^m\cong B^{m+1}$ for some $m\geq 0$.
Since $\fq$ is projective of rank one we have $\bigwedge^i\fq=0$ for $i\geq 2$
(this can be checked after localizing at each maximal ideal), so
$$B\cong\textstyle\bigwedge^{m+1}(B^{m+1})\cong\bigwedge^{m+1}(\fq\oplus B^m)
\cong\bigwedge^1\fq\otimes_B\bigwedge^m(B^m)\cong\fq .$$
Hence $\fq$ is a free $B$-module of rank one, i.e.~a principal ideal.
Therefore $B$ is a UFD and, by Lemma \ref{nagata-lemma}, so is $A$.
\end{proof}

\begin{lem}[Nakayama lemma, pro-$p$ version]\label{p:nak}
\lean{IwasawaAlgebra.span_eq_top_of_sup_X_smul_top_le,
IwasawaAlgebra.eq_top_span_of_sup_smul_top_le}
\leanok
Suppose $\Lambda\cong\BZ_p[[T]]$ and $X$ is a \emph{compact} $\Lambda$-module,
i.e.~a profinite abelian group with a continuous $\Lambda$-action
$\Lambda\times X\to X$ (equivalently, by Proposition
\ref{profinite-Gamma-module-is-Lambda-module}, a pro-$p$ abelian group with a
continuous $\Gamma$-action).
Let $x_1,\cdots,x_t\in X$ be such that their images in $X/TX$
generate $X/TX$ as a $\Lambda/(T)$-module.
Then $x_1,\cdots,x_t$ generate $X$ as a $\Lambda$-module.
\end{lem}

Similar result holds when $T$ is replaced
by any element of the maximal ideal $\fm=(p,T)$.
Also for several variable formal power series.

\begin{proof}
\leanok
Let $Y:=\Lambda x_1+\cdots+\Lambda x_t$ be the $\Lambda$-submodule
of $X$ generated by $x_1,\cdots,x_t$.
It is the image of the compact set $\Lambda^t$ under the continuous map
$(a_i)\mapsto\sum_ia_ix_i$, hence compact, hence closed in the Hausdorff space
$X$.
Since the images of the $x_i$ generate $X/TX$ we have $Y+TX=X$, so the compact
$\Lambda$-module $Z:=X/Y$ satisfies $TZ=Z$ (the image of $TX$ in $Z$ is $TZ$,
and it is all of $Z$).
We claim $Z=0$, which gives $Y=X$ as asserted.

Let $V\subset Z$ be any open $\Lambda$-submodule; such $V$ form a basis of
neighbourhoods of $0$, and $Z=\varprojlim_VZ/V$
(Lemma \ref{profinite-module-cofinal-submodules}).
The quotient $M:=Z/V$ is a \emph{finite} $\Lambda$-module, and for such a
module $\fm^kM=0$ for some $k\geq 1$: indeed $\Lambda/\Ann_\Lambda(M)$ embeds
into $\prod_{x\in M}M$ by $a\mapsto(ax)_x$, hence is a finite ring; it is local,
being a quotient of the local ring $\Lambda$, and the maximal ideal $\fn$ of a
finite (hence Artinian) local ring is nilpotent: the chain
$\fn\supset\fn^2\supset\cdots$ stabilizes, say $\fn^k=\fn^{k+1}=\fn\cdot\fn^k$,
and $\fn^k$ is a finitely generated module, so $\fn^k=0$ by Nakayama's lemma.
Therefore $\fm^k\subset\Ann_\Lambda(M)$, i.e.~$\fm^kM=0$.
From $TZ=Z$ we get $T^k(Z/V)=Z/V$, while
$T^k(Z/V)\subset\fm^k(Z/V)=0$ because $T\in\fm$.
Hence $Z/V=0$ for every such $V$, and therefore $Z=\varprojlim_VZ/V=0$.
\end{proof}

\begin{lem}
\label{profinite-module-cofinal-submodules}
\lean{IwasawaAlgebra.exists_isOpen_submodule_subset_of_mem_nhds,
AddSubgroup.isOpen_moduleCore}
Let $R$ be a profinite ring and $Z$ a profinite $R$-module (a profinite abelian
group with continuous $R$-action).
Then the open $R$-submodules of $Z$ form a basis of neighbourhoods of $0$, and
the natural map $Z\to\varprojlim_VZ/V$, the limit being over the open
$R$-submodules $V$, is an isomorphism of topological $R$-modules.
\end{lem}

\begin{proof}
Let $U\subset Z$ be an open subgroup; since open subgroups form a basis of
neighbourhoods of $0$ in a profinite group, it suffices to find an open
$R$-submodule $V\subset U$.
Put
$$V:=\{z\in Z\mid Rz\subset U\}=\bigcap_{r\in R}r^{-1}(U).$$
It is a subgroup of $Z$, it is contained in $U$ because $1\in R$, and it is an
$R$-submodule: if $Rz\subset U$ and $s\in R$, then $R(sz)=(Rs)z\subset Rz\subset
U$.
It is open by the tube lemma: the action map
$$f:R\times Z\to Z/U,\qquad (r,z)\mapsto rz+U$$
is continuous with discrete target, so $f^{-1}(0)$ is open and contains the
compact slice $R\times\{0\}$; hence there is an open neighbourhood $N$ of $0$ in
$Z$ with $R\times N\subset f^{-1}(0)$, i.e.~$N\subset V$.
A subgroup containing a neighbourhood of $0$ is open, so $V$ is open.
Hence the open $R$-submodules are cofinal among the open subgroups, and the
second assertion is the standard identification of a profinite group with the
inverse limit of its quotients by a cofinal system of open subgroups.
\end{proof}

\begin{prop}
\label{profinite-Gamma-module-is-Lambda-module}
Let $\Gamma\cong\BZ_p$ with topological generator $\gamma$ and
$\Gamma_n=\Gamma/\Gamma^{p^n}$, and let $\Lambda=\BZ_p[[\Gamma]]
=\varprojlim_n\BZ_p[\Gamma_n]$.
Let $X$ be a pro-$p$ abelian group (i.e.~an inverse limit of finite abelian
$p$-groups) equipped with a continuous $\Gamma$-action by group automorphisms.
Then the $\Gamma$-action extends uniquely to a continuous $\Lambda$-module
structure on $X$, and $T=\gamma-1$ acts as $x\mapsto(\gamma\bullet x)-x$.
\end{prop}

\begin{proof}
\emph{Step 1: $\Gamma$-stable open subgroups are cofinal.}
Let $U\subset X$ be an open subgroup and put
$V:=\bigcap_{\sigma\in\Gamma}\sigma^{-1}(U)$, a $\Gamma$-stable subgroup
contained in $U$.
As in the proof of Lemma \ref{profinite-module-cofinal-submodules}, the map
$\Gamma\times X\to X/U$, $(\sigma,x)\mapsto\sigma\bullet x+U$, is continuous
with discrete target and $\Gamma$ is compact, so by the tube lemma $V$ contains
an open neighbourhood of $0$ and hence is open.
Thus $X=\varprojlim_UX/U$ with $U$ running over the $\Gamma$-stable open
subgroups.
Each quotient $X/U$ is a finite abelian $p$-group, hence carries a unique
$\BZ_p$-module structure (it is killed by some $p^k$), and every subgroup of it
is automatically a $\BZ_p$-submodule.
\emph{Step 2: each $X/U$ is a $\Lambda$-module.}
The induced action of $\Gamma$ on the finite discrete group $X/U$ is
continuous, so the stabilizer of each of its finitely many elements is an open
subgroup of $\Gamma$; the intersection of these is open, hence contains
$\Gamma^{p^n}$ for some $n$, i.e.~$\Gamma$ acts on $X/U$ through
$\Gamma_n$.
Therefore $X/U$ is a $\BZ_p[\Gamma_n]$-module, hence a $\Lambda$-module through
the projection $\Lambda\to\BZ_p[\Gamma_n]$.

\emph{Step 3: passage to the limit.}
These structures are compatible with the transition maps, so
$X=\varprojlim_UX/U$ is a $\Lambda$-module, and the action
$\Lambda\times X\to X$ is continuous, being an inverse limit of the continuous
(locally constant) actions $\BZ_p[\Gamma_n]\times X/U\to X/U$.
Uniqueness holds because $\BZ_p[\Gamma]$ is dense in $\Lambda$ and the action
is continuous.
Finally $T=\gamma-1$ acts as stated by definition.
\end{proof}

\begin{definition}

if it satisfies the following properties:

\begin{lem}
\label{integrally-closed-is-local-prop}
\lean{IsIntegrallyClosed.of_localization}
\leanok
Let $A$ be a domain, $S$ be a subset of $\Spec(A)$
such that $A_\fp$ is integrally closed for all $\fp\in S$
and $\bigcap_{\fp\in S}A_\fp=A$ inside $\Frac(A)$.
Then $A$ itself is integrally closed.

(Mathlib: \docs{IsIntegrallyClosed.of_localization}.)
\end{lem}

\begin{proof}
\leanok
Suppose $x\in\Frac(A)$ is integral over $A$. Then it's also integral over $A_\fp$
for all $\fp\in\Spec(A)$. Hence $x\in A_\fp$ for all $\fp\in S$.
So $x\in\bigcap_{\fp\in S}A_\fp=A$.
\end{proof}

\begin{lem}
\label{ass-prime-of-quotient-by-element}
\uses{krull-principal-ideal-thm}
Let $A$ be a Noetherian integrally closed domain, let $b\in A$ be a nonzero
non-unit, and let $\fp\in\Ass(A/bA)$.
Then $\fp A_\fp$ is a nonzero principal ideal of $A_\fp$, and $\height(\fp)=1$.
\end{lem}

\begin{proof}
Since $\fp\in\Ass_A(A/bA)$, we have $\fp A_\fp\in\Ass_{A_\fp}(A_\fp/bA_\fp)$,
so there exists $u\in A_\fp$ with $u\notin bA_\fp$ and
$$\fp A_\fp=(bA_\fp:u):=\{c\in A_\fp\mid cu\in bA_\fp\}.$$
Note that $bu\in bA_\fp$, so $b\in\fp A_\fp$; in particular $\fp\neq 0$ and
$\height(\fp)\geq 1$.

Put $z:=u/b\in\Frac(A)$. Then $z\notin A_\fp$ (otherwise $u\in bA_\fp$),
and $z\fp A_\fp\subset A_\fp$ by the displayed description of $\fp A_\fp$,
so $z\fp A_\fp$ is an ideal of $A_\fp$.

We claim that $z\fp A_\fp\not\subset\fp A_\fp$.
Otherwise $\fp A_\fp$ would be a finitely generated $A_\fp$-module,
faithful (because $A_\fp$ is a domain and $\fp A_\fp\neq 0$),
which is stable under multiplication by $z$; by the determinant trick
(Cayley--Hamilton) $z$ would then be integral over $A_\fp$.
But $A_\fp$ is integrally closed, being a localization of the integrally closed
domain $A$ (\docs{isIntegrallyClosed_of_isLocalization}), so we would get
$z\in A_\fp$, a contradiction.

Therefore $z\fp A_\fp$ is an ideal of the local ring $A_\fp$ which is not
contained in its maximal ideal $\fp A_\fp$, i.e.~$z\fp A_\fp=A_\fp$.
Hence $\fp A_\fp=z^{-1}A_\fp=(b/u)A_\fp$ is principal and nonzero.
Applying Krull's Hauptidealsatz (Theorem \ref{krull-principal-ideal-thm}) to
$A_\fp$ we get $\height(\fp)=\height(\fp A_\fp)\leq 1$, hence $\height(\fp)=1$.
\end{proof}

\begin{prop}
\label{noeth-ring-is-krull-domain-iff}
\lean{isKrullDomain_iff_isIntegrallyClosed,
IsKrullDomain.isIntegrallyClosed,
IsIntegrallyClosed.isKrullDomain_of_isNoetherianRing}
\leanok
\uses{noeth-local-domain-is-icd-iff,krull-domain-defn,integrally-closed-is-local-prop,ass-prime-of-quotient-by-element}
A Noetherian ring is a Krull domain if and only if it is an integrally closed domain.
\end{prop}

\begin{proof}
\leanok
``$\Rightarrow$'': Lemma \ref{integrally-closed-is-local-prop}.

``$\Leftarrow$'': Let $\fp$ be a height one prime of $A$.
Then $A_\fp$ is integrally closed (\docs{isIntegrallyClosed_of_isLocalization}).
We have $\Spec(A_\fp)=\{0,\fp A_\fp\}$ hence
$A_\fp$ is also a Noetherian local domain of dimension one.
Now by Proposition \ref{noeth-local-domain-is-icd-iff}, $A_\fp$ is a DVR.

It remains to verify the other two conditions of Definition \ref{krull-domain-defn}.

\emph{Every nonzero element of $A$ lies in only finitely many height one primes.}
Let $a\in A$ be nonzero; if $a$ is a unit, no prime ideal contains it, so assume
$a$ is a non-unit. We claim that a height one prime $\fp$ contains $a$ if and only
if $\fp$ is a minimal prime over-ideal of $(a)$.
Indeed, if $\fp$ is minimal over $(a)$, then $\height(\fp)\leq 1$ by
Theorem \ref{krull-principal-ideal-thm}, while $\height(\fp)\geq 1$ because
$a\neq 0$ and $A$ is a domain, so $\fp\neq 0$.
Conversely, if $\height(\fp)=1$ and $a\in\fp$, choose a minimal prime over-ideal
$\fq$ of $(a)$ with $\fq\subset\fp$; then $\height(\fq)=1$ by what we just proved,
and $\height(\fp)=1$ forces $\fq=\fp$.
Since $A$ is Noetherian, $(a)$ has only finitely many minimal prime over-ideals
(\docs{Ideal.finite_minimalPrimes_of_isNoetherianRing}), which proves the claim.

\emph{$A=\bigcap_{\fp\in\Spec(A),\height(\fp)=1}A_\fp$ inside $\Frac(A)$.}
The inclusion ``$\subset$'' is clear. Conversely, let
$x\in\bigcap_{\height(\fp)=1}A_\fp$ and write $x=a/b$ with $a,b\in A$, $b\neq 0$;
we may assume that $b$ is not a unit.
Assume for contradiction that $x\notin A$, i.e.~$a\notin bA$, and let
$\fa:=(bA:a)=\Ann_A(\overline a)$, where $\overline a\neq 0$ is the image of $a$
in $A/bA$; it is a proper ideal of $A$.
Since $A$ is Noetherian, the set $\{\Ann_A(\overline c)\mid c\in A\setminus bA\}$
has a maximal element containing $\fa$, and every maximal element of this set is
a prime ideal, i.e.~belongs to $\Ass(A/bA)$;
let $\fp$ be such an element, so $\fa\subset\fp\in\Ass(A/bA)$.
By Lemma \ref{ass-prime-of-quotient-by-element}, $\height(\fp)=1$.
By assumption $x\in A_\fp$, so $a/b=a'/s$ for some $a'\in A$ and
$s\in A\setminus\fp$, whence $sa=a'b\in bA$ and therefore
$s\in\fa\subset\fp$, a contradiction.
\end{proof}

\subsection{Characteristic ideal}

\begin{prop}
\label{char-ideal-preliminary}
\uses{noeth-ring-filtration}
\lean{Module.IsTorsion.finite_height_one_support,
Module.IsTorsion.isFiniteLength_localizedModule_of_height_le_one}
\leanok
Let $A$ be a Noetherian ring, $M$ be a
finitely generated torsion $A$-module.
Then for any height one prime $\fp$ of $A$,
$M_\fp$ is an $A_\fp$-module of finite length. Moreover, there are only finitely
many height one primes $\fp$ of $A$ such that $M_\fp\neq 0$.
\end{prop}

\begin{proof}
\leanok
By Proposition \ref{noeth-ring-filtration},
we may let $0=M_0\subset M_1\subset\cdots\subset M_n=M$ be a filtration of $M$
such that for each $1\leq i\leq n$,
$M_i/M_{i-1}\cong A/\fp_i$ for some prime ideal $\fp_i$ of $A$.
Note that if $\fp,\fq$ are prime ideals of $A$,
then $(A/\fp)_\fq\neq 0$ if and only if $\fp\subset\fq$.
Therefore by $M$ is torsion $A$-module, we obtain that $\height(\fp_i)\geq 1$
for all $1\leq i\leq n$,
and if $\fp$ is a height one prime, then $M_\fp\neq 0$
if and only if $\fp_i\subset\fp$ for some $i$,
by height considerations this means that $\fp_i=\fp$ for some $i$,
hence such $\fp$ are only finitely many.

To prove $\ell_{A_\fp}(M_\fp)<\infty$,
we only need to show that if $\fp,\fq$ are prime ideals of $A$
such that $\height(\fp)\geq 1$ and $\height(\fq)=1$,
then $(A/\fp)_\fq$ is an $A_\fq$-module of finite length.
In fact, by height considerations we know that $(A/\fp)_\fq\neq 0$
if and only if $\fp=\fq$, in this case $(A/\fq)_\fq=A_\fq/\fq A_\fq
=k(\fq)$ is the residue field of $\fq$, which is
an $A_\fq$-module of length one.

(\emph{Another proof without using Proposition \ref{noeth-ring-filtration}.}
Note that $M_\fp=0$ for all minimal prime ideals of $A$,
therefore if $\fp$ is of height one such that $M_\fp\neq 0$,
then $\fp$ is a minimal element in $\Supp(M)$, hence $\fp\in\Ass(M)$
which is a finite set.
So there are only finitely
many height one primes $\fp$ of $A$ such that $M_\fp\neq 0$.

Suppose $\fp$ is a height one prime such that $M_\fp\neq 0$.
To prove that $M_\fp$ is an $A_\fp$-module of finite length,
we only need to prove that the ring $A_\fp/\Ann_{A_\fp}(M_\fp)$
is Artinian. Note that $\Ann_{A_\fp}(M_\fp)=\Ann_A(M)_\fp$,
hence $A_\fp/\Ann_{A_\fp}(M_\fp)=(A/\Ann_A(M))_\fp$
whose prime ideals are one-to-one correspondence to prime ideals
of $A$ between $\Ann_A(M)$ and $\fp$,
i.e.~prime ideals in $\Supp(M)$ which is contained in $\fp$.
Such ideal can only be $\fp$ itself,
since $M$ is torsion, every prime ideal in $\Supp(M)$ has height $\geq 1$.
Hence $A_\fp/\Ann_{A_\fp}(M_\fp)$
is Artinian.)
\end{proof}

In particular, this allows us to define the \emph{characteristic ideal} of $M$.

\begin{definition}
\label{char-ideal}
\uses{char-ideal-preliminary}
\lean{Module.charIdeal}
\leanok
Let $A$ be a Noetherian ring, $M$ be a
finitely generated torsion $A$-module.
The \emph{characteristic ideal} of $M$,
denoted by $\chaR_A(M)$, or simply $\chaR(M)$ if there is no risk of confusion, is defined to be
$$
\chaR_A(M):=\prod_{\substack{\fp\in\Spec(A)\\
\height(\fp)=1}}\fp^{\ell_{A_\fp}(M_\fp)}.
$$
\end{definition}

\begin{prop}
\label{char-ideal-additive}
\uses{char-ideal}
\lean{Module.IsTorsion.injective,Module.IsTorsion.surjective,Module.IsTorsion.exact,
Module.IsTorsion.charIdeal_eq_mul_of_exact}
\leanok
Let $A$ be a Noetherian ring.
Let $0\to M'\to M\to M''\to 0$ be a short exact sequence of finitely generated $A$-modules. Then $M$ is $A$-torsion if and only if $M'$ and $M''$ are $A$-torsion.
If $M$ is $A$-torsion, then $\chaR_A(M)=\chaR_A(M')\chaR_A(M'')$.
\end{prop}

\begin{proof}
\leanok
Since localization is exact, for any prime ideal $\fp$ of $A$,
the $0\to M_\fp'\to M_\fp\to M_\fp''\to 0$ is exact.
Let $\fp$ runs over all minimal prime ideals of $A$,
we obtain that $M$ is $A$-torsion if and only if $M'$ and $M''$ are $A$-torsion.
Also, we have $\ell_{A_\fp}(M_\fp)=\ell_{A_\fp}(M_\fp')+\ell_{A_\fp}(M_\fp'')$,
hence $\chaR_A(M)=\chaR_A(M')\chaR_A(M'')$ holds.
\end{proof}

\subsection{Pseudo-null module}

\begin{definition}
\label{pseudo-null}
\lean{Module.IsPseudoNull, LinearMap.IsPseudoIsomorphism, Module.IsPseudoIsomorphic}
\leanok
Let $A$ be a Noetherian ring.

{\rm(i)}
A finitely generated $A$-module $M$ is called a \emph{pseudo-null} $A$-module,
if $M_\fp=0$ for all prime ideals $\fp$ of $A$ of height $\leq 1$.

{\rm(ii)}
An $A$-linear homomorphism $f:M\to N$ between finitely generated $A$-modules
is called a \emph{pseudo-isomorphism} (\emph{pis} for short),
if its kernel and cokernel are pseudo-null $A$-modules.

{\rm(iii)}
Two finitely generated $A$-modules $M,N$ are called
\emph{pseudo-isomorphic} (\emph{pis} for short),
denoted by $M\sim_\pis N$ or simply $M\sim N$,
if there exists a pseudo-isomorphism from $M$ to $N$.
\end{definition}

\begin{remark}
We warn the reader that $M\sim N$ not necessarily implies $N\sim M$.
\end{remark}

\begin{prop}
\label{pseudo-null-criterion}
\uses{pseudo-null}
\lean{Module.isPseudoNull_iff_subsingleton_of_krullDimLE_one,
Module.isPseudoNull_iff_finite_of_ringKrullDim_eq_two}
\leanok
Let $A$ be a Noetherian ring, $M$ be a finitely generated $A$-module.

{\rm(i)} If $A$ is of Krull dimension $\leq 1$, then $M$ is pseudo-null
if and only if $M=0$.

{\rm(ii)} If $A$ is of Krull dimension $2$,
is a local ring with finite residue field, then $M$ is pseudo-null
if and only if the cardinality of $M$ is finite.
\end{prop}

\begin{proof}
\leanok
(i) Clear.

(ii) Let $\fm$ be the maximal ideal of $A$.
If $M$ is finite, then there exists $r\in\BN$
such that $\fm^rM=0$, hence $\supp(M)\subset\{\fm\}$.
On the other hand, if $\supp(M)\subset\{\fm\}$,
then there exists $r\in\BN$
such that $\fm^rM=0$, hence $\fm^r\subset\Ann_A(M)$, therefore
$M$ is a finitely generated $A/\fm^r$-module, which must be finite.
\end{proof}

\begin{prop}
\label{pseudo-null-char-ideal}
\uses{pseudo-null,char-ideal-additive}
\lean{Module.charIdeal_eq_one_of_isPseudoNull,
LinearMap.IsPseudoIsomorphism.charIdeal_eq,
Module.IsPseudoIsomorphic.charIdeal_eq}
\leanok
Let $A$ be a Noetherian ring, $M$, $N$ be finitely generated torsion $A$-modules.

{\rm(i)} If $M$ is pseudo-null, then $\chaR_A(M)=A$, the unit ideal.
(An earlier version of this statement read ``$\chaR_A(M)=0$'', which is wrong:
by Definition \ref{char-ideal} the characteristic ideal is a \emph{product} of
height one primes, and for a pseudo-null module all the exponents
$\ell_{A_\fp}(M_\fp)$ vanish, so the product is empty and equals $A$.
The {\Lean} name \texttt{Module.charIdeal\_eq\_one\_of\_isPseudoNull} confirms
that ``$=A$'' is the intended statement.)

{\rm(ii)} If $M\sim N$, then $\chaR_A(M)=\chaR_A(N)$.
\end{prop}

\begin{proof}
\leanok
Clear from definition and Proposition \ref{char-ideal-additive}.
\end{proof}

\begin{prop}
\label{smul-is-pis}
\uses{pseudo-null}
\lean{Module.IsTorsion.isPseudoIsomorphism_smul}
\leanok
Let $A$ be a Noetherian ring, $M$ be a finitely generated torsion $A$-module,
$a\in A$ such that $M_\fp=0$ for all height one primes of $A$ containing $a$.
Then the map $a:M\xrightarrow{\times a}M$ is a pseudo-isomorphism.
\end{prop}

\begin{proof}
\leanok
Let $K$ and $L$ be the kernel and cokernel of the map
$a:M\xrightarrow{\times a}M$, respectively.
Since localization is exact, for any prime ideal $\fp$ of $A$,
the sequence $0\to K_\fp\to M_\fp\xrightarrow{\times a}M_\fp\to L_\fp\to 0$
is exact.
If $\fp$ is a minimal prime ideal of $A$, then by $M$ is torsion,
we have $M_\fp=0$; if $\fp$ is a height one prime of $A$
such that $a\in\fp$, then by the assumption we know that $M_\fp=0$,
hence $K_\fp=L_\fp=0$.
If $\fp$ is a height one prime of $A$
such that $a\notin\fp$, then $a$ is invertible in $A_\fp$,
hence the map $M_\fp\xrightarrow{\times a}M_\fp$ is an isomorphism,
so we also have $K_\fp=L_\fp=0$.
Therefore $K$ and $L$ are pseudo-null.
\end{proof}

\subsection{Structure theorem for torsion module}

\begin{definition}
\label{ht-1-localization-is-PID}
\lean{HeightOneLocalizationIsPID}
\leanok
A Noetherian ring $A$ is called
``height one localizations are PID'', if
for any finitely many height one primes $\fp_1,\cdots,\fp_r$ ($r\geq 1$) of $A$,
let $S:=A\setminus\bigcup_{i=1}^r\fp_i$, then $S^{-1}A$ is a PID.
\end{definition}

If $A$ is a Noetherian integral domain, then by Lemma \ref{pis-iff} we
only need to check $r=1$ case.

\begin{lem}
\label{pis-iff}
\uses{char-ideal-preliminary,pseudo-null,pseudo-null-iff-localization-eq-zero}
\lean{LinearMap.isPseudoIsomorphism_iff_bijective_localizedModuleMap}
\leanok
Let $A$ be a Noetherian ring and let
$M,N$ be finitely generated torsion $A$-modules.
Let $\Sigma=\{\fq_1,\cdots,\fq_r\}
=\{\fq\in\Supp(M)\cup\Supp(N)\mid\height(\fq)=1\}$
(by Proposition \ref{char-ideal-preliminary} this is a finite set).
Let $S:=A\setminus\bigcup_{i=1}^r\fq_i$ which is a multiplicative subset of $A$.
Let $f:M\to N$ be an $A$-module homomorphism.
Then $f$ is a pseudo-isomorphism if and only if $S^{-1}f:S^{-1}M\to S^{-1}N$
is an isomorphism.
\end{lem}

\begin{proof}
\leanok
Since the height one support of $\ker(f)$ and $\coker(f)$
are contained in $\Sigma$,
and since $S^{-1}\ker(f)=\ker(S^{-1}f)$,
$S^{-1}\coker(f)=\coker(S^{-1}f)$ (localization is exact),
we only need to prove that if $M$ is a finitely generated torsion $A$-module
whose height one support is contained in $\Sigma$,
then $S^{-1}M=0$ if and only if $M$ is pseudo-null (equivalently, $M_\fq=0$
for all $\fq\in\Sigma$), which is Lemma \ref{pseudo-null-iff-localization-eq-zero} below.
\end{proof}

\begin{lem}
\label{pseudo-null-iff-localization-eq-zero}
\uses{pseudo-null}
\lean{Module.isPseudoNull_iff_subsingleton_of_subset,Module.isPseudoNull_iff_subsingleton_of_subset_of_isTorsion}
\leanok
Let $M$ be a finitely generated torsion $A$-module, $\Sigma$ be a finite set of height one prime ideals of $A$,
containing height one support of $M$.
Let $S:=A\setminus\bigcup_{\fq\in\Sigma}\fq$ which is a multiplicative subset of $A$.
Then $M$ is pseudo-null if and only if $S^{-1}M=0$.
\end{lem}

\begin{proof}
\leanok
``$\Leftarrow$'': Clear.
``$\Rightarrow$'': For all $\fq\in\Sigma$, $M_\fq=0$ means that $\Ann(M)\not\subset\fq$,
since $\fq$ are prime ideals, we have $\Ann(M)\not\subset\bigcup_{\fq\in\Sigma}\fq$,
so $S^{-1}M=0$.
\end{proof}

\begin{prop}[Structure theorem of finitely generated torsion $A$-modules]
\label{structure-thm}
\uses{ht-1-localization-is-PID,pis-iff}
\lean{Module.IsTorsion.isPseudoIsomorphic_pi}
Let $A$ be a Noetherian ring whose height one localizations are PID
(Definition \ref{ht-1-localization-is-PID}).
Let $M$ be a finitely generated torsion $A$-module.
Then there exist height one primes $\fp_1,\cdots,\fp_s$ of $A$
and positive integers $k_1,\cdots,k_s$, such that there exists a pseudo-isomorphism
$M\to\bigoplus_{i=1}^s A/\fp_i^{k_i}$.
Moreover, the sequence $(\fp_i^{k_i})_{i=1}^s$ is unique up to ordering.
\end{prop}

\begin{proof}
Let
$\Sigma=\{\fq_1,\cdots,\fq_r\}=\{\fq\in\Supp(M)\mid\height(\fq)=1\}$
(by Proposition \ref{char-ideal-preliminary} this is a finite set),
and let $S=A\setminus\bigcup_{i=1}^r\fq_i$.
We may assume $\Sigma\neq\varnothing$.
Then $S^{-1}M$ is a finitely generated $S^{-1}A$-module,
and is torsion (for example, since $\Hom_{S^{-1}A}(S^{-1}M,S^{-1}A)
=S^{-1}\Hom_A(M,A)=0$).

Note that the prime ideals $\fP$ of $S^{-1}A$ are one-to-one correspondence
to prime ideals $\fp$ of $A$ satisfying $\fp\cap S=\varnothing$
(i.e.~$\fp\subset\bigcup_{i=1}^r\fq_i$, i.e~$\fp\subset\fq_i$ for some $i$),
by $\fP=S^{-1}\fp$ and $\fp=\fP\cap A$.
In particular, $S^{-1}A$ is of dimension $\leq 1$.

By structure theorem of finitely generated torsion modules over a PID,
there exist primes $\fp_1,\cdots,\fp_s$ of $A$
satisfying $\fp_i\cap S=\varnothing$,
and positive integers $k_1,\cdots,k_s$, such that
there exists an isomorphism
$g:S^{-1}M\xrightarrow\sim\bigoplus_{i=1}^sS^{-1}(A/\fp_i^{k_i})$
of $S^{-1}A$-modules.
Since $S^{-1}M$ is torsion, the $\fp_i$'s must be of height one.
Since $\Hom_{S^{-1}A}(S^{-1}M,\bigoplus_{i=1}^sS^{-1}(A/\fp_i^{k_i}))
=S^{-1}\Hom_A(M,\bigoplus_{i=1}^sA/\fp_i^{k_i})$,
by multiplying an element of $S$ to $g$ if necessary
(this doesn't change the fact that $g$ is an isomorphism), we may find
an $A$-linear map $f:M\to\bigoplus_{i=1}^sA/\fp_i^{k_i}$
such that $g=S^{-1}f$.
Now by (i) we know that $f$ is a pseudo-isomorphism.

Conversely, if $(\fp_i^{k_i})_{i=1}^s$ is such that there exists a
pseudo-isomorphism
$M\to\bigoplus_{i=1}^s A/\fp_i^{k_i}$,
then enlarging $S$ if necessary, by Lemma \ref{pis-iff},
its localization
$S^{-1}M\to\bigoplus_{i=1}^sS^{-1}(A/\fp_i^{k_i})$
is an isomorphism of $S^{-1}A$-module, hence by
structure theorem of finitely generated torsion modules over a PID,
the $(\fp_i^{k_i})_{i=1}^s$ is unique up to ordering.
\end{proof}

\begin{remark}
The {\Lean} declaration \texttt{Module.IsTorsion.isPseudoIsomorphic\_pi} states
and proves only the existence part of this proposition. The uniqueness of
$(\fp_i^{k_i})_{i=1}^s$ up to ordering is not formalized. The {\Lean} proof of
existence does not pass through $S^{-1}A$. For each height one prime
$\fq\in\Supp(M)$ it applies the structure theorem of finitely generated torsion
modules over the PID $A_\fq$ (the case $r=1$ of Definition
\ref{ht-1-localization-is-PID}) to get
$M_\fq\cong\bigoplus_j(A/\fq^{e_{\fq,j}})_\fq$ with all $e_{\fq,j}\geq 1$. It
then takes $N=\bigoplus_{\fq,j}A/\fq^{e_{\fq,j}}$, observes that $M_\fp\cong
N_\fp$ for every height one prime $\fp$, and concludes by the implication
(b)$\Rightarrow$(a) of Proposition \ref{pis-symm}.
\end{remark}

\begin{prop}
\label{pis-symm}
\uses{ht-1-localization-is-PID,pis-iff}
\lean{Module.IsTorsion.isPseudoIsomorphic_iff_nonempty_linearEquiv_localizedModule,
Module.IsPseudoIsomorphic.symm,
Module.isPseudoIsomorphic_comm}
\leanok
Let $A$ be a Noetherian ring whose height one localizations are PID
(Definition \ref{ht-1-localization-is-PID}).
Let $M,N$ be finitely generated torsion $A$-modules.
Then the followings are equivalent:
\begin{itemize}
\item[(a)]
There exists a pseudo-isomorphism $M\to N$.
\item[(b)]
For any height one prime $\fp$ of $A$, we have $M_\fp\cong N_\fp$.
\end{itemize}
In particular, if there exists a pseudo-isomorphism $M\to N$,
then there also exists a pseudo-isomorphism $N\to M$.
\end{prop}

\begin{proof}
\leanok
(a)$\Rightarrow$(b): Clear.

(b)$\Rightarrow$(a): Let $\Sigma=\{\fq_1,\cdots,\fq_r\}
=\{\fq\in\Supp(M)\cup\Supp(N)\mid\height(\fq)=1\}$
(by Proposition \ref{char-ideal-preliminary} this is a finite set),
and let $S=A\setminus\bigcup_{i=1}^r\fq_i$.
We may assume $\Sigma\neq\varnothing$.
Since $M_\fp\cong N_\fp$ for all height one primes $\fp$ of $A$,
the $S^{-1}M$ and $S^{-1}N$, being finitely generated torsion modules over
a PID $S^{-1}A$, are isomorphic. Say $g:S^{-1}M\xrightarrow\sim S^{-1}N$
is an isomorphism of $S^{-1}A$-modules.
Since $\Hom_{S^{-1}A}(S^{-1}M,S^{-1}N)=S^{-1}\Hom_A(M,N)$,
by multiplying an element of $S$ to $g$ if necessary
(this doesn't change the fact that $g$ is an isomorphism), we may find
an $A$-linear map $f:M\to N$
such that $g=S^{-1}f$.
Now by Lemma \ref{pis-iff} we know that $f$ is a pseudo-isomorphism.
\end{proof}

\begin{remark}
In {\Lean} the implication (b)$\Rightarrow$(a) is proved without passing to the
semilocal ring $S^{-1}A$, and without using that height one localizations are
PID. For each $\fq\in\Sigma$, since $M$ is finitely presented, an isomorphism
$M_\fq\cong N_\fq$ multiplied by a suitable element of $A\setminus\fq$ is the
localization of an $A$-linear map $h_\fq:M\to N$, so $(h_\fq)_\fq$ is bijective.
Choose $n_\fq\geq 0$ with $\fq^{n_\fq}N_\fq=0$ (possible since $N_\fq$ is of
finite length) and
$c_\fq\in\prod_{\fq'\in\Sigma\setminus\{\fq\}}\fq'^{n_{\fq'}+1}$ with
$c_\fq\notin\fq$. Then $f=\sum_{\fq\in\Sigma}c_\fq h_\fq$ satisfies
$f_\fp=c_\fp(h_\fp)_\fp$ for every $\fp\in\Sigma$, while $M_\fp=N_\fp=0$ for
every other prime $\fp$ of height $\leq 1$. Hence $f_\fp$ is bijective for all
primes $\fp$ of height $\leq 1$, i.e.~$f$ is a pseudo-isomorphism. The last
assertion follows from the equivalence, since (b) is symmetric in $M$ and $N$.
\end{remark}

\subsection{Structure theorem for general module}

\begin{prop}
\label{pis-torsion-oplus-torsion-free}
\uses{ht-1-localization-is-PID,char-ideal-preliminary,smul-is-pis}
\lean{Module.isPseudoIsomorphic_torsion_prod_quotient}
\leanok
Let $A$ be a Noetherian ring whose height one localizations are PID
(Definition \ref{ht-1-localization-is-PID}).
Let $M$ be a finitely generated $A$-module,
$T\subset M$ be the torsion submodule.
Then there exists a pseudo-isomorphism $M\to T\oplus M/T$.
\end{prop}

\begin{proof}
\leanok
Let
$\Sigma=\{\fq_1,\cdots,\fq_r\}=\{\fq\in\Supp(M)\mid\height(\fq)=1\}$
(by Proposition \ref{char-ideal-preliminary} this is a finite set),
and let $S=A\setminus\bigcup_{i=1}^r\fq_i$.
We may assume $\Sigma\neq\varnothing$.
Then $0\to S^{-1}T\to S^{-1}M\to S^{-1}(M/T)\to 0$ is a short exact sequence,
$S^{-1}(M/T)$ is a finitely generated torsion-free $S^{-1}A$-module,
which is free since $S^{-1}A$ is a PID.
Hence we can find $f\in\Hom_{S^{-1}A}(S^{-1}M,S^{-1}T)=S^{-1}\Hom_A(M,T)$
such that $S^{-1}T\hookrightarrow S^{-1}M\xrightarrow{f}S^{-1}T$
is the identity map.
We can find $a\in S$ and $g\in\Hom_A(M,T)$ such that
$af=g$ and such that $T\hookrightarrow M\xrightarrow{g}T$
is $T\xrightarrow{\times a}T$ which is a pseudo-isomorphism by Proposition \ref{smul-is-pis}.
Now we have the following commutative diagram of short exact sequences
\begin{center}
\begin{tikzcd}
0\arrow{r} & T\arrow{r}\arrow{d}{\times a} &
M\arrow{r}{\pi}\arrow{d}{(g,\pi)} & M/T\arrow{r}\arrow{d}{\id} & 0 \\
0\arrow{r} & T\arrow{r} & T\oplus M/T\arrow{r} & M/T\arrow{r} & 0,
\end{tikzcd}
\end{center}
by snake lemma we know that the constructed $M\to T\oplus M/T$
is a pseudo-isomorphism.
\end{proof}

\begin{remark}
The {\Lean} proof also works one height one prime at a time. Let $\Sigma$ be the
finite set of height one primes in $\Supp(T)$. For $\fq\in\Sigma$, $(M/T)_\fq$
is a finitely generated torsion-free, hence free, module over the PID $A_\fq$,
so $0\to T_\fq\to M_\fq\to(M/T)_\fq\to 0$ splits. Therefore there is an
$A$-linear map $g_\fq:M\to T$ such that the composition $T_\fq\to
M_\fq\xrightarrow{(g_\fq)_\fq}T_\fq$ is bijective. Choosing $c_\fq\notin\fq$
that lies in a sufficiently high power of every other $\fq'\in\Sigma$ (so that
$c_\fq T_{\fq'}=0$), the map $g=\sum_{\fq\in\Sigma}c_\fq g_\fq$ has the same
property at every $\fq\in\Sigma$. One then checks directly that $(g,\pi):M\to
T\oplus M/T$ becomes bijective after localizing at every prime $\fp$ of height
$\leq 1$ (for $\fp\notin\Sigma$ one has $T_\fp=0$). Proposition
\ref{smul-is-pis} and the snake lemma are not used.
\end{remark}

which is WIP in mathlib. We skip these results.

\section{Structure of Iwasawa module}

\subsection{Iwasawa algebra}

Let $p$ be a prime,
$\Gamma$ be a topological abelian group, isomorphic to $\BZ_p$
as a topological abelian group, and let $\gamma\in\Gamma$ be a topological generator
of $\Gamma$ (i.e.~the subgroup $\{\gamma^n\mid n\in\BZ\}$ is dense in $\Gamma$).
For each $n\geq 0$ let $\Gamma_n:=\Gamma/\Gamma^{p^n}$.

\begin{definition}
\label{Iwasawa-alg-defn}
\lean{CompleteGroupAlgebra,CompleteGroupAlgebra.equivInverseLimit}
The \emph{Iwasawa algebra} is defined as the completed group algebra
$$
\Lambda:=\BZ_p[[\Gamma]]:=\varprojlim_n\BZ_p[\Gamma_n],
$$
where the transition map $\BZ_p[\Gamma_{n+1}]\to
\BZ_p[\Gamma_n]$ is induced by the natural projection
$\Gamma_{n+1}\to\Gamma_n$.
Each $\BZ_p[\Gamma_n]$ is a free $\BZ_p$-module of rank $p^n$,
we endow it with the $p$-adic topology,
and endow $\Lambda$ with the subspace topology
of the product topology of $\prod_{n=0}^\infty\BZ_p[\Gamma_n]$.
\end{definition}

\begin{remark}
In {\Lean}, the completed group algebra is \texttt{CompleteGroupAlgebra}: for a
topological group $G$, $R[[G]]$ is the inverse limit of $R[G/N]$ over all open
normal subgroups $N$ of $G$, and \texttt{CompleteGroupAlgebra.equivInverseLimit}
identifies it with the inverse limit over any decreasing neighbourhood basis of
$1$ made of open normal subgroups, such as $\{\Gamma^{p^n}\}_{n\geq 0}$. No
topology is put on $R[[G]]$; only $\BZ_p[[T]]$ carries a topology in {\Lean}
(see Proposition \ref{Iwasawa-alg-isom}).
\end{remark}

\begin{prop}
\label{linear-map-is-adic-continuous}
Let $A$ be a ring, $\fa$ be an ideal of $A$.
Let $M,N$ be two $A$-modules,
and $\varphi:M\to N$ be an $A$-module homomorphism.
Then $\varphi$ is continuous if we endow $M,N$ with $\fa$-adic topology.

In particular, if $\varphi$ is an $A$-module isomorphism,
then it is a homeomorphism of topological spaces if we endow $M,N$ with $\fa$-adic topology.
\end{prop}

\begin{proof}
Let $x\in M$ and $y:=\varphi(x)\in N$.
Let $U$ be any open neighborhood of $y$ in $N$.
Then there exists some $n$ such that $y+\fa^nN\subset U$.
Take $V=x+\fa^nM$ then it is an open neighborhood of $x$ in $M$,
and we have $\varphi(V)=y+\varphi(\fa^nM)=y+\fa^n\varphi(M)\subset y+\fa^nN\subset U$.
Therefore $\varphi$ is continuous.
\end{proof}

\begin{prop}
\label{Iwasawa-alg-isom-finite-level}
\uses{Iwasawa-alg-defn,linear-map-is-adic-continuous}
\lean{EquivMvZp.groupAlgebraLevelEquiv,
CyclicGroupAlgebra.algEquiv,
IwasawaAlgebra.quotXPowSubOneEquivQuotOmega}
For each $n\geq 0$, there is an isomorphism of $\BZ_p$-algebras
$$
\BZ_p[\Gamma_n]\xrightarrow\sim\BZ_p[T]/\big((1+T)^{p^n}-1\big),\qquad
\gamma\mapsto 1+T.
$$
They are all free $\BZ_p$-modules of finite rank,
we endow them with $p$-adic topology.
By Proposition \ref{linear-map-is-adic-continuous}
we know that it is a homeomorphism of topological spaces.
\end{prop}

\begin{proof}
We have $\Gamma/\Gamma^{p^n}\cong\BZ/p^n\BZ$ as an abelian group,
and the image of $\gamma\in\Gamma$
in it is a generator of it. By abuse of notation we still denote the image of
$\gamma\in\Gamma$ in it by $\gamma$.
Then $\BZ[\Gamma/\Gamma^{p^n}]$ as a $\BZ$-module is free of rank $p^n$
and $\{\gamma^k\}_{0\leq k\leq p^n-1}$ is a basis of it.
Now it's easy to see that as a $\BZ_p$-module homomorphism,
$\BZ_p[\Gamma/\Gamma^{p^n}]\xrightarrow\sim\BZ_p[T]/\big((1+T)^{p^n}-1\big)$,
$\gamma^k\mapsto(1+T)^k$ is well-defined and is a $\BZ_p$-module isomorphism,
and preserves multiplication.
Therefore it is an isomorphism of $\BZ_p$-algebras.
\end{proof}

\begin{remark}
In {\Lean}, the isomorphism of $\BZ_p$-algebras is the composite of
\texttt{EquivMvZp.groupAlgebraLevelEquiv}
($\BZ_p[\Gamma_n]\cong\BZ_p[\BZ/p^n\BZ]$), \texttt{CyclicGroupAlgebra.algEquiv}
($A[\BZ/m\BZ]\cong A[T]/(T^m-1)$, $k\mapsto T^k$) and
\texttt{IwasawaAlgebra.quotXPowSubOneEquivQuotOmega} (induced by $T\mapsto
1+T$). The topological assertion is not formalized.
\end{remark}

\begin{prop}
\label{Iwasawa-alg-isom}
\uses{Iwasawa-alg-isom-finite-level,isom-given-by-weierstrass-division}
\lean{EquivMvZp.completeGroupAlgebraEquivPowerSeries,
EquivMvZp.completeGroupAlgebraEquivPowerSeries_of_gen,
IwasawaAlgebra.isAdic_idealAX}
There is an isomorphism of topological rings
$\BZ_p[[T]]\xrightarrow\sim\Lambda$
sending $1+T$ to $\gamma$,
where $\BZ_p[[T]]$ is endowed with $(p,T)$-adic topology.
\end{prop}

\begin{proof}
We prove that there is a natural isomorphism of $\BZ_p$-algebras
$$
\varprojlim_n\BZ_p[T]/\big((1+T)^{p^n}-1\big)
\xrightarrow\sim\BZ_p[[T]],
$$
and which is a homeomorphism of topological spaces,
where the topology of the left hand side is the subspace topology
of the product topology of the topology defined in Proposition
\ref{Iwasawa-alg-isom-finite-level},
and the topology of the right hand side it the $(p,T)$-adic topology.
From which we can obtain the isomorphism of topological rings
$\Lambda\xrightarrow\sim\BZ_p[[T]]$ given by $\gamma\mapsto 1+T$.

For simplicity of notation, denote $\varphi_n(T):=(1+T)^{p^n}-1$.
Clearly, for each $n\geq 0$ and for all $1\leq i\leq p^n-1$,
we have $\binom{p^n}{i}\in p\BZ$,
hence $\varphi_n(T)\in T^{p^n}+p\BZ[T]_{\deg\leq p^n-1}\subset(p,T)$,
in particular $\varphi_n(T)$ is a distinguished polynomial of degree $p^n$.
Moreover, $\varphi_{n+1}(T)=\varphi_n(T)\cdot\sum_{i=0}^{p-1}(1+T)^{p^ni}$
with $\sum_{i=0}^{p-1}(1+T)^{p^ni}\in(p,T)$,
hence $\varphi_n(T)\in(p,T)^{n+1}$ for all $n\geq 0$.

It's clear that $\BZ_p[T]_{\deg\leq p^n-1}\xrightarrow\sim\BZ_p[T]/(\varphi_n(T))$
is an isomorphism of $\BZ_p$-modules,
and the Weierstrass division (Proposition \ref{weierstrass-division}) implies that
$\BZ_p[T]_{\deg\leq p^n-1}\xrightarrow\sim\BZ_p[[T]]/(\varphi_n(T))$
is also an isomorphism of $\BZ_p$-modules,
therefore the natural ring homomorphism $\BZ_p[T]\hookrightarrow\BZ_p[[T]]$
induces an isomorphism of $\BZ_p$-algebras
$\BZ_p[T]/(\varphi_n(T))\xrightarrow\sim\BZ_p[[T]]/(\varphi_n(T))$
(Corollary \ref{isom-given-by-weierstrass-division}).

Since each $\BZ_p[[T]]/(\varphi_n(T))$ is a free $\BZ_p$-module of finite rank
endowed with the $p$-adic topology, we have
$\BZ_p[[T]]/(\varphi_n(T))\cong\varprojlim_m\BZ_p[[T]]/(p^m,\varphi_n(T))$,
where each $\BZ_p[[T]]/(p^m,\varphi_n(T))$ is endowed with discrete topology.
Therefore we have the following isomorphisms of rings as well as topological spaces:
\begin{align*}
\varprojlim_n\overbrace{\BZ_p[T]/(\varphi_n(T))}^{p\text{-adic topology}}
\xrightarrow\sim
\varprojlim_n\overbrace{\BZ_p[[T]]/(\varphi_n(T))}^{p\text{-adic topology}}
&\cong
\varprojlim_{m,n}\overbrace{\BZ_p[[T]]/(p^m,\varphi_n(T))}^{\text{discrete topology}} \\
&\stackrel{(*)}\cong
\varprojlim_k\overbrace{\BZ_p[[T]]/(p,T)^k}^{\text{discrete topology}}
\xrightarrow\sim
\overbrace{\BZ_p[[T]]}^{(p,T)\text{-adic topology}},
\end{align*}
here $(*)$ holds because $\{(p^m,\varphi_n(T))\}_{m\geq 1,n\geq 1}$
and $\{(p,T)^k\}_{k\geq 1}$ are \emph{cofinal}.
In fact, for each $k\geq 1$, and for any $m\geq k$ and $n\geq k$,
we have $(p^m,\varphi_n(T))\subset(p,T)^k$;
conversely, for each $m\geq 1$ and $n\geq 1$,
we have $(p,T)^{p^n}\subset(p,\varphi_n(T))$,
and $(p,\varphi_n(T))^m\subset(p^m,\varphi_n(T))$,
therefore for any $k\geq p^nm$, we have
$(p,T)^k\subset(p,T)^{p^nm}\subset(p,\varphi_n(T))^m\subset(p^m,\varphi_n(T))$.
\end{proof}

\begin{remark}
In {\Lean}, \texttt{EquivMvZp.completeGroupAlgebraEquivPowerSeries} is an
isomorphism of $\BZ_p$-algebras $\BZ_p[[\Gamma]]\cong\BZ_p[[T]]$ sending
$\gamma$ to $1+T$
(\texttt{EquivMvZp.completeGroupAlgebraEquivPowerSeries\_of\_gen}). As in the
proof above, it is assembled from the level isomorphisms
$\BZ_p[\BZ/p^n\BZ]\cong\BZ_p[[T]]/(\varphi_n(T))$
(\texttt{IwasawaAlgebra.levelEquiv}, which uses Corollary
\ref{isom-given-by-weierstrass-division}) and
$\BZ_p[[T]]\cong\varprojlim_n\BZ_p[[T]]/(\varphi_n(T))$
(\texttt{PowerSeries.equivInverseLimitOmega}). No topology is put on $\Lambda$
itself. $\BZ_p[[T]]$ carries the coefficientwise topology, which is shown to be
the $(p,T)$-adic topology (\texttt{IwasawaAlgebra.isAdic\_idealAX}), so the
homeomorphism part of the statement is not formalized.
\end{remark}

\subsection{Weierstrass preparation theorem}

\begin{definition}
\label{distinguished-polynomial}
\lean{Polynomial.IsDistinguishedAt}
\leanok
If $(A,\fm,k)$ is a local ring, then a polynomial $f(X)=\sum_{i=0}^na_iX^i\in A[X]$
is called a \emph{distinguished polynomial}
if $a_n=1$ and $a_i\in\fm$ for all $0\leq i\leq n-1$.

(Mathlib: \docs{Polynomial.IsDistinguishedAt})
\end{definition}

\begin{prop}
\label{power-series-invertible-iff}
\lean{PowerSeries.isUnit_iff_constantCoeff}
\leanok
Let $A$ be a ring, and let $f(X)=\sum_{n=0}^\infty a_nX^n\in A[[X]]$
be a formal power series.
Then $f(X)\in A[[X]]^\times$ if and only if $a_0\in A^\times$.

(Mathlib: \docs{PowerSeries.isUnit_iff_constantCoeff})
\end{prop}

\begin{proof}
\leanok
If $f(X)\in A[[X]]^\times$,
then there exists $g(X)=\sum_{n=0}^\infty b_nX^n\in A[[X]]$
such that $f(X)g(X)=1$, therefore by considering constant term we obtain
$a_0b_0=1$, hence $a_0\in A^\times$.
Conversely, if $a_0\in A^\times$, by multiplying $a_0^{-1}$ to $f(X)$
if necessary, we may assume that $a_0=1$
and $f(X)=1-Xf_1(X)$ for some $f_1(X)\in A[[X]]$.
Since $A[[X]]$ is $(X)$-adically complete and separated,
it's easy to see that $1+\sum_{k=0}^\infty X^kf_1(X)^k$
converges $(X)$-adically in $A[[X]]$ and which is the inverse of
$f(X)$.
\end{proof}

\begin{prop}[Weierstrass division]
\label{weierstrass-division}
\uses{power-series-invertible-iff}
\lean{PowerSeries.exists_isWeierstrassDivision,
PowerSeries.IsWeierstrassDivision.elim}
\leanok
Let $(A,\fm,k)$ be a complete local ring,
$g(X)=\sum_{i=0}^\infty a_iX^i\in A[[X]]\setminus\fm[[X]]$ be a formal power series
such that not all of its coefficients are in $\fm$.
Let $n\geq 0$ be the integer such that $a_n\in A\setminus\fm=A^\times$
and $a_i\in\fm$ for all $0\leq i\leq n-1$.
Then for any $f\in A[[X]]$,
there exists a unique formal power series
$q(X)\in A[[X]]$ and a unique polynomial $r(X)\in A[X]$ of degree $\leq n-1$
such that $f=gq+r$.
\end{prop}

\begin{proof}
\leanok
Write $g(X)=\sum_{i=0}^{n-1}a_iX^i+X^ng_1(X)$ for some $g_1(X)\in A[[X]]^\times$, and
$f(X)=\sum_{i=0}^{n-1}b_iX^i+X^nf_1(X)$ for some $f_1(X)\in A[[X]]$.
We construct a sequence $(q_k)_{k=1}^\infty$ inductively in $A[[X]]$,
such that $f-gq_k\in A[X]_{\deg\leq n-1}+\fm^k[[X]]$,
and such that $q_{k+1}(X)-q_k(X)\in\fm^k[[X]]$.
We construct $q_1(X):=f_1(X)g_1(X)^{-1}$.
Since $a_i\in\fm$ for all $i\leq n-1$, we have
\begin{align*}
f(X)-g(X)q_1(X)&=f(X)-\left(\sum_{i=0}^{n-1}a_iX^i\right)q_1(X)
-X^nf_1(X) \\
&=\sum_{i=0}^{n-1}b_iX^i-\left(\sum_{i=0}^{n-1}a_iX^i\right)q_1(X)
\in A[X]_{\deg\leq n-1}+\fm[[X]].
\end{align*}
Suppose $q_k(X)$ is constructed, then we may write
$f(X)-g(X)q_k(X)=\sum_{i=0}^{n-1}b_i^{(k)}X^i+X^ns_k(X)$
for some $s_k(X)\in\fm^k[[X]]$, and we construct
$q_{k+1}(X):=q_k(X)+s_k(X)g_1(X)^{-1}$. Then we have
\begin{align*}
f(X)-g(X)q_{k+1}(X)&=\sum_{i=0}^{n-1}b_i^{(k)}X^i+X^ns_k(X)
-\left(\sum_{i=0}^{n-1}a_iX^i\right)s_k(X)g_1(X)^{-1}
-X^ns_k(X) \\
&=\sum_{i=0}^{n-1}b_i^{(k)}X^i-\left(\sum_{i=0}^{n-1}a_iX^i\right)s_k(X)g_1(X)^{-1}
\in A[X]_{\deg\leq n-1}+\fm^{k+1}[[X]].
\end{align*}

Since $A[[X]]$ is complete and separated according to the sequence
$\{\fm^k[[X]]\}_{k\geq 1}$ of ideals, there exists a unique limit $q(X)\in A[[X]]$
of the sequence $(q_k)_{k=1}^\infty$, which satisfies $r:=f-gq\in A[X]_{\deg\leq n-1}$.

To prove the uniqueness, suppose $q(X)\in A[[X]]$ and $r(X)\in A[X]_{\deg\leq n-1}$
such that $gq=r$, then we prove by induction that for any $k\geq 0$
we have $q,r\in\fm^k[[X]]$, which implies that $q=r=0$.
When $k=0$ there is nothing to prove. Suppose $q,r\in\fm^k[[X]]$ for some $k\geq 0$.
Then we have $(\sum_{i=0}^{n-1}a_iX^i)q(X)+X^ng_1(X)q(X)=r(X)$,
since $a_i\in\fm$ for all $i\leq n-1$, we obtain $r(X)\in\fm^{k+1}[X]_{\deg\leq n-1}$.
Multiply $g_1(X)^{-1}$ to both side,
we obtain $(\sum_{i=0}^{n-1}a_iX^i)q(X)g_1(X)^{-1}+X^nq(X)=r(X)g_1(X)^{-1}$,
therefore $q(X)\in\fm^{k+1}[[X]]$.
\end{proof}

\begin{cor}
\label{isom-given-by-weierstrass-division}
\uses{weierstrass-division}
\lean{Polynomial.IsDistinguishedAt.algEquivQuotient}
\leanok
Let $(A,\fm,k)$ be a complete local ring,
$g(X)=\sum_{i=0}^n a_iX^i\in A[X]$ be a polynomial
such that $a_n\in A\setminus\fm$ and $a_i\in\fm$ for all $i<n$.
Then the natural map $A[X]/(g)\to A[[X]]/(g)$
is an isomorphism.
\end{cor}

\begin{proof}
\leanok
Let $f\in A[[X]]$.
Then by Proposition \ref{weierstrass-division},
we may find a unique formal power series
$q(X)\in A[[X]]$ and a unique polynomial $r(X)\in A[X]$ of degree $\leq n-1$
such that $f=gq+r$.
Then $r$ is the unique inverse of $f$ under the natural map $A[X]/(g)\to A[[X]]/(g)$.
\end{proof}

\begin{prop}[Weierstrass preparation theorem]
\label{weierstrass-preparation}
\uses{weierstrass-division,distinguished-polynomial}
\lean{PowerSeries.exists_isWeierstrassFactorization,
PowerSeries.IsWeierstrassFactorization.elim}
\leanok
Let $(A,\fm,k)$ be a complete local ring.
Let $g(X)\in A[[X]]\setminus\fm[[X]]$ be a formal power series
such that not all of its coefficients are in $\fm$.
Then there is a unique distinguished polynomial $f(X)\in A[X]$
and a unique invertible formal power series $h(X)\in A[[X]]^\times$ such that $g=fh$.
\end{prop}

\begin{proof}
\leanok
Take $f(X)=X^n$ in Proposition \ref{weierstrass-division}, we obtain $q(X)\in A[[X]]$
and $r(X)\in A[X]_{\deg\leq n-1}$ such that $X^n=g(X)q(X)+r(X)$.
Since $g(X)=\sum_{i=1}^{n-1}a_iX^i+X^ng_1(X)$
with $a_i\in\fm$ for all $i\leq n-1$ and $g_1(X)\in A[[X]]^\times$,
we have $r(X)\in\fm[X]_{\deg\leq n-1}$, and by the construction in (ii)
we have $q(X)\in g_1(X)^{-1}+\fm[[X]]\subset A[[X]]^\times$.
Therefore take $h(X):=q(X)^{-1}\in A[[X]]^\times$
and $f(X):=X^n-r(X)$, then $f(X)$ is a distinguished polynomial of degree $n$,
and $g(X)=f(X)h(X)$ holds.

To prove the uniqueness, suppose $f(X)$ and $f'(X)$ are two distinguished polynomials
and $u(X)\in A[[X]]^\times$ such that $f'(X)=f(X)u(X)$.
Then $\overline u(X)\in k[[X]]^\times$ and we have
$\overline f{}'(X)=X^{\deg(f')}=\overline f(X)\overline u(X)
=X^{\deg(f)}\overline u(X)\in k[[X]]^\times$,
which forces that $\deg(f)=\deg(f')$ and $\overline u(X)=1$.
Therefore $f'(X)-f(X)\in A[X]_{\deg\leq\deg(f)-1}$
and $f'(X)=f(X)+(f'(X)-f(X))$ is a Weierstrass division of $f'$ by $f$,
on the other hand, $f'(X)=f(X)u(X)$ is also a Weierstrass division of $f'$ by $f$,
hence by the uniqueness of Weierstrass division
we have $u(X)=1$ and $f'(X)=f(X)$.

(\emph{Another proof.}
It is possible to prove Weierstrass preparation theorem using a form
of Hensel's lemma presented in \url{https://ncatlab.org/nlab/show/Hensel's+lemma}.)
\end{proof}

\subsection{Characteristic ideal}

Let $\Lambda=\BZ_p[[T]]$.

\begin{prop}
\label{Lambda-is-reg-of-dim-2}
\uses{Iwasawa-alg-isom,krull-principal-ideal-thm,power-series-invertible-iff}
\lean{IwasawaAlgebra.isNoetherianRing_powerSeries,
IwasawaAlgebra.isLocalRing_powerSeries,
IwasawaAlgebra.maximalIdeal_eq_span_pair,
IwasawaAlgebra.ringKrullDim_eq_two}
$\Lambda$ is a
Noetherian regular local ring of Krull dimension $2$.

(We try to avoid this result but prove its consequences directly,
since regular local ring is still WIP in mathlib.)
\end{prop}

\begin{proof}
By Proposition \ref{Iwasawa-alg-isom} we identify $\Lambda$ with $\BZ_p[[T]]$.

\emph{Noetherian.} $\BZ_p$ is Noetherian, and the ring of formal power series in
one variable over a Noetherian ring is Noetherian.

\emph{Domain.} $\BZ_p$ is a domain; if $f,g\in\BZ_p[[T]]$ are nonzero with lowest
nonvanishing coefficients $a_i$ and $b_j$, then the coefficient of $T^{i+j}$ in
$fg$ is $a_ib_j\neq 0$, so $fg\neq 0$.

\emph{Local with maximal ideal $\fm=(p,T)$.}
By Proposition \ref{power-series-invertible-iff}, $f\in\BZ_p[[T]]^\times$ if and
only if $f(0)\in\BZ_p^\times$, i.e.~if and only if $f\notin(p,T)$.
So the non-units form the ideal $(p,T)$, hence $\Lambda$ is local with maximal
ideal $\fm=(p,T)$ and residue field $\Lambda/\fm=\BF_p$.

\emph{Krull dimension $2$.}
Since $\fm$ is generated by the two elements $p$ and $T$, Krull's Hauptidealsatz
(Theorem \ref{krull-principal-ideal-thm}) gives
$\dim\Lambda=\height(\fm)\leq 2$.
Conversely $0\subsetneqq(T)\subsetneqq(p,T)$ is a chain of prime ideals of length
$2$ (note $\Lambda/(T)\cong\BZ_p$ is a domain), so $\dim\Lambda\geq 2$.

\emph{Regular.}
We must show $\dim_{\BF_p}\fm/\fm^2=2$.
The classes of $p$ and $T$ span $\fm/\fm^2$, and we claim they are linearly
independent over $\BF_p$. Suppose $\alpha p+\beta T\in\fm^2=(p^2,pT,T^2)$ with
$\alpha,\beta\in\Lambda$, say
$\alpha p+\beta T=\gamma_1p^2+\gamma_2pT+\gamma_3T^2$.
Reducing modulo $T$ gives $\alpha(0)p=\gamma_1(0)p^2$ in $\BZ_p$, hence
$\alpha(0)\in p\BZ_p$, i.e.~$\alpha\in\fm$.
Then $\alpha p\in p\fm\subset(p^2,pT)$, so $\beta T\in(p^2,pT,T^2)$; reducing
modulo $p$ gives $\overline\beta T\in(T^2)$ in $\BF_p[[T]]$, hence
$\overline\beta\in(T)$, i.e.~$\beta\in\fm$.
Therefore $\dim_{\BF_p}\fm/\fm^2=2=\dim\Lambda$, so $\Lambda$ is regular.
\end{proof}

\begin{remark}
Regularity is not formalized in {\Lean}. What is formalized is that
$\Lambda=\BZ_p[[T]]$ is a Noetherian local ring
(\texttt{IwasawaAlgebra.isNoetherianRing\_powerSeries},
\texttt{IwasawaAlgebra.isLocalRing\_powerSeries}) with maximal ideal $(p,T)$
(\texttt{IwasawaAlgebra.maximalIdeal\_eq\_span\_pair}), residue field of
cardinality $p$ (\texttt{IwasawaAlgebra.card\_quotient\_maximalIdeal}) and Krull
dimension $2$ (\texttt{IwasawaAlgebra.ringKrullDim\_eq\_two}). The upper bound
on the dimension uses Krull's height theorem as in the proof above, and the
lower bound uses $\dim R[[T]]\geq\dim R+1$ in place of the chain
$0\subsetneqq(T)\subsetneqq(p,T)$.
\end{remark}

\begin{cor}
\label{Lambda-is-UFD}
\uses{Lambda-is-reg-of-dim-2,regular-local-ring-is-UFD,weierstrass-preparation,isom-given-by-weierstrass-division,Iwasawa-alg-isom}
\lean{IwasawaAlgebra.uniqueFactorizationMonoid_powerSeries,
IwasawaAlgebra.isDomain_powerSeries}
\leanok
$\Lambda$ is a UFD.
\end{cor}

\begin{proof}
\leanok
A corollary of Proposition \ref{Lambda-is-reg-of-dim-2} and
Theorem \ref{regular-local-ring-is-UFD}
(or maybe one can check directly that the $I$-adic completion of a UFD is a UFD).

One can also use the Weierstrass preparation theorem, as follows; this second
proof avoids regular local rings altogether, and uses only that
$\Lambda=\BZ_p[[T]]$ is a Noetherian local domain with maximal ideal $\fm=(p,T)$
(established in the first four paragraphs of the proof of
Proposition \ref{Lambda-is-reg-of-dim-2}).

\emph{Step 1 (normal form).}
Since $\bigcap_{k\geq 0}p^k\Lambda=0$, every nonzero $f\in\Lambda$ can be written
as $f=p^\mu g$ with $\mu\geq 0$ and $g\notin p\Lambda$.
Applying the Weierstrass preparation theorem
(Proposition \ref{weierstrass-preparation}) to the complete local ring
$(\BZ_p,(p),\BF_p)$ and to $g\in\BZ_p[[T]]\setminus p\BZ_p[[T]]$, we get
$g=Pu$ with $P\in\BZ_p[T]$ a distinguished polynomial and $u\in\Lambda^\times$.
So $f=p^\mu Pu$, and $\mu,P,u$ are uniquely determined by $f$.

\emph{Step 2 ($\Lambda$ is atomic).}
$\Lambda$ is Noetherian, hence satisfies the ascending chain condition on
principal ideals, hence every nonzero non-unit of $\Lambda$ is a finite product
of irreducible elements.

\emph{Step 3 (the irreducible elements).}
Let $f$ be irreducible and write $f=p^\mu Pu$ as in Step 1.
If $\mu\geq 1$, then irreducibility and the fact that $p$ is not a unit force
$\mu=1$ and $P=1$, i.e.~$f=pu$.
If $\mu=0$, then $f=Pu$ with $P$ distinguished of degree $\geq 1$, and $P$ is
irreducible. So, up to units, the irreducible elements of $\Lambda$ are $p$ and
the irreducible distinguished polynomials.

\emph{Step 4 ($p$ is prime).}
$\Lambda/(p)\cong\BF_p[[T]]$ is a domain.

\emph{Step 5 (an irreducible distinguished polynomial $P$ is prime).}
We first check that $P$ is irreducible as an element of $\BZ_p[T]$.
Suppose $P=fg$ with $f,g\in\BZ_p[T]$ non-units of $\BZ_p[T]$
(the units of $\BZ_p[T]$ are $\BZ_p^\times$).
Neither $f$ nor $g$ is constant: a constant factor of the monic polynomial $P$
divides $1$, hence is a unit.
If $f$ were a unit of $\Lambda$, i.e.~$f(0)\in\BZ_p^\times$, then $g=f^{-1}P$
would satisfy $g\notin p\Lambda$ (comparing leading coefficients in $P=fg$
shows that the leading coefficient of $g$ is a unit of $\BZ_p$), so $g=Qv$ with $Q$ distinguished and
$v\in\Lambda^\times$ by Proposition \ref{weierstrass-preparation}; then
$P=Q\cdot(fv)$ is a Weierstrass factorization of $P$, so $Q=P$ and $fv=1$ by the
uniqueness part of Proposition \ref{weierstrass-preparation}.
But $\deg Q\leq\deg g<\deg P$, a contradiction.
Hence $f$, and likewise $g$, is a non-unit of $\Lambda$, contradicting the
irreducibility of $P$ in $\Lambda$.
Therefore $P$ is irreducible in $\BZ_p[T]$.
Since $\BZ_p$ is a PID, $\BZ_p[T]$ is a UFD, so $(P)$ is a prime ideal of
$\BZ_p[T]$ and $\BZ_p[T]/(P)$ is a domain.
By Corollary \ref{isom-given-by-weierstrass-division},
$\BZ_p[T]/(P)\xrightarrow\sim\Lambda/(P)$, so $\Lambda/(P)$ is a domain and $P$
is a prime element of $\Lambda$.

\emph{Step 6.}
$\Lambda$ is atomic (Step 2) and each of its irreducible elements is prime
(Steps 3--5), hence $\Lambda$ is a UFD.
\end{proof}

\begin{remark}
The {\Lean} proof
(\texttt{IwasawaAlgebra.uniqueFactorizationMonoid\_powerSeries}) follows neither
route above. It is the Mathlib instance stating that $R[[T]]$ is a UFD for every
principal ideal domain $R$, proved with Kaplansky's criterion (a domain is a UFD
if and only if every nonzero prime ideal contains a prime element). A prime
ideal of $R[[T]]$ containing $T$ contains the prime element $T$. A prime ideal
not containing $T$ is generated by a single element, because its image under
$f\mapsto f(0)$ is a principal ideal of $R$.
\end{remark}

\begin{cor}
\label{Lambda-ht-1-principal}
\uses{Lambda-is-UFD,UFD-iff-ht-1-principal,weierstrass-preparation}
\lean{IwasawaAlgebra.exists_prime_span_eq_of_height_eq_one,
IwasawaAlgebra.eq_span_singleton_p_of_mem,
IwasawaAlgebra.exists_unique_distinguished_span_eq_of_height_eq_one,
IwasawaAlgebra.exists_gen_of_height_eq_one}
\leanok
Any height $1$ prime $\fp$ of $\Lambda$
is principal. Moreover,

{\rm(i)}
If the generator of $\fp$ is in $p\BZ_p[[T]]$, then
we must have $\fp=(p)$.

{\rm(ii)}
If the generator of $\fp$ is not in $p\BZ_p[[T]]$, then
by Proposition \ref{weierstrass-preparation} such $\fp$
has a unique generator which is an irreducible distinguished polynomial.
\end{cor}

\begin{proof}
\leanok
By Theorem \ref{UFD-iff-ht-1-principal} and Corollary \ref{Lambda-is-UFD},
any height $1$ prime $\fp$ of $\Lambda$ is principal, say $\fp=(g)$ with
$g\neq 0$; since $\fp$ is prime, $g$ is a prime element, in particular
irreducible and not a unit.

{\rm(i)} If $g\in p\BZ_p[[T]]$, write $g=ph$. Since $g$ is irreducible and $p$ is
not a unit, $h$ must be a unit, hence $\fp=(g)=(p)$.

{\rm(ii)} If $g\notin p\BZ_p[[T]]$, then by the Weierstrass preparation theorem
(Proposition \ref{weierstrass-preparation}) we may write $g=Pu$ with $P$ a
distinguished polynomial and $u\in\Lambda^\times$; thus $\fp=(P)$, and $P$ is
irreducible because $g$ is, and $\deg P\geq 1$ because $g$ is not a unit.
If $P'$ is another distinguished polynomial with $(P')=(P)$, then $P'=Pv$ for
some $v\in\Lambda^\times$; both $P'=P'\cdot 1$ and $P'=P\cdot v$ are Weierstrass
factorizations of $P'$, so $P'=P$ and $v=1$ by the uniqueness part of
Proposition \ref{weierstrass-preparation}.
Hence the distinguished generator of $\fp$ is unique.
\end{proof}

\begin{remark}
In {\Lean}, (i) and (ii) are stated under the hypotheses $p\in\fp$
(\texttt{IwasawaAlgebra.eq\_span\_singleton\_p\_of\_mem}) and $p\notin\fp$
(\texttt{IwasawaAlgebra.exists\_unique\_distinguished\_span\_eq\_of\_height\_eq\_one}).
These are equivalent to the hypotheses above, since a generator of $\fp$ lies in
$p\BZ_p[[T]]$ if and only if $p\in\fp$.
\end{remark}

Therefore, we have

\begin{prop}
\label{Lambda-module-structure}
\uses{Lambda-ht-1-principal,structure-thm}
If $X$ is a finitely generated torsion $\Lambda$-module,
then there exists a pseudo-isomorphism
$$
X\to\bigoplus_{i=1}^m\Lambda/(f_i^{b_i})\oplus\bigoplus_{j=1}^s\Lambda/(p^{n_j})
$$
where $f_1,\cdots,f_m$ are irreducible distinguished polynomials.
The characteristic ideal $\chaR_\Lambda(X)$ is generated by
$p^{\sum_{j=1}^sn_j}\prod_{i=1}^mf_i^{b_i}$
which is contained in $p^{\sum_{j=1}^sn_j}\BZ_p[[T]]$
but not in $p^{1+\sum_{j=1}^sn_j}\BZ_p[[T]]$.
\end{prop}

\begin{proof}
\uses{Lambda-is-UFD,Lambda-is-reg-of-dim-2,regular-domain-is-good,char-ideal-additive,pseudo-null-char-ideal,noeth-local-domain-is-icd-iff}
By Corollary \ref{Lambda-is-UFD}, $\Lambda$ is a UFD, hence integrally closed:
if $x=a/b\in\Frac(\Lambda)$ with $a,b\in\Lambda$ having no common prime factor
satisfies $x^n+c_{n-1}x^{n-1}+\cdots+c_0=0$ with $c_i\in\Lambda$, then
$a^n=-b(c_{n-1}a^{n-1}+\cdots+c_0b^{n-1})$, so every prime factor of $b$ divides
$a^n$ and hence $a$; therefore $b$ is a unit and $x\in\Lambda$.
By Proposition \ref{regular-domain-is-good}, the height one localizations of
$\Lambda$ are PID, so the structure theorem (Proposition \ref{structure-thm})
applies to the finitely generated torsion $\Lambda$-module $X$: there are height
one primes $\fq_1,\cdots,\fq_t$ of $\Lambda$ and integers $c_k\geq 1$ together
with a pseudo-isomorphism $X\to\bigoplus_{k=1}^t\Lambda/\fq_k^{c_k}$.
By Corollary \ref{Lambda-ht-1-principal} each $\fq_k$ is either $(p)$ or $(f)$
for a (unique) irreducible distinguished polynomial $f$; naming the factors
accordingly gives the asserted pseudo-isomorphism
$$X\to\bigoplus_{i=1}^m\Lambda/(f_i^{b_i})\oplus\bigoplus_{j=1}^s\Lambda/(p^{n_j}).$$

We now compute the characteristic ideal.
Let $\fq=(g)$ and $\fq'=(g')$ be distinct height one primes of $\Lambda$.
Then $\fq\not\subset\fq'$ (two distinct height one primes of a domain are
incomparable), so $g\notin\fq'$, hence $g$ is invertible in $\Lambda_{\fq'}$ and
$(\Lambda/\fq^c)_{\fq'}=0$ for all $c\geq 1$.
On the other hand $\Lambda_\fq$ is a Noetherian local domain of dimension one
whose maximal ideal $\fq\Lambda_\fq=g\Lambda_\fq$ is principal, hence a discrete
valuation ring (Proposition \ref{noeth-local-domain-is-icd-iff}), and
$(\Lambda/\fq^c)_\fq=\Lambda_\fq/g^c\Lambda_\fq$ has length $c$.
By Definition \ref{char-ideal} this gives $\chaR_\Lambda(\Lambda/\fq^c)=\fq^c$,
and Proposition \ref{char-ideal-additive} (applied inductively to the direct sum)
yields
$$\chaR_\Lambda\Big(\bigoplus_{i=1}^m\Lambda/(f_i^{b_i})
\oplus\bigoplus_{j=1}^s\Lambda/(p^{n_j})\Big)
=\Big(p^{\sum_{j=1}^sn_j}\prod_{i=1}^mf_i^{b_i}\Big).$$
By Proposition \ref{pseudo-null-char-ideal}(ii) this ideal is also
$\chaR_\Lambda(X)$.
Finally, a product of distinguished polynomials is distinguished, so
$\prod_{i=1}^mf_i^{b_i}$ is monic and in particular is not in $p\BZ_p[[T]]$;
therefore the generator $p^{\sum_jn_j}\prod_if_i^{b_i}$ lies in
$p^{\sum_jn_j}\BZ_p[[T]]$ but not in $p^{1+\sum_jn_j}\BZ_p[[T]]$.
\end{proof}

\begin{definition}
\label{iwasawa-mod-invariants}
\uses{Lambda-module-structure}
\lean{IwasawaAlgebra.mu,
IwasawaAlgebra.lambda,
IwasawaAlgebra.muMod,
IwasawaAlgebra.lambdaMod}
\leanok
{\rm(i)}
The $\mu$-invariant of $X$
is defined to be $\mu(X):=\sum_{j=1}^sn_j$,
and the $\lambda$-invariant of $X$
is defined to be $\lambda(X):=\sum_{i=1}^mb_i\deg f_i$.

{\rm(ii)}
If $f\in\BZ_p[[T]]$ is not zero, then define
$\mu(f)$ be the integer such that
$f\in p^{\mu(f)}\BZ_p[[T]]$ but
$f\notin p^{1+\mu(f)}\BZ_p[[T]]$,
define $\lambda(f)$ be the leading degree of
$(p^{-\mu(f)}f\bmod p)\in\BF_p[[T]]$.
\end{definition}

\begin{remark}
In {\Lean}, $\mu(f)$ and $\lambda(f)$ (\texttt{IwasawaAlgebra.mu},
\texttt{IwasawaAlgebra.lambda}) are read off the unique factorization
$f=p^{\mu}Pu$ with $P$ a distinguished polynomial and $u\in\Lambda^\times$
(\texttt{IwasawaAlgebra.IsWeierstrassNormalForm}), with $\lambda(f):=\deg P$.
This agrees with (ii), since $p^{-\mu}f\bmod p=T^{\deg P}\,\overline u$ with
$\overline u\in\BF_p[[T]]^\times$. The invariants of a module
(\texttt{IwasawaAlgebra.muMod}, \texttt{IwasawaAlgebra.lambdaMod}) are defined
as $\mu(f)$ and $\lambda(f)$ for a nonzero generator $f$ of $\chaR_\Lambda(X)$.
That this agrees with (i) follows from Proposition \ref{Lambda-module-structure}
and \texttt{IwasawaAlgebra.muMod\_eq\_sum\_and\_lambdaMod\_eq\_sum}.
\end{remark}

Clearly, $\mu(X)$ and $\lambda(X)$ are equal to
$\mu(f)$ and $\lambda(f)$ if $\chaR_\Lambda(X)=(f)$.

\begin{prop}
\label{iwasawa-mod-invariants-2}
\uses{iwasawa-mod-invariants,Lambda-module-structure,char-ideal,pseudo-null-criterion,weierstrass-division,Lambda-is-reg-of-dim-2}
We have $\mu(X)=\sum_{i=0}^\infty\rank_{\BF_p[[T]]}X[p^{i+1}]/X[p^i]$,
and $\lambda(X)=\rank_{\BZ_p}X/X[p^\infty]$.
%and $\chaR_\Lambda(X)=(p^{\mu(X)}h_X(T))\subset\Lambda$, where $h_X(T)$
%is the characteristic polynomial of $T$ acts on $X\otimes_{\BZ_p}\BQ_p$.
\end{prop}

\begin{proof}
\emph{Conventions.}
Here $X$ is a finitely generated torsion $\Lambda$-module,
$X[p^i]:=\{x\in X\mid p^ix=0\}$ and $X[p^\infty]:=\bigcup_{i\geq 0}X[p^i]$;
note that $X[p^{i+1}]/X[p^i]$ is killed by $p$, hence is a finitely generated
$\BF_p[[T]]=\Lambda/(p)$-module. We put
$\rank_{\BF_p[[T]]}M:=\dim_{\BF_p((T))}\big(M\otimes_{\BF_p[[T]]}\BF_p((T))\big)$
and $\rank_{\BZ_p}N:=\dim_{\BQ_p}(N\otimes_{\BZ_p}\BQ_p)$;
both are additive on short exact sequences (localization is exact) and vanish on
finite modules.

Write $\fp_0:=(p)$, a height one prime of $\Lambda$, and let $R:=\Lambda_{\fp_0}$.

\emph{Step 0.}
$R$ is a discrete valuation ring with uniformizer $p$ and residue field
$R/pR=\Frac(\BF_p[[T]])=\BF_p((T))$; indeed $\Lambda$ is a UFD and $p$ is a prime
element (see the proof of Corollary \ref{Lambda-is-UFD}), so $R$ is a local UFD
of dimension one with principal maximal ideal.
Moreover $\ell_R(X_{\fp_0})=\mu(X)$: by Definition \ref{char-ideal},
$\chaR_\Lambda(X)=\prod_{\height(\fq)=1}\fq^{\ell_{\Lambda_\fq}(X_\fq)}$, while by
Proposition \ref{Lambda-module-structure} this ideal is generated by
$p^{\mu(X)}\prod_if_i^{b_i}$ with $\prod_if_i^{b_i}\notin p\Lambda$; comparing the
exponent of the prime $(p)$ in the two factorizations of this ideal in the UFD
$\Lambda$ gives $\ell_R(X_{\fp_0})=\mu(X)$.

\emph{Step 1 (the formula for $\mu$).}
Localization at $\fp_0$ is exact, so $(X[p^k])_{\fp_0}=X_{\fp_0}[p^k]$ for all
$k$, and therefore
$$\big(X[p^{i+1}]/X[p^i]\big)_{\fp_0}
=X_{\fp_0}[p^{i+1}]/X_{\fp_0}[p^i].$$
The module $Q_i:=X[p^{i+1}]/X[p^i]$ is killed by $p$, so it is a finitely
generated $\BF_p[[T]]$-module and its localization at $\fp_0$ is
$Q_i\otimes_{\BF_p[[T]]}\BF_p((T))$; as $R$-module it is killed by $p$, so its
length over $R$ equals its dimension over the residue field
$R/pR=\BF_p((T))$. Hence
$$\rank_{\BF_p[[T]]}\big(X[p^{i+1}]/X[p^i]\big)
=\ell_R\big(X_{\fp_0}[p^{i+1}]/X_{\fp_0}[p^i]\big).$$
Now $N:=X_{\fp_0}$ is an $R$-module of finite length $\mu(X)$ by Step 0, so
$N\cong\bigoplus_{k=1}^tR/p^{m_k}R$ with $\sum_km_k=\ell_R(N)=\mu(X)$
(structure theorem over the discrete valuation ring $R$).
For such $N$ we have $N[p^{i+1}]/N[p^i]\cong(R/pR)^{\#\{k\mid m_k>i\}}$, whence
$$\sum_{i=0}^\infty\ell_R\big(N[p^{i+1}]/N[p^i]\big)
=\sum_{i=0}^\infty\#\{k\mid m_k>i\}=\sum_{k=1}^tm_k=\mu(X),$$
all but finitely many terms being zero. This is the first formula.

\emph{Step 2 (the formula for $\lambda$).}
Let $\varphi:X\to E:=\bigoplus_{i=1}^m\Lambda/(f_i^{b_i})
\oplus\bigoplus_{j=1}^s\Lambda/(p^{n_j})$ be a pseudo-isomorphism as in
Proposition \ref{Lambda-module-structure}; by
Proposition \ref{pseudo-null-criterion}(ii) (applicable since, by
Proposition \ref{Lambda-is-reg-of-dim-2}, $\Lambda$ is local of Krull dimension
$2$ with finite residue field $\BF_p$) the kernel $K$ and the cokernel $C$ of
$\varphi$ are finite.

By Weierstrass division (Proposition \ref{weierstrass-division}) applied to the
distinguished polynomial $f_i^{b_i}$ of degree $b_i\deg f_i$, the module
$\Lambda/(f_i^{b_i})$ is a free $\BZ_p$-module of rank $b_i\deg f_i$ with basis
$1,T,\cdots,T^{b_i\deg f_i-1}$; in particular it has no $p$-torsion. Hence
$$E[p^\infty]=\bigoplus_{j=1}^s\Lambda/(p^{n_j}),\qquad
E/E[p^\infty]=\bigoplus_{i=1}^m\Lambda/(f_i^{b_i}),\qquad
\rank_{\BZ_p}\big(E/E[p^\infty]\big)=\sum_{i=1}^mb_i\deg f_i=\lambda(X).$$

It remains to see that $\varphi$ induces a map
$X/X[p^\infty]\to E/E[p^\infty]$ which is injective with finite cokernel.
Let $p^a$ kill $K$. If $x\in X$ satisfies $\varphi(x)\in E[p^\infty]$, say
$p^k\varphi(x)=0$, then $p^kx\in K$, so $p^{k+a}x=0$ and $x\in X[p^\infty]$;
hence the induced map is injective.
Its cokernel is a quotient of $E/\varphi(X)=C$, hence finite.
Since $\rank_{\BZ_p}$ is additive and vanishes on finite modules,
$\rank_{\BZ_p}(X/X[p^\infty])=\rank_{\BZ_p}(E/E[p^\infty])=\lambda(X)$.
\end{proof}

\subsection{Growth of coinvariant part}

Let $\Lambda=\BZ_p[[T]]$.

In this subsection we write, for $n\geq 0$,
$$
\omega_n:=\gamma^{p^n}-1=(1+T)^{p^n}-1\in\BZ_p[T],
$$
and, for $n\geq e\geq 0$, $\nu_{n,e}:=\sum_{k=0}^{p^{n-e}-1}\gamma^{kp^e}$.
We also fix the valuation $v$ on a fixed algebraic closure $\ov\BQ_p$ of $\BQ_p$
normalized by $v(p)=1$.

\begin{lem}
\label{nu-distinguished}
\uses{distinguished-polynomial}
\lean{Polynomial.oneAddXPowSubOne,
Polynomial.oneAddXPowSubOne_def,
Polynomial.nu,
Polynomial.isDistinguishedAt_oneAddXPowSubOne,
Polynomial.natDegree_oneAddXPowSubOne,
Polynomial.oneAddXPowSubOne_dvd_of_dvd,
Polynomial.nu_mul_oneAddXPowSubOne,
Polynomial.isDistinguishedAt_nu,
Polynomial.natDegree_nu,
Polynomial.nu_dvd_nu}
\leanok
For all $n\geq e\geq 0$:

{\rm(i)} $\omega_n$ is a distinguished polynomial of degree $p^n$, and
$\omega_n\mid\omega_{n+1}$ in $\BZ_p[T]$;

{\rm(ii)} $\omega_n=\nu_{n,e}\,\omega_e$, and $\nu_{n,e}$ is a distinguished
polynomial of degree $p^n-p^e$;

{\rm(iii)} $\nu_{n,e}\mid\nu_{n+1,e}$ in $\BZ_p[T]$.
\end{lem}

\begin{proof}
\leanok
(i) $\omega_n=(1+T)^{p^n}-1$ is monic of degree $p^n$ with constant term $0$, and
$\binom{p^n}i\in p\BZ$ for $0<i<p^n$, so $\omega_n\equiv T^{p^n}\pmod p$;
thus all coefficients of $\omega_n$ other than the leading one lie in $p\BZ_p$,
i.e.~$\omega_n$ is distinguished.
Putting $Z:=(1+T)^{p^n}$ we have $\omega_{n+1}=Z^p-1=(Z-1)(Z^{p-1}+\cdots+1)$,
so $\omega_n=Z-1$ divides $\omega_{n+1}$.

(ii) With $S:=\gamma^{p^e}=(1+T)^{p^e}$ we have
$\nu_{n,e}=\sum_{k=0}^{p^{n-e}-1}S^k$, so
$\nu_{n,e}\,(S-1)=S^{p^{n-e}}-1$, i.e.~$\nu_{n,e}\,\omega_e=\omega_n$.
Comparing leading terms, $\nu_{n,e}$ is monic of degree $p^n-p^e$; and reducing
modulo $p$, $T^{p^n}=\overline{\nu_{n,e}}\cdot T^{p^e}$ in $\BF_p[T]$ gives
$\overline{\nu_{n,e}}=T^{p^n-p^e}$, so $\nu_{n,e}$ is distinguished.

(iii) $\nu_{n+1,e}=\omega_{n+1}/\omega_e=(\omega_{n+1}/\omega_n)\cdot\nu_{n,e}$
by (i) and (ii).
\end{proof}

\begin{lem}
\label{omega-val-growth}
\uses{distinguished-polynomial}
{\rm(i)} If $F\in\BZ_p[T]$ is a distinguished polynomial of degree $\geq 1$ and
$\alpha\in\ov\BQ_p$ is a root of $F$, then $v(\alpha)>0$.

{\rm(ii)} Let $\alpha\in\ov\BQ_p$ with $v(\alpha)>0$ and
$(1+\alpha)^{p^n}\neq 1$ for all $n\geq 0$. Then there are a constant
$c_\alpha\in\BQ$ and an integer $n_\alpha\geq 0$ such that
$v(\omega_n(\alpha))=n+c_\alpha$ for all $n\geq n_\alpha$.
\end{lem}

\begin{proof}
(i) Write $F=T^d+a_{d-1}T^{d-1}+\cdots+a_0$ with $v(a_i)\geq 1$, and suppose
$v(\alpha)\leq 0$. From $\alpha^d=-\sum_{i<d}a_i\alpha^i$ we get
$dv(\alpha)\geq\min_{i<d}(v(a_i)+iv(\alpha))\geq 1+dv(\alpha)$, because
$iv(\alpha)\geq dv(\alpha)$ for $i\leq d$ and $v(\alpha)\leq 0$.
This is absurd. Note also $\alpha\ne0$ is not required: if $\alpha=0$ then
$v(\alpha)=\infty>0$.

(ii) Put $\beta:=1+\alpha$, so $\delta_n:=\beta^{p^n}-1\neq 0$ for all $n$ and
$v(\delta_0)=v(\alpha)>0$. For any $\beta_0$ with $\delta:=\beta_0-1\neq 0$,
$$\beta_0^p-1=(1+\delta)^p-1=p\delta+\sum_{i=2}^{p-1}\binom pi\delta^i+\delta^p .$$
If $v(\delta)>\frac1{p-1}$, then $v(p\delta)=1+v(\delta)$, while the middle terms
have valuation $\geq 1+2v(\delta)>1+v(\delta)$ and the last term has valuation
$pv(\delta)>1+v(\delta)$ (the latter because $(p-1)v(\delta)>1$); hence
$$v(\beta_0^p-1)=1+v(\delta).$$
In general the same expansion only gives
$$v(\beta_0^p-1)\geq\min\big(1+v(\delta),\,pv(\delta)\big).$$
We use this to find some $n$ with $v(\delta_n)>\frac1{p-1}$.
Suppose $v(\delta_n)\leq\frac1{p-1}$ for some $n$.
Since $p\geq 2$ we have $\frac1{p-1}\leq 1<1+v(\delta_n)$, so if the minimum above
is attained by the first term then already $v(\delta_{n+1})>\frac1{p-1}$;
otherwise $v(\delta_{n+1})\geq p\,v(\delta_n)$.
Hence, as long as the valuations stay $\leq\frac1{p-1}$, they are multiplied by
at least $p$ at each step, so after finitely many steps they exceed
$\frac1{p-1}$. Therefore there is $n_\alpha$ with
$t:=v(\delta_{n_\alpha})>\frac1{p-1}$.
By the displayed formula and induction, $v(\delta_n)=(n-n_\alpha)+t$ for all
$n\geq n_\alpha$ (each step increases the valuation, so it stays
$>\frac1{p-1}$). Take $c_\alpha:=t-n_\alpha$.
\end{proof}

\begin{lem}
\label{quotient-by-distinguished}
\uses{weierstrass-division,isom-given-by-weierstrass-division,Lambda-is-UFD,omega-val-growth}
\lean{Polynomial.IsDistinguishedAt.basisQuotientPowerSeries,
Polynomial.IsDistinguishedAt.basisQuotientPowerSeries_apply,
IwasawaAlgebra.card_quotient_span_p_pow_distinguished,
Polynomial.IsDistinguishedAt.finite_quotient_pair_powerSeries,
Polynomial.IsDistinguishedAt.exists_card_quotient_pair_powerSeries}
Let $F\in\BZ_p[T]$ be a distinguished polynomial of degree $d$.

{\rm(i)} $\Lambda/(F)$ is a free $\BZ_p$-module with basis
$1,T,\cdots,T^{d-1}$.

{\rm(ii)} For every $m\geq 1$ we have $\ord_p\#\big(\Lambda/(p^m,F)\big)=md$.

{\rm(iii)} Assume $d\geq 1$ and let $g\in\Lambda$ have no irreducible factor in
common with $F$. Then $\Lambda/(F,g)$ is finite and
$$\ord_p\#\big(\Lambda/(F,g)\big)=\sum_{\alpha}v\big(g(\alpha)\big),$$
where $\alpha$ runs over the $d$ roots of $F$ in $\ov\BQ_p$, counted with
multiplicity (note that $v(\alpha)>0$ by Lemma \ref{omega-val-growth}(i), so
$g(\alpha)$ converges).
\end{lem}

\begin{proof}
(i) By the Weierstrass division (Proposition \ref{weierstrass-division}) applied
to $A=\BZ_p$, every $f\in\Lambda$ can be written uniquely as $f=Fq+r$ with
$q\in\Lambda$ and $r\in\BZ_p[T]$ of degree $\leq d-1$.

(ii) Immediate from (i): $\Lambda/(p^m,F)\cong(\BZ/p^m\BZ)^d$.

(iii) Multiplication by $g$ on $\Lambda/(F)$ is injective: if $gh\in(F)$ then
$F\mid gh$, and since $\Lambda$ is a UFD (Corollary \ref{Lambda-is-UFD}) and $F$
and $g$ have no common irreducible factor, $F\mid h$.
Under the identification of (i), multiplication by $g$ is an injective
$\BZ_p$-linear endomorphism $u$ of $\BZ_p^d$, and by the theory of elementary
divisors $\#\coker(u)=p^{v(\det u)}$, i.e.
$\ord_p\#(\Lambda/(F,g))=v(\det u)$; in particular $\Lambda/(F,g)$ is finite.
By Weierstrass division write $g=Fq+G$ with $G\in\BZ_p[T]$ of degree $\leq d-1$;
then $u$ is multiplication by $G$ on
$\Lambda/(F)\cong\BZ_p[T]/(F)$ (Corollary \ref{isom-given-by-weierstrass-division}),
and $g(\alpha)=G(\alpha)$ for every root $\alpha$ of $F$.
Determinants are unchanged by the flat base change
$\BZ_p\to\ov\BQ_p$, so $\det u$ is the determinant of multiplication by $G$ on
$\ov\BQ_p[T]/(F)$. Writing $F=\prod_{k=1}^d(T-\alpha_k)$ and filtering
$\ov\BQ_p[T]/(F)$ by the ideals generated by
$(T-\alpha_1)\cdots(T-\alpha_j)$, whose successive quotients are
one-dimensional with multiplication by $G$ acting as $G(\alpha_j)$, we get
$\det u=\prod_{k=1}^dG(\alpha_k)=\prod_{k=1}^dg(\alpha_k)$, whence the formula.
\end{proof}

\begin{lem}
\label{euler-char-lemma}
\uses{pseudo-null,pseudo-null-criterion}
\lean{Module.chi,
Module.chi_eq_zero_of_finite,
Module.finite_torsionBy_middle,
Module.finite_quotSMulTop_middle,
Module.finite_torsionBy_left,
Module.finite_quotSMulTop_left,
Module.finite_torsionBy_right,
Module.finite_quotSMulTop_right,
Module.chi_eq_add_of_exact,
Module.finite_torsionBy_of_finite_ker_of_finite_coker,
Module.finite_quotSMulTop_of_finite_ker_of_finite_coker,
Module.chi_eq_of_finite_ker_of_finite_coker}
\leanok
For $g\in\Lambda$ and a $\Lambda$-module $M$ put
$M[g]:=\{x\in M\mid gx=0\}$, and, when $M[g]$ and $M/gM$ are both finite,
$$\chi_g(M):=\ord_p\#(M/gM)-\ord_p\#(M[g]).$$

{\rm(i)} If $M$ is finite, then $M[g]$ and $M/gM$ are finite and $\chi_g(M)=0$.

{\rm(ii)} Let $0\to A\to B\to C\to 0$ be an exact sequence of $\Lambda$-modules.
If for two of the three modules $M\in\{A,B,C\}$ both $M[g]$ and $M/gM$ are
finite, then this also holds for the third one, and
$\chi_g(B)=\chi_g(A)+\chi_g(C)$.

{\rm(iii)} If $\varphi:M\to N$ is a $\Lambda$-module homomorphism with finite
kernel and finite cokernel, and if $N[g]$ and $N/gN$ are finite, then $M[g]$ and
$M/gM$ are finite and $\chi_g(M)=\chi_g(N)$.
\end{lem}

\begin{proof}
\leanok
(i) The sequence $0\to M[g]\to M\xrightarrow{\times g}M\to M/gM\to 0$ is exact,
and $M$ is finite, so $\#M[g]=\#(M/gM)$.

(ii) The snake lemma applied to multiplication by $g$ on the given short exact
sequence yields the exact sequence
$$0\to A[g]\to B[g]\to C[g]\to A/gA\to B/gB\to C/gC\to 0 .$$
If the data for $A$ and $C$ are finite, then $B[g]$ is an extension of a subgroup
of $C[g]$ by $A[g]$ and $B/gB$ is an extension of a subgroup of $C/gC$ by a
quotient of $A/gA$, so they are finite.
If the data for $B$ and $C$ are finite, then $A[g]\subset B[g]$ is finite and
$A/gA$ is an extension of a subgroup of $B/gB$ by a quotient of $C[g]$, so it is
finite. If the data for $A$ and $B$ are finite, then $C[g]$ is an extension of a
subgroup of $A/gA$ by a quotient of $B[g]$ and $C/gC$ is a quotient of $B/gB$.
In all cases the six terms are finite, and the alternating sum of
$\ord_p\#(-)$ along an exact sequence of finite abelian groups vanishes, which is
exactly $\chi_g(B)=\chi_g(A)+\chi_g(C)$.

(iii) Let $K:=\ker\varphi$, $M':=\varphi(M)$ and $C:=N/M'$; by assumption $K$ and
$C$ are finite.
Apply (ii) to $0\to M'\to N\to C\to 0$: the data for $N$ and $C$ are finite, so
those for $M'$ are, and $\chi_g(M')=\chi_g(N)-\chi_g(C)=\chi_g(N)$ by (i).
Apply (ii) to $0\to K\to M\to M'\to 0$: the data for $K$ and $M'$ are finite, so
those for $M$ are, and $\chi_g(M)=\chi_g(K)+\chi_g(M')=\chi_g(M')$ by (i).
\end{proof}

\begin{prop}
\label{growth-general}
\uses{Lambda-module-structure,iwasawa-mod-invariants,pseudo-null-criterion,quotient-by-distinguished,euler-char-lemma,Lambda-is-UFD,omega-val-growth}
\lean{IwasawaAlgebra.exists_factorization_card_quotSMulTop_eq}
\leanok
Let $X$ be a finitely generated torsion $\Lambda$-module and let
$(g_n)_{n\geq n_0}$ be a sequence of distinguished polynomials in $\BZ_p[T]$ such
that
\begin{itemize}
\item[(a)] $g_n\mid g_{n+1}$ in $\BZ_p[T]$ for all $n\geq n_0$;
\item[(b)] $\deg g_n=p^n+b$ for some constant $b\in\BZ$ independent of $n$;
\item[(c)] for every $\alpha\in\ov\BQ_p$ with $v(\alpha)>0$ and
$g_n(\alpha)\neq 0$ for all $n\geq n_0$, there are $c_\alpha\in\BQ$ and
$n_\alpha\geq n_0$ with $v(g_n(\alpha))=n+c_\alpha$ for all $n\geq n_\alpha$;
\item[(d)] $X/g_nX$ is finite for all sufficiently large $n$.
\end{itemize}
Then there is an integer $\nu$ such that
$$\ord_p\#(X/g_nX)=\mu(X)p^n+\lambda(X)n+\nu$$
for all sufficiently large $n$.
\end{prop}

\begin{proof}
\leanok
By Proposition \ref{Lambda-module-structure} choose a pseudo-isomorphism
$\varphi:X\to E:=\bigoplus_{i=1}^m\Lambda/(f_i^{b_i})
\oplus\bigoplus_{j=1}^s\Lambda/(p^{n_j})$; by
Proposition \ref{pseudo-null-criterion}(ii) its kernel $K$ and cokernel $C$ are
finite. Let $N\geq n_0$ be such that $X/g_nX$ is finite for all $n\geq N$.

\emph{Step 1: for $n\geq N$, $E/g_nE$ is finite, no $f_i$ divides $g_n$, and
$E[g_n]=0$.}
The exact sequence
$\varphi(X)/g_n\varphi(X)\to E/g_nE\to C/g_nC\to 0$, together with the fact that
$\varphi(X)/g_n\varphi(X)$ is a quotient of $X/g_nX$ and that $C$ is finite,
shows that $E/g_nE$ is finite.
If $f_i\mid g_n$ for some $i$ and some $n\geq N$, then $\Lambda/(f_i^{b_i},g_n)$
surjects onto $\Lambda/(f_i)$, which is a free $\BZ_p$-module of rank
$\deg f_i\geq 1$ by Lemma \ref{quotient-by-distinguished}(i), hence infinite;
this contradicts the finiteness of $E/g_nE$.
Consequently $\Lambda$ being a UFD (Corollary \ref{Lambda-is-UFD}) and $f_i$
being irreducible, $f_i^{b_i}$ and $g_n$ have no common irreducible factor, so
multiplication by $g_n$ is injective on $\Lambda/(f_i^{b_i})$.
It is also injective on $\Lambda/(p^{n_j})$: if $g_nh\in(p^{n_j})$ and
$h\notin(p^{n_j})$, write $h=p^kh'$ with $k<n_j$ and $h'\notin(p)$; then
$g_nh'\in(p)$, contradicting that $\Lambda/(p)=\BF_p[[T]]$ is a domain and that
$g_n\notin(p)$ ($g_n$ is monic). Hence $E[g_n]=0$.

\emph{Step 2: $\ord_p\#(X/g_nX)=\ord_p\#(E/g_nE)+\ord_p\#(K[g_n])$ for
$n\geq N$.}
By Lemma \ref{euler-char-lemma}(iii),
$\chi_{g_n}(X)=\chi_{g_n}(E)=\ord_p\#(E/g_nE)$, using $E[g_n]=0$.
Moreover $X[g_n]=K[g_n]$: the inclusion $\supset$ is clear, and if $g_nx=0$ then
$g_n\varphi(x)=0$, so $\varphi(x)\in E[g_n]=0$ and $x\in K$.
This gives the assertion.
Furthermore, $g_n\mid g_{n+1}$ implies $K[g_n]\subset K[g_{n+1}]$, an increasing
chain of subgroups of the finite group $K$; hence there are $N_1\geq N$ and a
constant $c_1$ with $\ord_p\#K[g_n]=c_1$ for all $n\geq N_1$.

\emph{Step 3: computation of $\ord_p\#(E/g_nE)$.}
We have
$$\ord_p\#(E/g_nE)=\sum_{j=1}^s\ord_p\#\big(\Lambda/(p^{n_j},g_n)\big)
+\sum_{i=1}^m\ord_p\#\big(\Lambda/(f_i^{b_i},g_n)\big).$$
By Lemma \ref{quotient-by-distinguished}(ii) and hypothesis (b), the first sum
equals $\sum_jn_j\,(p^n+b)=\mu(X)p^n+b\,\mu(X)$.

For the second sum, fix $i$ and let $\alpha$ be a root of $f_i^{b_i}$, i.e.~a root
of $f_i$; then $v(\alpha)>0$ by Lemma \ref{omega-val-growth}(i).
We claim $g_n(\alpha)\neq 0$ for all $n\geq n_0$.
Indeed $f_i$ is irreducible in $\Lambda$; as in Step 5 of the proof of
Corollary \ref{Lambda-is-UFD}, it is then irreducible in $\BZ_p[T]$, hence
(being monic) irreducible in $\BQ_p[T]$ by Gauss's lemma.
If $g_n(\alpha)=0$ then $f_i$, the minimal polynomial of $\alpha$ up to a
constant, divides $g_n$ in $\BQ_p[T]$, hence in $\BZ_p[T]$ since both are monic;
for $n\geq N$ this contradicts Step 1, and for $n<N$ it contradicts Step 1
together with $g_n\mid g_N$.
By hypothesis (c) there are $c_\alpha$ and $n_\alpha$ with
$v(g_n(\alpha))=n+c_\alpha$ for $n\geq n_\alpha$.
By Lemma \ref{quotient-by-distinguished}(iii),
$\ord_p\#(\Lambda/(f_i^{b_i},g_n))=\sum_\alpha v(g_n(\alpha))$, the sum being over
the $b_i\deg f_i$ roots of $f_i^{b_i}$ counted with multiplicity.
Summing over $i$ and taking $n$ larger than all the $n_\alpha$, we obtain
$$\sum_{i=1}^m\ord_p\#\big(\Lambda/(f_i^{b_i},g_n)\big)
=\Big(\sum_{i=1}^mb_i\deg f_i\Big)n+c_2=\lambda(X)\,n+c_2$$
with $c_2:=\sum_\alpha c_\alpha$ independent of $n$.

Combining Steps 2 and 3, for all sufficiently large $n$,
$$\ord_p\#(X/g_nX)=\mu(X)p^n+\lambda(X)n+\nu,\qquad
\nu:=b\,\mu(X)+c_2+c_1,$$
and $\nu$ is an integer because all the other terms are.
\end{proof}

\begin{remark}
The {\Lean} statement
\texttt{IwasawaAlgebra.exists\_factorization\_card\_quotSMulTop\_eq} allows real
constants $c_\alpha$ in (c) and requires (d) for all $n\geq n_0$. Neither is a
loss of generality. Real constants make (c) a weaker hypothesis. If (d) holds
for $n\geq N$, replace $n_0$ by $\max(n_0,N)$: (a) and (b) persist, and so does
(c), because by (a), $g_n(\alpha)\neq0$ for all $n\geq\max(n_0,N)$ forces
$g_n(\alpha)\neq0$ for all $n\geq n_0$.
\end{remark}

\begin{lem}
\label{finite-quotient-implies-torsion}
\uses{krull-principal-ideal-thm,Lambda-is-reg-of-dim-2}
Let $X$ be a finitely generated $\Lambda$-module and let $g\in\fm=(p,T)$ be such
that $X/gX$ is finite. Then $X$ is a torsion $\Lambda$-module.
\end{lem}

\begin{proof}
If $X=gX$ then $X=0$ by Nakayama's lemma and there is nothing to prove, so we may
assume $X/gX\neq 0$.
Let $\fa:=\Ann_\Lambda(X)$ and $R:=\Lambda/\fa$, a Noetherian local ring with
maximal ideal $\fm_R=\fm/\fa$.
Since $X$ is finitely generated, $\Supp(X/gX)=V(\fa+(g))$, and $X/gX$ is finite,
so $\Supp(X/gX)\subset\{\fm\}$; hence $\fm_R$ is a minimal prime over-ideal of
the principal ideal $(g)R$.
By Krull's Hauptidealsatz (Theorem \ref{krull-principal-ideal-thm}),
$\dim R=\height(\fm_R)\leq 1$.
Since $\Lambda$ is a domain of Krull dimension $2$
(Proposition \ref{Lambda-is-reg-of-dim-2}), this forces $\fa\neq 0$.
A nonzero element of $\fa$ annihilates $X$, so $X$ is $\Lambda$-torsion.
\end{proof}

We now turn to the growth of the $\BZ_p$-rank of the quotients $X/FX$, where
$F$ is a distinguished polynomial; the case $F=\omega_n$ is
Lemma \ref{p:rank-growth} below.
For a $\Lambda$-module $M$ and $g\in\Lambda$ we keep writing
$M[g]:=\{x\in M\mid gx=0\}$.
Recall that for a finitely generated $\BZ_p$-module $N$ we put
$\rank_{\BZ_p}N:=\dim_{\BQ_p}(N\otimes_{\BZ_p}\BQ_p)$; it is additive on short
exact sequences and vanishes exactly on the finite ones.
Consequently the alternating sum of the $\BZ_p$-ranks along \emph{any} exact
sequence $0\to N_1\to\cdots\to N_k\to 0$ of finitely generated $\BZ_p$-modules
vanishes (break it into short exact sequences).

\begin{lem}
\label{rank-euler-char}
\uses{quotient-by-distinguished}
\lean{Module.rho,
Module.Finite.quotSMulTop,
Module.Finite.torsionBy,
Polynomial.IsDistinguishedAt.finite_quotient_powerSeries,
Module.finrank_eq_zero_of_finite,
Module.rho_eq_zero_of_finite,
Module.rho_eq_add_of_exact,
Module.finrank_torsionBy_eq_of_finite_ker_of_finite_coker,
Module.finrank_quotSMulTop_eq_of_finite_ker_of_finite_coker,
Module.rho_eq_of_finite_ker_of_finite_coker,
IwasawaAlgebra.subsingleton_torsionBy_of_free,
IwasawaAlgebra.finrank_quotSMulTop_of_free,
Polynomial.IsDistinguishedAt.free_quotient_powerSeries,
Polynomial.IsDistinguishedAt.finrank_quotient_powerSeries}
\leanok
Let $F\in\BZ_p[T]$ be a distinguished polynomial of degree $d$ and let $M$ be a
finitely generated $\Lambda$-module.

{\rm(i)} $M/FM$ and $M[F]$ are finitely generated $\BZ_p$-modules; we may thus
define
$$\rho_F(M):=\rank_{\BZ_p}(M/FM)-\rank_{\BZ_p}(M[F])\in\BZ.$$

{\rm(ii)} If $M$ is finite, then $\rank_{\BZ_p}(M/FM)=\rank_{\BZ_p}(M[F])=0$;
in particular $\rho_F(M)=0$.

{\rm(iii)} If $0\to A\to B\to C\to 0$ is an exact sequence of finitely generated
$\Lambda$-modules, then $\rho_F(B)=\rho_F(A)+\rho_F(C)$.

{\rm(iv)} If $\varphi:M\to N$ is a homomorphism of finitely generated
$\Lambda$-modules with finite kernel and finite cokernel, then
$\rank_{\BZ_p}(M/FM)=\rank_{\BZ_p}(N/FN)$ and
$\rank_{\BZ_p}(M[F])=\rank_{\BZ_p}(N[F])$; in particular
$\rho_F(M)=\rho_F(N)$.

{\rm(v)} $\Lambda[F]=0$ and $\Lambda/F\Lambda$ is $\BZ_p$-free of rank $d$; hence
$\rho_F(\Lambda)=d$ and, more generally, $\rho_F(\Lambda^r)=rd$ and
$\Lambda^r[F]=0$ for $r\geq 0$.
\end{lem}

\begin{proof}
\leanok
(i) By Lemma \ref{quotient-by-distinguished}(i) the ring $\Lambda/(F)$ is a free
$\BZ_p$-module of rank $d$.
Now $M/FM$ is a finitely generated module over $\Lambda/(F)$, hence a finitely
generated $\BZ_p$-module.
Since $\Lambda$ is Noetherian and $M$ is finitely generated, the submodule $M[F]$
is a finitely generated $\Lambda$-module; it is killed by $F$, hence is a
finitely generated $\Lambda/(F)$-module, hence a finitely generated
$\BZ_p$-module.

(ii) $M[F]$ is a submodule and $M/FM$ a quotient of the finite module $M$, so
both are finite, and finite $\BZ_p$-modules have rank $0$.

(iii) The snake lemma applied to multiplication by $F$ on the given short exact
sequence yields the exact sequence
$$0\to A[F]\to B[F]\to C[F]\to A/FA\to B/FB\to C/FC\to 0$$
of finitely generated $\BZ_p$-modules (finitely generated by (i)).
The alternating sum of the $\BZ_p$-ranks along it vanishes, which is precisely
$\rho_F(B)=\rho_F(A)+\rho_F(C)$.

(iv) Put $K:=\ker\varphi$, $M':=\varphi(M)$ and $C:=\coker\varphi=N/M'$; by
hypothesis $K$ and $C$ are finite, and $M'$ is finitely generated.
The snake lemma applied to $0\to K\to M\to M'\to 0$ gives the exact sequence
$$0\to K[F]\to M[F]\to M'[F]\to K/FK\to M/FM\to M'/FM'\to 0 .$$
Here $K[F]$ and $K/FK$ are finite.
Hence $M[F]\to M'[F]$ has finite kernel and its cokernel embeds into $K/FK$, so
$\rank_{\BZ_p}M[F]=\rank_{\BZ_p}M'[F]$; and $M/FM\to M'/FM'$ is surjective with
kernel a quotient of $K/FK$, so $\rank_{\BZ_p}(M/FM)=\rank_{\BZ_p}(M'/FM')$.
The snake lemma applied to $0\to M'\to N\to C\to 0$ gives
$$0\to M'[F]\to N[F]\to C[F]\to M'/FM'\to N/FN\to C/FC\to 0 ,$$
where $C[F]$ and $C/FC$ are finite; as before this gives
$\rank_{\BZ_p}M'[F]=\rank_{\BZ_p}N[F]$ and
$\rank_{\BZ_p}(M'/FM')=\rank_{\BZ_p}(N/FN)$.
Combining the two chains of equalities proves (iv).

(v) $\Lambda$ is a domain and $F\neq 0$ (it is monic), so $\Lambda[F]=0$; and
$\Lambda/F\Lambda$ is $\BZ_p$-free of rank $d$ by
Lemma \ref{quotient-by-distinguished}(i).
The statement for $\Lambda^r$ follows since $(-)/F(-)$ and $(-)[F]$ commute with
finite direct sums.
\end{proof}

\begin{lem}
\label{torsion-rank-bounded}
\uses{Lambda-module-structure,pseudo-null-criterion,quotient-by-distinguished,rank-euler-char,iwasawa-mod-invariants,Lambda-is-reg-of-dim-2}
\lean{IwasawaAlgebra.exists_bound_of_isTorsion}
Let $X$ be a finitely generated \emph{torsion} $\Lambda$-module and let
$F\in\BZ_p[T]$ be a distinguished polynomial. Then
$$\rank_{\BZ_p}(X/FX)\leq\lambda(X)\qquad\text{and}\qquad
\rank_{\BZ_p}(X[F])\leq\lambda(X).$$
In particular both ranks, and hence $|\rho_F(X)|$, are bounded by a constant
depending only on $X$ and not on $F$.
\end{lem}

\begin{proof}
By Proposition \ref{Lambda-module-structure} there is a pseudo-isomorphism
$$\varphi:X\longrightarrow
E:=\bigoplus_{i=1}^m\Lambda/(f_i^{b_i})\oplus\bigoplus_{j=1}^s\Lambda/(p^{n_j})$$
with the $f_i$ irreducible distinguished polynomials; by
Proposition \ref{pseudo-null-criterion}(ii) (applicable since, by
Proposition \ref{Lambda-is-reg-of-dim-2}, $\Lambda$ is local of Krull dimension
$2$ with finite residue field $\BF_p$) the kernel and the cokernel of $\varphi$
are finite.
By Lemma \ref{rank-euler-char}(iv) it therefore suffices to prove the two
inequalities for $E$ in place of $X$; and since $(-)/F(-)$ and $(-)[F]$ commute
with finite direct sums, it suffices to bound each summand.

\emph{The summands $\Lambda/(p^{n_j})$ contribute $0$.}
The module $M:=\Lambda/(p^{n_j})$ is a finitely generated $\Lambda$-module, so by
Lemma \ref{rank-euler-char}(i) both $M/FM$ and $M[F]$ are finitely generated
$\BZ_p$-modules; they are killed by $p^{n_j}$, hence finite, hence of rank $0$.
(Alternatively, $M/FM=\Lambda/(p^{n_j},F)$ is finite by
Lemma \ref{quotient-by-distinguished}(ii).)

\emph{The summand $\Lambda/(f_i^{b_i})$ contributes at most $d_i:=b_i\deg f_i$.}
A product of distinguished polynomials is distinguished (reduce modulo $p$), so
$f_i^{b_i}$ is distinguished of degree $d_i$, and by
Lemma \ref{quotient-by-distinguished}(i) the module $M_i:=\Lambda/(f_i^{b_i})$ is
a free $\BZ_p$-module of rank $d_i$.
Hence $M_i/FM_i$, being a quotient of $M_i$, has $\BZ_p$-rank $\leq d_i$, and
$M_i[F]$, being a $\BZ_p$-submodule of $M_i$, has $\BZ_p$-rank $\leq d_i$.

Summing over the summands and using
$\lambda(X)=\sum_{i=1}^mb_i\deg f_i=\sum_id_i$
(Definition \ref{iwasawa-mod-invariants}) gives both inequalities.
Finally $|\rho_F(X)|\leq\max\big(\rank_{\BZ_p}(X/FX),\rank_{\BZ_p}(X[F])\big)
\leq\lambda(X)$, since $\rho_F(X)$ is the difference of two non-negative
integers each $\leq\lambda(X)$.
\end{proof}

\begin{remark}
The {\Lean} declaration \texttt{IwasawaAlgebra.exists\_bound\_of\_isTorsion}
formalizes only the last sentence of the statement. It gives a constant $c$,
depending only on $X$, with $\rank_{\BZ_p}(X/FX)\leq c$ and
$\rank_{\BZ_p}(X[F])\leq c$ for every distinguished polynomial $F$. Its proof
takes $c=\sum_ib_i\deg f_i$, but the identification $c=\lambda(X)$ is not
stated. This uniform bound is the form used in Lemma \ref{p:rank-growth}.
\end{remark}

\begin{lem}
\label{free-submodule-full-rank}
\lean{Module.exists_free_submodule_isTorsion_quotient}
\leanok
Let $X$ be a finitely generated $\Lambda$-module and let
$$r:=\rank_\Lambda X:=\dim_{\Frac\Lambda}\big(X\otimes_\Lambda\Frac\Lambda\big).$$
Then there is a free $\Lambda$-submodule $L\subset X$ of rank $r$ such that
$X/L$ is a finitely generated torsion $\Lambda$-module.
\end{lem}

\begin{proof}
\leanok
Write $\CK:=\Frac\Lambda=S^{-1}\Lambda$ with $S:=\Lambda\setminus\{0\}$; note
$X\otimes_\Lambda\CK=S^{-1}X$.
The images of a finite generating set of $X$ span the $\CK$-vector space
$S^{-1}X$, so we may choose $x_1,\cdots,x_r\in X$ whose images in $S^{-1}X$ form
a $\CK$-basis.
They are $\Lambda$-linearly independent: a relation $\sum_ia_ix_i=0$ with
$a_i\in\Lambda$ maps to the relation $\sum_i(a_i/1)(x_i/1)=0$ in $S^{-1}X$,
whence $a_i/1=0$ in $\CK$ and $a_i=0$ ($\Lambda$ is a domain).
So $L:=\sum_{i=1}^r\Lambda x_i$ is free of rank $r$.
Put $Q:=X/L$, a finitely generated $\Lambda$-module.
Localization is exact, so $S^{-1}Q=S^{-1}X/S^{-1}L=0$ because the $x_i/1$ span
$S^{-1}X$.
As $Q$ is generated by finitely many elements $q_1,\cdots,q_k$ and $q_l/1=0$ in
$S^{-1}Q$, there are $s_l\in S$ with $s_lq_l=0$; then $s:=s_1\cdots s_k\in S$ is
a nonzero element of $\Lambda$ annihilating $Q$, i.e.~$Q$ is torsion.
\end{proof}

\begin{remark}
In {\Lean} (\texttt{Module.exists\_free\_submodule\_isTorsion\_quotient}, stated
for an arbitrary commutative domain in place of $\Lambda$) the rank is Mathlib's
\texttt{Module.finrank}. It equals
$\dim_{\Frac\Lambda}(X\otimes_\Lambda\Frac\Lambda)$ by
\texttt{IsBaseChange.finrank\_eq}. There $L$ is spanned by a linearly
independent family of cardinality $r$, and $X/L$ is torsion because its rank is
$\rank_\Lambda X-\rank_\Lambda L=0$.
\end{remark}

\begin{lem}\label{p:rank-growth}
\uses{Lambda-module-structure,rank-euler-char,torsion-rank-bounded,free-submodule-full-rank,nu-distinguished}
\lean{IwasawaAlgebra.exists_bound_finrank_quotSMulTop_omega,
IwasawaAlgebra.exists_bound_finrank_quotSMulTop}
\leanok
Suppose $X$ is a finitely generated $\Lambda$-module
of rank $r$,
then we have
$$
\rank_{\BZ_p}\left(X/(\gamma^{p^n}-1)X\right)=rp^n+O(1)
$$
as $n\to\infty$.
\end{lem}

For example, if $X=\Lambda$, then $r=1$,
and $\rank_{\BZ_p}\big(X/(\gamma^{p^n}-1)X\big)=p^n$.

\begin{proof}
\leanok
Here $r=\rank_\Lambda X=\dim_{\Frac\Lambda}(X\otimes_\Lambda\Frac\Lambda)$ as in
Lemma \ref{free-submodule-full-rank}, and we show the sharper statement: there is
a constant $c\geq 0$, depending only on $X$, with
$$\big|\rank_{\BZ_p}(X/\omega_nX)-rp^n\big|\leq c\qquad\text{for all }n\geq 0 .$$

Recall from Lemma \ref{nu-distinguished}(i) that $\omega_n=\gamma^{p^n}-1$ is a
distinguished polynomial of degree $p^n$, so
Lemma \ref{rank-euler-char} applies to $F=\omega_n$, and we abbreviate
$\rho_n:=\rho_{\omega_n}$.

\emph{Step 1: two auxiliary torsion modules.}
Let $X_{\mathrm{tor}}\subset X$ be the $\Lambda$-torsion submodule; it is
finitely generated because $\Lambda$ is Noetherian and $X$ is finitely generated.
By Lemma \ref{free-submodule-full-rank} choose a free submodule $L\subset X$ of
rank $r$ with $Q:=X/L$ a finitely generated torsion $\Lambda$-module.

\emph{Step 2: the Euler characteristic identity.}
Apply Lemma \ref{rank-euler-char}(iii) to $0\to L\to X\to Q\to 0$ and then
Lemma \ref{rank-euler-char}(v) with $d=\deg\omega_n=p^n$:
$$\rho_n(X)=\rho_n(L)+\rho_n(Q)=rp^n+\rho_n(Q).$$
By the definition of $\rho_n$ this reads
$$\rank_{\BZ_p}(X/\omega_nX)=rp^n+\rho_n(Q)+\rank_{\BZ_p}(X[\omega_n]).$$

\emph{Step 3: the two error terms are bounded.}
First, $X[\omega_n]=X_{\mathrm{tor}}[\omega_n]$: indeed $\omega_n\neq 0$, so any
$x$ with $\omega_nx=0$ is a torsion element; the reverse inclusion is trivial.
By Lemma \ref{torsion-rank-bounded} applied to the finitely generated torsion
module $X_{\mathrm{tor}}$ and to $F=\omega_n$,
$$0\leq\rank_{\BZ_p}(X[\omega_n])=\rank_{\BZ_p}(X_{\mathrm{tor}}[\omega_n])
\leq\lambda(X_{\mathrm{tor}}).$$
Second, by Lemma \ref{torsion-rank-bounded} applied to $Q$ and $F=\omega_n$,
$$|\rho_n(Q)|\leq\lambda(Q).$$
Both bounds are independent of $n$.

Combining Steps 2 and 3 gives the claim with
$c:=\lambda(X_{\mathrm{tor}})+\lambda(Q)$.
In particular, for $X=\Lambda$ we have $r=1$, $X_{\mathrm{tor}}=0$, $L=X$,
$Q=0$, and the identity of Step 2 reads
$\rank_{\BZ_p}(\Lambda/\omega_n\Lambda)=p^n$ exactly, as asserted after the
statement.
\end{proof}

\begin{remark}
{\Lean} proves the sharper bound $|\rank_{\BZ_p}(X/FX)-r\deg F|\leq c$ for every
distinguished polynomial $F$
(\texttt{IwasawaAlgebra.exists\_bound\_finrank\_quotSMulTop}). Its proof does
not use $X_{\mathrm{tor}}$. Since $L[F]=0$, the snake sequence of $0\to L\to
X\to Q\to0$ bounds both error terms by $\rank_{\BZ_p}(Q[F])$ and
$\rank_{\BZ_p}(Q/FQ)$, so only the constant of Lemma \ref{torsion-rank-bounded}
for $Q$ is needed.
\end{remark}

\begin{prop}
\label{coinvariant-growth}
\uses{p:rank-growth,iwasawa-mod-invariants-2,growth-general,finite-quotient-implies-torsion,nu-distinguished,omega-val-growth}
\lean{IwasawaAlgebra.exists_factorization_card_quotSMulTop_omega}
\leanok
If $X$ is a finitely generated
$\Lambda$-module such that $X/(\gamma^{p^n}-1)X$ is finite
for all sufficiently large $n$,
then $X$ is $\Lambda$-torsion, and
there exists some integer $\nu$
such that for all sufficiently large $n$,
$$
\ord_p(\#(X/(\gamma^{p^n}-1)X))=\mu(X)p^n
+\lambda(X)n+\nu.
$$
\end{prop}

\begin{proof}
\leanok
Put $g_n:=\omega_n=\gamma^{p^n}-1$ and pick $N$ with $X/g_nX$ finite for $n\geq N$.
Since $\omega_N\in\fm$, Lemma \ref{finite-quotient-implies-torsion} shows that $X$
is a torsion $\Lambda$-module.

We check the hypotheses of Proposition \ref{growth-general} for the sequence
$(\omega_n)_{n\geq 0}$.
Hypothesis (a) and (b) (with $b=0$) hold by Lemma \ref{nu-distinguished}(i).
For (c), let $\alpha\in\ov\BQ_p$ with $v(\alpha)>0$ and $\omega_n(\alpha)\neq 0$
for all $n$, i.e.~$(1+\alpha)^{p^n}\neq 1$ for all $n$; then
Lemma \ref{omega-val-growth}(ii) gives exactly the required
$v(\omega_n(\alpha))=n+c_\alpha$ for $n\gg 0$.
Hypothesis (d) is the assumption.
Proposition \ref{growth-general} now gives the assertion.
\end{proof}

\begin{remark}
The {\Lean} proof deduces that $X$ is $\Lambda$-torsion from Lemma
\ref{p:rank-growth} rather than from Lemma \ref{finite-quotient-implies-torsion}
(\texttt{IwasawaAlgebra.isTorsion\_of\_finite\_quotSMulTop\_omega}). If
$r=\rank_\Lambda X>0$, then $\rank_{\BZ_p}(X/\omega_nX)\geq rp^n-c>0$ for large
$n$, contradicting the finiteness of $X/\omega_nX$. Hence $r=0$, and $X$ is
torsion by Lemma \ref{free-submodule-full-rank}.
\end{remark}

\begin{prop}[\cite{Was97}, Proposition 13.19]
\label{coinvariant-growth-2}
\uses{p:rank-growth,iwasawa-mod-invariants-2}
\lean{IwasawaAlgebra.exists_factorization_card_quotSMulTop_nu}
\leanok
Let $e\geq 0$ be an integer.
If $X$ is a finitely generated
$\Lambda$-module such that $X/\nu_{n,e}X$ is finite
for all sufficiently large $n\geq e$, where
$$
\nu_{n,e}:=\sum_{k=0}^{p^{n-e}-1}\gamma^{kp^e},
$$
then $X$ is $\Lambda$-torsion, and
there exists some integer $\nu$
such that for all sufficiently large $n$,
$$
\ord_p(\#(X/\nu_{n,e}X))=\mu(X)p^n
+\lambda(X)n+\nu.
$$
\end{prop}

\begin{proof}
\leanok
\uses{growth-general,finite-quotient-implies-torsion,nu-distinguished,omega-val-growth}
Put $g_n:=\nu_{n,e}$ for $n\geq e$ and pick $N>e$ with $X/g_nX$ finite for
$n\geq N$ (possible, since the hypothesis holds for all sufficiently large $n$).
Since $\nu_{N,e}$ is a distinguished polynomial of degree $p^N-p^e\geq 1$
(Lemma \ref{nu-distinguished}(ii)), we have $\nu_{N,e}\in\fm=(p,T)$;
hence $X$ is a torsion $\Lambda$-module by
Lemma \ref{finite-quotient-implies-torsion}.

We check the hypotheses of Proposition \ref{growth-general} for the sequence
$(\nu_{n,e})_{n\geq e}$.
Hypotheses (a) and (b) (with $b=-p^e$) hold by
Lemma \ref{nu-distinguished}(ii),(iii), and (d) is the assumption.

For (c), let $\alpha\in\ov\BQ_p$ with $v(\alpha)>0$ and $\nu_{n,e}(\alpha)\neq 0$
for all $n\geq e$. There are two cases.

If $\omega_e(\alpha)=0$, i.e.~$(1+\alpha)^{p^e}=1$, then
$$\nu_{n,e}(\alpha)=\sum_{k=0}^{p^{n-e}-1}\big((1+\alpha)^{p^e}\big)^k=p^{n-e},$$
so $v(\nu_{n,e}(\alpha))=n-e$ for all $n\geq e$, which is of the required form
with $c_\alpha=-e$.

If $\omega_e(\alpha)\neq 0$, then $\omega_n(\alpha)=\nu_{n,e}(\alpha)\omega_e(\alpha)
\neq 0$ for all $n\geq e$ by Lemma \ref{nu-distinguished}(ii); moreover
$\omega_n(\alpha)\neq0$ for $n<e$ as well, since $\omega_n\mid\omega_e$.
So $(1+\alpha)^{p^n}\neq 1$ for all $n$, and
Lemma \ref{omega-val-growth}(ii) gives
$$v(\nu_{n,e}(\alpha))=v(\omega_n(\alpha))-v(\omega_e(\alpha))
=n+c_\alpha-v(\omega_e(\alpha))$$
for all sufficiently large $n$, again of the required form.

Proposition \ref{growth-general} now gives the assertion.
\end{proof}

\begin{remark}
As for Proposition \ref{coinvariant-growth}, the {\Lean} proof deduces that $X$
is $\Lambda$-torsion from the bound $|\rank_{\BZ_p}(X/FX)-r\deg F|\leq c$
(\texttt{IwasawaAlgebra.exists\_bound\_finrank\_quotSMulTop}, the sharper form
of Lemma \ref{p:rank-growth}). It applies this bound to the distinguished
polynomials $F=\nu_{n,e}$, whose degree $p^n-p^e$ is unbounded
(\texttt{IwasawaAlgebra.isTorsion\_of\_finite\_quotSMulTop}), rather than using
Lemma \ref{finite-quotient-implies-torsion}.
\end{remark}

\begin{lem}
\label{finite-index-submodule-growth}
\uses{coinvariant-growth-2,pseudo-null-criterion,pseudo-null-char-ideal,
iwasawa-mod-invariants,Lambda-module-structure,Lambda-is-reg-of-dim-2}
\lean{IwasawaAlgebra.exists_factorization_card_quotient_smul_submodule}
\leanok
Let $X$ be a finitely generated $\Lambda$-module, let $Y\subset X$ be a
$\Lambda$-submodule of finite index, and let $e\geq 0$.
Assume that $X/\nu_{n,e}Y$ is finite for all sufficiently large $n$.
Then $X$ and $Y$ are finitely generated torsion $\Lambda$-modules with
$\mu(Y)=\mu(X)$ and $\lambda(Y)=\lambda(X)$, and there is an integer $\nu$ such
that
$$\ord_p\#\big(X/\nu_{n,e}Y\big)=\mu(X)p^n+\lambda(X)n+\nu$$
for all sufficiently large $n$.
\end{lem}

\begin{proof}
\leanok
Since $\Lambda$ is Noetherian and $X$ is finitely generated, so is the submodule
$Y$.
For $n\geq e$ we have $\nu_{n,e}Y\subset Y\subset X$, so $Y/\nu_{n,e}Y$ is a
$\Lambda$-submodule of $X/\nu_{n,e}Y$ and hence is finite for all sufficiently
large $n$.
By Proposition \ref{coinvariant-growth-2}, $Y$ is a finitely generated torsion
$\Lambda$-module and there is an integer $\nu_0$ with
$$\ord_p\#\big(Y/\nu_{n,e}Y\big)=\mu(Y)p^n+\lambda(Y)n+\nu_0$$
for all sufficiently large $n$.

\emph{$X$ is torsion.}
Let $0\neq a\in\Lambda$ with $aY=0$, and let $m:=\#(X/Y)$, so that $mX\subset Y$.
Then $ma\neq 0$ in the domain $\Lambda$ and $(ma)X=a(mX)\subset aY=0$.

\emph{$\mu(Y)=\mu(X)$ and $\lambda(Y)=\lambda(X)$.}
The inclusion $\iota:Y\hookrightarrow X$ has zero kernel and cokernel $X/Y$,
which is finite, hence pseudo-null by Proposition
\ref{pseudo-null-criterion}(ii) (applicable because, by Proposition
\ref{Lambda-is-reg-of-dim-2}, $\Lambda$ is local of Krull dimension $2$ with
finite residue field $\BF_p$).
So $\iota$ is a pseudo-isomorphism and
$\chaR_\Lambda(Y)=\chaR_\Lambda(X)$ by
Proposition \ref{pseudo-null-char-ideal}(ii).
By Proposition \ref{Lambda-module-structure} the characteristic ideal of a
finitely generated torsion $\Lambda$-module $M$ is generated by
$p^{\mu(M)}\prod_if_i^{b_i}$ with $\prod_if_i^{b_i}$ distinguished, and
Definition \ref{iwasawa-mod-invariants} identifies $\mu(M)$ and $\lambda(M)$ with
the invariants $\mu$ and $\lambda$ of any generator of $\chaR_\Lambda(M)$
(see the remark following that definition).
Hence equal characteristic ideals force $\mu(Y)=\mu(X)$ and
$\lambda(Y)=\lambda(X)$.

\emph{Conclusion.}
The exact sequence of finite abelian groups
$$0\to Y/\nu_{n,e}Y\to X/\nu_{n,e}Y\to X/Y\to 0$$
gives
$$\ord_p\#\big(X/\nu_{n,e}Y\big)=\ord_p\#\big(Y/\nu_{n,e}Y\big)+\ord_p\#(X/Y)
=\mu(X)p^n+\lambda(X)n+\nu$$
for all sufficiently large $n$, with $\nu:=\nu_0+\ord_p\#(X/Y)$.
\end{proof}

\section{Global class field theory}

The results of this section are the class field theory input used in the
previous sections --- concretely, in Proposition \ref{Xn-isom-An} and hence in
Theorem \ref{clgp-growth}; they are also exactly what the {\Lean} declarations
\texttt{NumberField.IsUnramifiedEverywhere.artinMap},
\texttt{surjective\_artinMap}, \texttt{artinMap\_spec} and
\texttt{bijective\_artinMap\_of\_isSepClosed} assert.
We follow \cite{Neu99}, Chapter VI, and \cite{Mil20}; see also \cite{CF67}.

\emph{Honesty warning.}
Global class field theory is a long theorem.
We give the statement of every step, and a real proof of every step that is not
one of the four genuinely deep inputs, which are
Theorem \ref{local-reciprocity} (local reciprocity),
Theorem \ref{idele-class-H1-vanishes} (the second inequality,
$H^1(G,C_L)=0$),
Theorem \ref{brauer-exact-sequence} (Hasse--Brauer--Noether, i.e.~the exactness
of the sequence of Brauer groups, which uses the analytic first inequality /
Dirichlet density) and
Theorem \ref{existence-theorem} (the existence theorem).
For those four we state the theorem precisely, describe the structure of the
proof, and say plainly that the proof is not supplied here.
Everything else below is proved.

Throughout, $K$ is a number field with ring of integers $\CO_K$.
A \emph{place} $v$ of $K$ is an equivalence class of absolute values; $K_v$ is
the completion, and for $v$ finite $\CO_v\subset K_v$ is the valuation ring,
$\fm_v$ its maximal ideal, $\pi_v$ a uniformizer and $k_v=\CO_v/\fm_v$ the
(finite) residue field.
For a finite extension $L/K$ and a place $w$ of $L$ above $v$ we write $w\mid v$.
We say that $L/K$ is \emph{unramified at $v$} if for one (equivalently, by
Galois conjugacy, every) $w\mid v$ the extension $L_w/K_v$ is unramified, where
for archimedean $v$ this means $L_w=K_v$ (so a real place may not become complex),
and \emph{unramified everywhere} if it is unramified at every place.

\subsection{Ideles and the idele class group}

\begin{definition}
\label{idele-group}
The \emph{idele group} of $K$ is the restricted product
$$J_K:=\Big\{(a_v)_v\in\prod_vK_v^\times\ \Big|\
a_v\in\CO_v^\times\text{ for all but finitely many finite }v\Big\},$$
topologized so that the subgroups
$J_{K,S}:=\prod_{v\in S}K_v^\times\times\prod_{v\notin S}\CO_v^\times$
($S$ a finite set of places containing the archimedean ones) are open and carry
the product topology.
We write
$$U_K:=\prod_{v\nmid\infty}\CO_v^\times\times\prod_{v\mid\infty}K_v^\times
\subset J_K,$$
an open subgroup, the group of \emph{unit ideles}.
For $a\in K^\times$ the family $(a)_v$ lies in $J_K$; this embeds $K^\times$ into
$J_K$ as a discrete subgroup.
The \emph{idele class group} is $C_K:=J_K/K^\times$.
\end{definition}

\begin{prop}
\label{idele-class-group-galois}
Let $L/K$ be a finite Galois extension with group $G$.
Then $G$ acts continuously on $J_L$ and on $C_L$, and
$$J_L^G=J_K,\qquad C_L^G=C_K .$$
Moreover, as a $G$-module,
$$J_L=\bigoplus_{v}\ \prod_{w\mid v}L_w^\times
\quad\text{(restricted product over }v\text{)},\qquad
\prod_{w\mid v}L_w^\times\cong\Ind_{G_w}^G(L_w^\times),$$
where $G_w\subset G$ is the decomposition group of a fixed $w\mid v$.
\end{prop}

\begin{proof}
$G$ permutes the places of $L$ above a given place $v$ of $K$ transitively, and
$\sigma$ maps $L_w$ isomorphically to $L_{\sigma w}$ over $K_v$; hence
$\prod_{w\mid v}L_w^\times$ is the induced module $\Ind_{G_w}^G(L_w^\times)$
(choose coset representatives $\sigma$ of $G/G_w$, so that $w'=\sigma w$ runs
over the places above $v$).
Taking $G$-invariants of an induced module gives the invariants of the inducing
module, so $(\prod_{w\mid v}L_w^\times)^G=(L_w^\times)^{G_w}=K_v^\times$
(local Galois theory), whence $J_L^G=J_K$.
For $C_L$, the exact sequence $1\to L^\times\to J_L\to C_L\to 1$ gives
$$1\to K^\times\to J_K\to C_L^G\to H^1(G,L^\times)$$
and $H^1(G,L^\times)=0$ by Hilbert's Theorem 90, so $C_L^G=J_K/K^\times=C_K$.
\end{proof}

\begin{prop}
\label{idele-class-group-and-class-group}
The map sending an idele $a=(a_v)$ to the fractional ideal
$$(a):=\prod_{v\nmid\infty}\fp_v^{v(a_v)}$$
(a finite product) induces isomorphisms
$$J_K/U_K\xrightarrow{\ \sim\ }I_K\quad\text{(the group of fractional ideals)},
\qquad
J_K/K^\times U_K\xrightarrow{\ \sim\ }\Cl(K),\qquad
C_K/\overline{U_K}\xrightarrow{\ \sim\ }\Cl(K),$$
where $\overline{U_K}$ denotes the image of $U_K$ in $C_K$.
In particular $K^\times U_K$ is an open subgroup of $J_K$ of finite index
$\#\Cl(K)$, and $\overline{U_K}$ is an open subgroup of $C_K$ of finite index
$\#\Cl(K)$.
\end{prop}

\begin{proof}
The map $a\mapsto(a)$ is a surjective homomorphism onto $I_K$, because $I_K$ is
free on the finite places and we may realize any prescribed exponents by an
idele; its kernel is exactly the set of ideles with $v(a_v)=0$ for all finite
$v$, i.e.~$U_K$.
Under it, the image of $K^\times$ is the group of principal fractional ideals, so
the quotient is $\Cl(K)$.
The last isomorphism is the second one divided by $K^\times$.
Openness of $K^\times U_K$ is clear since $U_K$ is open, and $\Cl(K)$ is finite,
which gives the index statement.
\end{proof}

\subsection{Input from local class field theory}

\begin{thm}[Local reciprocity; \cite{Neu99}, Ch.~V]
\label{local-reciprocity}
Let $v$ be a place of $K$.

{\rm(i)} For every finite Galois extension $L_w/K_v$ with group $G_w$ there is a
canonical isomorphism (the \emph{local invariant map})
$$\inv_v:H^2(G_w,L_w^\times)\xrightarrow{\ \sim\ }
\tfrac1{n_w}\BZ/\BZ\subset\BQ/\BZ,\qquad n_w:=[L_w:K_v],$$
compatible with inflation (for $L_w\subset L_w'$) and satisfying
$\inv_v\circ\res=[L_w':L_w]\cdot\inv_v$ for restriction to an open subgroup.
For $v$ archimedean the same holds with $n_w\in\{1,2\}$.

{\rm(ii)} Consequently $(\Gal(\ov{K_v}/K_v),\ov{K_v}^\times)$ is a class
formation, and there is a local reciprocity homomorphism
$$\theta_v:K_v^\times\longrightarrow\Gal(L_w/K_v)$$
for every finite abelian $L_w/K_v$, which is surjective with kernel
$N_{L_w/K_v}L_w^\times$.
\end{thm}

\begin{proof}
Not supplied here. This is local class field theory; see \cite{Neu99},
Ch.~V, \S1--\S3 (the invariant map is built from
$H^2(L_w^{\mathrm{unr}}/K_v,\cdot)\cong\BZ/n\BZ$ via the valuation and the
computation $H^1(G_w,\CO_{L_w}^\times)=0$, $H^2$ of the units vanishing for
unramified extensions), and \cite{Mil20}, Ch.~I.
\end{proof}

\begin{prop}
\label{local-unramified-reciprocity}
\uses{local-reciprocity}
Let $v$ be a finite place and $L_w/K_v$ a finite abelian extension of degree $n$.

{\rm(i)} If $L_w/K_v$ is unramified, then $\theta_v(\pi_v)=\Frob_v$, the
Frobenius of $L_w/K_v$, and
$N_{L_w/K_v}L_w^\times=\pi_v^{n\BZ}\cdot\CO_v^\times$; in particular
$\CO_v^\times\subset N_{L_w/K_v}L_w^\times$, i.e.~$\theta_v(\CO_v^\times)=1$.

{\rm(ii)} Conversely, if $\CO_v^\times\subset N_{L_w/K_v}L_w^\times$ then
$L_w/K_v$ is unramified.

{\rm(iii)} If $v$ is archimedean, then $K_v^\times=N_{L_w/K_v}L_w^\times$ if and
only if $L_w=K_v$, i.e.~if and only if $L_w/K_v$ is unramified in the sense
fixed above.
\end{prop}

\begin{proof}
(i) is part of the construction of $\theta_v$ in Theorem
\ref{local-reciprocity}: the unramified part of local class field theory says
that $\theta_v$ induces $K_v^\times/\CO_v^\times\cong\BZ\to\Gal(L_w/K_v)$,
$\pi_v\mapsto\Frob_v$, for unramified $L_w$; the norm group statement follows
since $N\CO_{L_w}^\times=\CO_v^\times$ for unramified extensions
(surjectivity of the norm on units of an unramified extension of local fields,
which follows from surjectivity of the norm on the residue fields and
successive approximation) and $N(\pi_v)=\pi_v^n$ up to units.

(ii) By Theorem \ref{local-reciprocity}(ii), $\theta_v$ induces an isomorphism
$K_v^\times/N L_w^\times\cong\Gal(L_w/K_v)$.
If $\CO_v^\times\subset NL_w^\times$, then $\Gal(L_w/K_v)$ is a quotient of
$K_v^\times/\CO_v^\times\cong\BZ$, hence cyclic, generated by the image of
$\pi_v$; let $M_w/K_v$ be the unramified extension of the same degree $n$.
By (i), $NM_w^\times=\pi_v^{n\BZ}\CO_v^\times$, which is contained in
$NL_w^\times$ (as $\pi_v^n\in NL_w^\times$ by the displayed isomorphism, and
$\CO_v^\times\subset NL_w^\times$ by hypothesis) and has the same index $n$ in
$K_v^\times$; so the two norm groups coincide, and by the uniqueness part of
local class field theory (the map $L_w\mapsto NL_w^\times$ is injective on
finite abelian extensions) $L_w=M_w$ is unramified.

(iii) For $K_v=\BC$ there is nothing to prove. For $K_v=\BR$ the only nontrivial
option is $L_w=\BC$, and $N_{\BC/\BR}\BC^\times=\BR_{>0}\neq\BR^\times$.
\end{proof}

\subsection{Cohomology of the ideles and the class formation}

In this subsection $L/K$ is a finite Galois extension of number fields with group
$G$, of degree $n$; for a place $w\mid v$ of $L$ we write $G_w$ for the
decomposition group and $n_w=[L_w:K_v]=\#G_w$.
All cohomology groups are Tate cohomology groups of the finite group $G$ when we
write $H^i$ with $i\leq 0$.

\begin{prop}
\label{cohomology-of-ideles}
\uses{idele-class-group-galois,local-reciprocity}
$$H^1(G,J_L)=0,\qquad
H^2(G,J_L)\cong\bigoplus_v H^2(G_w,L_w^\times)
\cong\bigoplus_v\tfrac1{n_w}\BZ/\BZ\subset\BQ/\BZ .$$
More precisely, for every $i$ one has
$H^i(G,J_L)=\bigoplus_vH^i(G_w,L_w^\times)$, the sum being over the places $v$
of $K$ (one $w\mid v$ chosen for each $v$).
\end{prop}

\begin{proof}
Cohomology of a finite group commutes with direct limits, and $J_L$ is the
direct limit over finite $S$ of the $G$-modules
$J_{L,S}=\prod_{w\in S_L}L_w^\times\times\prod_{w\notin S_L}\CO_w^\times$, where
$S$ runs over the finite sets of places of $K$ containing the archimedean ones
and $S_L$ is the set of places of $L$ above $S$.
By Proposition \ref{idele-class-group-galois} we have
$J_{L,S}=\prod_{v\in S}\Ind_{G_w}^G(L_w^\times)\times
\prod_{v\notin S}\Ind_{G_w}^G(\CO_w^\times)$, so by Shapiro's lemma
$$H^i(G,J_{L,S})=\prod_{v\in S}H^i(G_w,L_w^\times)\times
\prod_{v\notin S}H^i(G_w,\CO_w^\times).$$
For $v\notin S$ the extension $L_w/K_v$ is unramified (enlarging $S$ we may and
do assume $S$ contains all ramified places, and the limit is unchanged), and for
an unramified extension of local fields $H^i(G_w,\CO_w^\times)=0$ for all $i$
(\cite{Neu99}, Ch.~V, (1.2): $\CO_w^\times$ is cohomologically trivial for
unramified $L_w/K_v$).
Passing to the limit gives the displayed direct sum decomposition.
Now $H^1(G_w,L_w^\times)=0$ by Hilbert's Theorem 90, and
$H^2(G_w,L_w^\times)\cong\frac1{n_w}\BZ/\BZ$ by
Theorem \ref{local-reciprocity}(i).
\end{proof}

\begin{thm}[Second inequality; \cite{Neu99}, Ch.~VI, (7.1)]
\label{idele-class-H1-vanishes}
\uses{idele-class-group-galois}
For every finite Galois extension $L/K$ of number fields with group $G$ we have
$$H^1(G,C_L)=0 .$$
\end{thm}

\begin{proof}
Not supplied here. The structure of the proof is:
by the inflation--restriction sequence and solvability of the reduction, one
reduces to $L/K$ cyclic of prime degree $\ell$; then one shows
$\#H^1(G,C_L)\cdot\ell=\#H^0(G,C_L)\cdot\#H^1(G,C_L)/h(C_L)$ using
Theorem \ref{herbrand-quotient-idele-class}, so that the assertion is
equivalent to the \emph{second inequality}
$$\big[C_K:N_{L/K}C_L\big]\leq\ell .$$
The latter is proved by Kummer theory: after adjoining $\mu_\ell$ and enlarging
the set $S$ of places so that $J_K=K^\times J_{K,S}$ and $\CO_{K,S}$ is a
principal ideal domain, one writes $L=K(\sqrt[\ell]{\Delta})$ for a suitable
group $\Delta$ of $S$-units and counts indices.
See \cite{Neu99}, Ch.~VI, \S7, or \cite{Mil20}, Ch.~VII.
This is one of the two genuinely deep global inputs.
\end{proof}

\begin{thm}
\label{herbrand-quotient-idele-class}
\uses{idele-class-group-galois,cohomology-of-ideles}
Let $L/K$ be a \emph{cyclic} extension of number fields of degree $n$ with group
$G$. Then the Herbrand quotient of the idele class group is
$$h(C_L):=\frac{\#H^0(G,C_L)}{\#H^1(G,C_L)}=n .$$
\end{thm}

\begin{proof}
We sketch the standard computation and indicate its two inputs; it is not one of
the deep steps, but it is long.
Choose a finite set $S$ of places of $K$ containing the archimedean places, the
places ramified in $L/K$, and enough places so that $J_L=L^\times J_{L,S_L}$,
i.e.~so that the $S_L$-class group of $L$ is trivial (possible since $\Cl(L)$ is
finite).
Then $C_L=J_{L,S_L}L^\times/L^\times\cong J_{L,S_L}/\CO_{L,S_L}^\times$, where
$\CO_{L,S_L}^\times=L^\times\cap J_{L,S_L}$ is the group of $S_L$-units.
The Herbrand quotient is multiplicative in short exact sequences, so
$$h(C_L)=\frac{h(J_{L,S_L})}{h(\CO_{L,S_L}^\times)} .$$
By Shapiro's lemma as in Proposition \ref{cohomology-of-ideles},
$h(J_{L,S_L})=\prod_{v\in S}h(L_w^\times)=\prod_{v\in S}n_w$, using the local
computation $h(L_w^\times)=n_w$ for a cyclic extension of local fields
(\cite{Neu99}, Ch.~V, (2.1)); and the places outside $S$ contribute $1$ because
$\CO_w^\times$ is cohomologically trivial there.
For the $S_L$-units, Dirichlet's $S$-unit theorem gives a $G$-equivariant
embedding of finite index of $\CO_{L,S_L}^\times$ into the lattice
$\{x\in\prod_{w\in S_L}\BZ\mid\sum x_w=0\}$; the Herbrand quotient is unchanged
by finite-index (indeed by finite kernel and cokernel) modifications and by
tensoring the computation up, whence
$$h(\CO_{L,S_L}^\times)=\frac{\prod_{v\in S}n_w}{n}$$
(the numerator is $h(\prod_{w\in S_L}\BZ)=h(\bigoplus_{v\in S}\Ind_{G_w}^G\BZ)
=\prod_{v\in S}h_{G_w}(\BZ)=\prod_{v\in S}n_w$ and the denominator is
$h(\BZ)=n$ for the trivial module $\BZ$).
Dividing gives $h(C_L)=n$.
\end{proof}

\begin{cor}
\label{global-norm-index}
\uses{idele-class-H1-vanishes,herbrand-quotient-idele-class}
For $L/K$ cyclic of degree $n$ we have $H^1(G,C_L)=0$ and
$$\big[C_K:N_{L/K}C_L\big]=\#H^0(G,C_L)=n .$$
\end{cor}

\begin{proof}
$H^0(G,C_L)=C_L^G/N_{L/K}C_L=C_K/N_{L/K}C_L$ by Proposition
\ref{idele-class-group-galois}.
Combine Theorems \ref{idele-class-H1-vanishes} and
\ref{herbrand-quotient-idele-class}.
\end{proof}

\begin{thm}[Hasse--Brauer--Noether; \cite{Neu99}, Ch.~VI, (6.3), (8.1)]
\label{brauer-exact-sequence}
\uses{cohomology-of-ideles}
The sequence
$$0\longrightarrow H^2(G,L^\times)\longrightarrow H^2(G,J_L)
\xrightarrow{\ \sum_v\inv_v\ }\tfrac1n\BZ/\BZ\longrightarrow 0$$
is exact. Equivalently, in the limit over all $L$: an element of $\Br(K)$ is
trivial if and only if all its local invariants vanish, and the sum of the local
invariants of any element of $\Br(K)$ is zero.
\end{thm}

\begin{proof}
Not supplied here.
Exactness at the left ($H^2(G,L^\times)\hookrightarrow H^2(G,J_L)$, the
Hasse principle for the Brauer group) and the fact that
$\sum_v\inv_v$ kills $H^2(G,L^\times)$ (Artin's reciprocity law in its
cohomological form) are the substance of global class field theory; the
classical proofs reduce, via the vanishing of $H^1(G,C_L)$
(Theorem \ref{idele-class-H1-vanishes}) and cyclotomic base change, to cyclic
cyclotomic extensions, where an analytic ingredient
(Dirichlet density of primes / the first inequality) is used to produce enough
split primes. See \cite{Neu99}, Ch.~VI, \S6--\S8, and \cite{Mil20}, Ch.~VIII.
This is the second of the two genuinely deep global inputs.
\end{proof}

\begin{thm}[The idele classes form a class formation]
\label{idele-class-formation}
\uses{idele-class-H1-vanishes,brauer-exact-sequence,cohomology-of-ideles,global-norm-index}
For every finite Galois $L/K$ with group $G$ of order $n$ we have
$$H^1(G,C_L)=0,\qquad
H^2(G,C_L)\text{ is cyclic of order }n,$$
and there is a canonical isomorphism
$\inv_{L/K}:H^2(G,C_L)\xrightarrow{\sim}\frac1n\BZ/\BZ$, compatible with
inflation and satisfying $\inv\circ\res=[L':L]\inv$ for restriction to a
subgroup.
The class $u_{L/K}\in H^2(G,C_L)$ with $\inv_{L/K}(u_{L/K})=\frac1n+\BZ$ is
called the \emph{fundamental class}.
\end{thm}

\begin{proof}
The short exact sequence $1\to L^\times\to J_L\to C_L\to 1$ gives the long exact
sequence
$$H^1(G,J_L)\to H^1(G,C_L)\to H^2(G,L^\times)\xrightarrow{\ \iota\ }H^2(G,J_L)
\xrightarrow{\ \kappa\ }H^2(G,C_L).$$
By Proposition \ref{cohomology-of-ideles} we have $H^1(G,J_L)=0$, and by
Theorem \ref{brauer-exact-sequence} the map $\iota$ is injective with image
$\ker(\sum_v\inv_v)$, where $\sum_v\inv_v:H^2(G,J_L)\to\frac1n\BZ/\BZ$ is
surjective.
By exactness, $\ker\kappa=\mathrm{im}\,\iota=\ker(\sum_v\inv_v)$, so $\sum_v\inv_v$
factors through an \emph{isomorphism}
$$\inv_{L/K}:\mathrm{im}(\kappa)\xrightarrow{\ \sim\ }\tfrac1n\BZ/\BZ .$$
Also $H^1(G,C_L)=0$ by Theorem \ref{idele-class-H1-vanishes}.

What remains is the surjectivity of $\kappa$, equivalently (since $\mathrm{im}\,\kappa$ has
order $n$ by the previous paragraph) the statement $\#H^2(G,C_L)=n$.
For $G$ \emph{cyclic} this follows from the $2$-periodicity of Tate cohomology
of a cyclic group together with Corollary \ref{global-norm-index}:
$\#H^2(G,C_L)=\#H^0(G,C_L)=n$.
For general $G$ we do not supply the proof: it is the last step of the standard
verification that $(G_K,C)$ is a class formation; see \cite{Neu99}, Ch.~VI,
\S6--\S8, or \cite{Mil20}, Ch.~VIII.
The compatibilities of $\inv_{L/K}$ under inflation and restriction follow from
the corresponding local compatibilities of Theorem \ref{local-reciprocity}(i),
since $\inv_{L/K}$ is by construction induced by $\sum_v\inv_v$.
\end{proof}

\subsection{The reciprocity map}

\begin{thm}[Tate--Nakayama; \cite{Neu99}, Ch.~IV, (6.2)]
\label{tate-nakayama}
\uses{idele-class-formation}
Let $L/K$ be finite Galois with group $G$, and let $u_{L/K}\in H^2(G,C_L)$ be
the fundamental class.
Then for every $i\in\BZ$ the cup product with $u_{L/K}$
$$H^i(G,\BZ)\xrightarrow{\ \cup\,u_{L/K}\ }H^{i+2}(G,C_L)$$
is an isomorphism.
For $i=-2$ this gives
$$G^{\mathrm{ab}}=H^{-2}(G,\BZ)\xrightarrow{\ \sim\ }H^0(G,C_L)=C_K/N_{L/K}C_L .$$
\end{thm}

\begin{proof}
This is the abstract Tate--Nakayama theorem applied to the class formation of
Theorem \ref{idele-class-formation}: if $u\in H^2(G,A)$ is such that for every
subgroup $H\subset G$ the restriction $\res_H u$ generates $H^2(H,A)$, which is
cyclic of order $\#H$, and $H^1(H,A)=0$, then $\cup u$ is an isomorphism in all
degrees.
Both hypotheses hold by Theorem \ref{idele-class-formation}.
We do not reproduce the proof of the abstract Tate--Nakayama theorem; see
\cite{Neu99}, Ch.~IV, (6.2), or \cite{Mil20}, Ch.~II.
\end{proof}

\begin{definition}
\label{global-reciprocity-map}
\uses{tate-nakayama}
For $L/K$ finite Galois with group $G$, the \emph{global reciprocity map}
$$\theta_{L/K}:C_K\longrightarrow G^{\mathrm{ab}}$$
is the composition of the projection $C_K\to C_K/N_{L/K}C_L$ with the inverse of
the isomorphism of Theorem \ref{tate-nakayama}.
It is surjective with kernel $N_{L/K}C_L$ (in particular, if $L/K$ is abelian,
$\theta_{L/K}$ induces $C_K/N_{L/K}C_L\cong\Gal(L/K)$), and it is compatible
with passing to subextensions: if $K\subset L'\subset L$ with $L'/K$ Galois,
then $\theta_{L'/K}$ is $\theta_{L/K}$ followed by the projection
$\Gal(L/K)^{\mathrm{ab}}\to\Gal(L'/K)^{\mathrm{ab}}$.
By passing to the inverse limit one obtains
$\theta_K:C_K\to\Gal(K^{\mathrm{ab}}/K)$, and for any (possibly infinite)
abelian extension $M/K$ a continuous homomorphism
$\theta_{M/K}:C_K\to\Gal(M/K)$.
\end{definition}

\begin{thm}[Local--global compatibility; \cite{Neu99}, Ch.~VI, (5.6)]
\label{reciprocity-local-compatibility}
\uses{global-reciprocity-map,local-reciprocity,local-unramified-reciprocity}
Let $L/K$ be finite abelian with group $G$, let $v$ be a place of $K$ and
$w\mid v$ a place of $L$.
Let $i_v:K_v^\times\to C_K$ be the map induced by the inclusion of the $v$-th
component into $J_K$. Then the diagram
$$\begin{array}{ccc}
K_v^\times&\xrightarrow{\ \theta_v\ }&\Gal(L_w/K_v)\\
\downarrow i_v&&\downarrow\\
C_K&\xrightarrow{\ \theta_{L/K}\ }&\Gal(L/K)
\end{array}$$
commutes, the right vertical arrow being the inclusion of the decomposition
group $G_w$.
In particular:

{\rm(i)} if $L/K$ is unramified at $v$ and $v$ is finite, then
$\theta_{L/K}(i_v(\pi_v))=\Frob_v$ and $\theta_{L/K}(i_v(\CO_v^\times))=1$;

{\rm(ii)} $\theta_{L/K}\big(\ov{U_K}\big)=1$ if and only if $L/K$ is unramified
at every place, where $\ov{U_K}$ is the image of the unit ideles in $C_K$.
\end{thm}

\begin{proof}
We only sketch the commutativity of the diagram, which is standard but is a
genuine computation with cup products; the consequences (i) and (ii) are then
proved in full.
The commutativity of the diagram is the statement that the global invariant map
of Theorem \ref{idele-class-formation} is the sum of the local ones, i.e.
that the fundamental class $u_{L/K}$ restricts to the local fundamental classes;
this is exactly how $\inv_{L/K}$ was defined in
Theorem \ref{idele-class-formation} out of the $\inv_v$, and the compatibility
of cup products with the maps $H^2(G_w,L_w^\times)\to H^2(G,J_L)\to H^2(G,C_L)$
then gives the diagram.

(i) follows from Proposition \ref{local-unramified-reciprocity}(i) and the
diagram.

(ii) If $L/K$ is unramified everywhere, then $\theta_v(\CO_v^\times)=1$ for all
finite $v$ by Proposition \ref{local-unramified-reciprocity}(i) and
$\theta_v(K_v^\times)=1$ for archimedean $v$ (then $L_w=K_v$), so
$\theta_{L/K}(\ov{U_K})=1$ by the diagram, using that $U_K$ is topologically
generated by the images of the local unit groups and that $\theta_{L/K}$ is
continuous with finite (hence discrete) target.
Conversely, if $\theta_{L/K}(\ov{U_K})=1$ then for each $v$ we get
$\theta_v(\CO_v^\times)=1$ (resp.~$\theta_v(K_v^\times)=1$ for $v$ archimedean),
i.e.~$\CO_v^\times\subset N_{L_w/K_v}L_w^\times$ (resp.~$K_v^\times=NL_w^\times$),
so $L/K$ is unramified at $v$ by
Proposition \ref{local-unramified-reciprocity}(ii),(iii).
\end{proof}

\begin{thm}[Existence theorem; \cite{Neu99}, Ch.~VI, (6.1)]
\label{existence-theorem}
\uses{global-reciprocity-map}
The map $L\mapsto N_{L/K}C_L$ is an inclusion-reversing bijection between the
finite abelian extensions $L/K$ inside a fixed separable closure and the open
subgroups of finite index of $C_K$.
\end{thm}

\begin{proof}
Not supplied here.
That $N_{L/K}C_L$ is open of finite index, and that $L\mapsto N_{L/K}C_L$ is
injective and inclusion-reversing, follows from
Definition \ref{global-reciprocity-map} and Corollary \ref{global-norm-index}
(the index equals $[L:K]$ for $L/K$ abelian).
Surjectivity --- every open subgroup of finite index is a norm group --- is the
existence theorem; its proof uses Kummer theory, the structure of $C_K$ (in
particular the compactness of $C_K^1$), and the second inequality.
See \cite{Neu99}, Ch.~VI, \S6.
\end{proof}

\subsection{The Artin map of an unramified abelian extension}

We now specialize to unramified extensions and obtain the four statements
formalized in {\Lean}.
Let $F$ be a number field.

\begin{thm}
\label{artin-map}
\uses{idele-class-group-and-class-group,global-reciprocity-map,
reciprocity-local-compatibility}
\lean{NumberField.IsUnramifiedEverywhere.artinMap}
Let $K/F$ be an abelian Galois extension (not assumed finite) which is
unramified at every place of $F$.
Then there is a unique group homomorphism
$$\mathrm{Art}_{K/F}:\Cl(\CO_F)\longrightarrow\Gal(K/F)$$
such that for every prime ideal $\fp$ of $\CO_F$ the class $[\fp]$ is sent to
the Frobenius element $\Frob_\fp\in\Gal(K/F)$.
\end{thm}

\begin{proof}
\emph{The Frobenius element exists.}
Let $\fp$ be a prime of $\CO_F$, with associated finite place $v$.
For every finite subextension $L/F$ of $K/F$ the extension $L/F$ is abelian and
unramified at $v$, so the decomposition group at a place $w\mid v$ of $L$ is
cyclic generated by a Frobenius element which, $L/F$ being abelian, does not
depend on the choice of $w\mid v$; call it $\Frob_\fp^{L}$.
These are compatible under restriction, so they define
$\Frob_\fp:=\varprojlim_L\Frob_\fp^L\in\Gal(K/F)=\varprojlim_L\Gal(L/F)$.

\emph{Construction of the map.}
Since $I_F$, the group of fractional ideals, is free abelian on the primes
$\fp$, there is a unique homomorphism $I_F\to\Gal(K/F)$, $\fp\mapsto\Frob_\fp$;
we must show that it kills the principal ideals, and this is the content of
Artin reciprocity.
Fix a finite subextension $L/F$; it suffices to prove the claim for each such
$L$, since $\Gal(K/F)=\varprojlim\Gal(L/F)$.
By Proposition \ref{idele-class-group-and-class-group} the map $J_F\to I_F$,
$a\mapsto(a)$, is surjective with kernel $U_F$ and carries $F^\times$ onto the
principal ideals.
By Theorem \ref{reciprocity-local-compatibility}(i) and continuity, for an idele
$a\in J_F$ with image $(a)=\prod_\fp\fp^{n_\fp}$ we have
$$\theta_{L/F}(a\bmod F^\times)=\prod_\fp\Frob_\fp^{n_\fp},$$
because $a$ differs from $\prod_\fp\pi_\fp^{n_\fp}$ (an idele with finitely many
non-trivial entries) by an element of $U_F$, and
$\theta_{L/F}(\ov{U_F})=1$ by Theorem
\ref{reciprocity-local-compatibility}(ii), $L/F$ being unramified everywhere.
Hence the composite $J_F\to I_F\to\Gal(L/F)$ equals
$\theta_{L/F}\circ(\text{projection to }C_F)$, which kills $F^\times$.
Since $J_F\to I_F$ is surjective and carries $F^\times$ onto the principal
ideals, the map $I_F\to\Gal(L/F)$ kills the principal ideals, as required.
Uniqueness is clear, since the classes $[\fp]$ generate $\Cl(\CO_F)$.
\end{proof}

\begin{thm}
\label{artin-map-spec}
\uses{artin-map}
\lean{NumberField.IsUnramifiedEverywhere.artinMap_spec}
In the situation of Theorem \ref{artin-map}, let $\fp$ be a prime of $\CO_F$ and
$\fP$ a prime of $\CO_K$ above $\fp$. Then
$$\mathrm{Art}_{K/F}([\fp])=\Frob_\fP,$$
the arithmetic Frobenius at $\fP$, i.e.~the unique element $\sigma$ of the
decomposition group at $\fP$ with $\sigma(x)\equiv x^{\#(\CO_F/\fp)}
\pmod{\fP}$ for all $x\in\CO_K$.
\end{thm}

\begin{proof}
This is the definition of $\Frob_\fp$ in the proof of Theorem \ref{artin-map}:
$K/F$ is unramified at $\fp$, so the decomposition group at $\fP$ maps
isomorphically to the Galois group of the residue extension, which is
(topologically) generated by the $\#(\CO_F/\fp)$-power map; the corresponding
element is $\Frob_\fP$.
Since $K/F$ is abelian, $\Frob_\fP$ is independent of the choice of $\fP$ above
$\fp$ (the primes above $\fp$ are permuted transitively by $\Gal(K/F)$ and
$\Frob_{\sigma\fP}=\sigma\Frob_\fP\sigma^{-1}=\Frob_\fP$), so
$\Frob_\fP=\Frob_\fp=\mathrm{Art}_{K/F}([\fp])$.
\end{proof}

\begin{thm}
\label{artin-map-surjective}
\uses{artin-map,global-reciprocity-map,reciprocity-local-compatibility,
idele-class-group-and-class-group}
\lean{NumberField.IsUnramifiedEverywhere.surjective_artinMap}
In the situation of Theorem \ref{artin-map}, the map
$\mathrm{Art}_{K/F}:\Cl(\CO_F)\to\Gal(K/F)$ is surjective.
Consequently $\#\Gal(K/F)\leq\#\Cl(\CO_F)$; in particular $K/F$ is a finite
extension and $[K:F]$ divides $\#\Cl(\CO_F)$.
\end{thm}

\begin{proof}
First let $L/F$ be a \emph{finite} subextension.
By Definition \ref{global-reciprocity-map} the reciprocity map
$\theta_{L/F}:C_F\to\Gal(L/F)$ is surjective, and by the proof of Theorem
\ref{artin-map} the composite $\Cl(\CO_F)\to\Gal(L/F)$ induced by
$\mathrm{Art}$ is obtained from $\theta_{L/F}$ by factoring out
$\ov{U_F}$, using $\Cl(\CO_F)=C_F/\ov{U_F}$
(Proposition \ref{idele-class-group-and-class-group}) and
$\theta_{L/F}(\ov{U_F})=1$
(Theorem \ref{reciprocity-local-compatibility}(ii)).
A surjection factoring through a quotient of its source is still surjective, so
$\Cl(\CO_F)\to\Gal(L/F)$ is onto.
(Alternatively, for finite $L/F$ surjectivity follows from the Chebotarev
density theorem, which produces a prime with any prescribed Frobenius.)

Hence $\#\Gal(L/F)\leq\#\Cl(\CO_F)$ for every finite subextension $L/F$, and
$\#\Cl(\CO_F)$ is finite.
Therefore the degrees $[L:F]$ are bounded, so $K/F$ is finite --- if it were
not, it would contain finite subextensions of arbitrarily large degree --- and
applying the above to $L=K$ gives the surjectivity of $\mathrm{Art}_{K/F}$.
Finally $[K:F]=\#\Gal(K/F)$ divides $\#\Cl(\CO_F)$ because
$\Gal(K/F)$ is a quotient group of the finite abelian group $\Cl(\CO_F)$.
\end{proof}

\begin{thm}[Hilbert class field]
\label{hilbert-class-field}
\uses{artin-map,artin-map-surjective,existence-theorem,
idele-class-group-and-class-group,global-reciprocity-map,
reciprocity-local-compatibility}
\lean{NumberField.IsUnramifiedEverywhere.bijective_artinMap_of_isSepClosed}
Let $\Omega$ be a separably closed field containing $F$ (e.g.~a separable
closure) and let $H\subset\Omega$ be the maximal abelian extension of $F$ inside
$\Omega$ which is unramified at every place of $F$ (the \emph{Hilbert class
field} of $F$).
Then $H/F$ is finite and
$$\mathrm{Art}_{H/F}:\Cl(\CO_F)\xrightarrow{\ \sim\ }\Gal(H/F)$$
is an isomorphism; in particular $[H:F]=\#\Cl(\CO_F)=h_F$.
\end{thm}

\begin{proof}
$H$ is well defined: the compositum of two abelian extensions of $F$ unramified
everywhere is again abelian and unramified everywhere, so the family of such
subextensions of $\Omega$ is directed and $H$ is their union;
$H/F$ is abelian and unramified everywhere.
By Theorem \ref{artin-map-surjective}, $H/F$ is finite and
$\mathrm{Art}_{H/F}$ is surjective, so it remains to prove injectivity, i.e.
$\#\Gal(H/F)\geq\#\Cl(\CO_F)$.

By Proposition \ref{idele-class-group-and-class-group} the subgroup
$\ov{U_F}\subset C_F$ is open of index $\#\Cl(\CO_F)$.
By the existence theorem (Theorem \ref{existence-theorem}) there is a finite
abelian extension $L/F$ with $N_{L/F}C_L=\ov{U_F}$, and then
$$\Gal(L/F)\cong C_F/N_{L/F}C_L=C_F/\ov{U_F}\cong\Cl(\CO_F)$$
by Definition \ref{global-reciprocity-map}, so $[L:F]=\#\Cl(\CO_F)$.
Moreover $\theta_{L/F}(\ov{U_F})=1$, so $L/F$ is unramified at every place by
Theorem \ref{reciprocity-local-compatibility}(ii); replacing $L$ by an
$F$-isomorphic copy inside $\Omega$ (possible since $\Omega$ is separably closed
and $L/F$ is separable) we get $L\subset H$ and hence
$\#\Gal(H/F)\geq[L:F]=\#\Cl(\CO_F)$, as required.
\end{proof}

\begin{cor}
\label{hilbert-p-class-field}
\uses{hilbert-class-field}
Let $F$ be a number field, $p$ a prime, and let $L$ be the maximal unramified
abelian $p$-extension of $F$ inside a separable closure, i.e.~the largest
subextension of $H/F$ whose Galois group is a $p$-group.
Then
$$\Gal(L/F)\cong\Cl(\CO_F)(p),$$
the $p$-primary part of the class group; in particular
$[L:F]=p^{\ord_p(h_F)}$.
\end{cor}

\begin{proof}
Any abelian extension of $F$ which is unramified everywhere lies in $H$
(Theorem \ref{hilbert-class-field}), so $L$ is the subfield of $H$ fixed by the
prime-to-$p$ part of the finite abelian group
$\Gal(H/F)\cong\Cl(\CO_F)$ under $\mathrm{Art}_{H/F}$.
Writing $\Cl(\CO_F)=\Cl(\CO_F)(p)\times\Cl(\CO_F)(p')$ with $\Cl(\CO_F)(p')$ the
prime-to-$p$ part, the maximal $p$-quotient of $\Gal(H/F)$ is
$\Cl(\CO_F)(p)$, and $\Gal(L/F)$ is that maximal $p$-quotient.
\end{proof}

\section{Arithmetic of $\BZ_p$-extensions}

\subsection{Group theory preliminaries}

Let $G$ be a group, $X$ be an abelian normal subgroup,
$\Gamma=G/X$ be the quotient group.

\begin{definition}
\label{conjugate-action}
\lean{Subgroup.conjQuotient,Subgroup.conjQuotient_mk_apply}
\leanok
$X$ has a natural, well-defined $\Gamma$-action,
given by $\sigma\bullet x
=\widetilde\sigma x\widetilde\sigma^{-1}$
where $\widetilde\sigma\in G$ is any lifting of $\sigma\in\Gamma$.
\end{definition}

\begin{lem}
\label{conjugate-action-cont}
\uses{conjugate-action}
\lean{Subgroup.continuous_conjQuotient}
\leanok
If $G$ is a topological group, $X$ is a closed abelian normal subgroup,
then $\Gamma\times X\to X$, $(\sigma,x)\mapsto\sigma\bullet x$
is continuous.
\end{lem}

\begin{proof}
\leanok
Consider the map $c:G\times X\to X$, $(g,x)\mapsto gxg^{-1}$.
It is well defined because $X$ is normal in $G$, and it is continuous, being the
restriction of the continuous multiplication and inversion maps of $G$ to
$G\times X$ followed by the inclusion of the subspace $X$.

Let $\pi:G\to\Gamma=G/X$ be the projection.
It is an open surjection, as is any quotient map of topological groups
(if $U\subset G$ is open then $\pi^{-1}(\pi(U))=UX=\bigcup_{x\in X}Ux$ is open).
Hence $\pi\times\id_X:G\times X\to\Gamma\times X$ is an open continuous
surjection, and therefore a quotient map.

Finally, $c$ is constant on the fibres of $\pi\times\id_X$: if $\pi(g)=\pi(g')$,
write $g'=gu$ with $u\in X$; then, $X$ being abelian,
$$g'x(g')^{-1}=g(uxu^{-1})g^{-1}=gxg^{-1}$$
for every $x\in X$.
By the universal property of quotient maps, $c$ factors as
$c=(\text{the map }(\sigma,x)\mapsto\sigma\bullet x)\circ(\pi\times\id_X)$
with the induced map $\Gamma\times X\to X$ continuous.
This induced map is exactly the action of Definition \ref{conjugate-action}.
\end{proof}

\begin{lem}[\cite{Was97}, Lemma 13.14]
\label{commutator-eq}
\uses{conjugate-action-cont}
\lean{Subgroup.gammaSubOneG,
Subgroup.mem_gammaSubOneG_iff,
Subgroup.commutator_eq_gammaSubOneG,
Subgroup.isClosed_gammaSubOneG}
\leanok
Let $G$ be a compact Hausdorff
topological group, $X$ be a closed abelian normal subgroup,
$G'$ be the closure of the commutator subgroup of $G$.
Suppose $\Gamma=G/X$ is topological cyclic (hence is abelian)
with a topological generator $\gamma$,
and there exists a subgroup $I$ of $G$
such that $I\hookrightarrow G\twoheadrightarrow\Gamma$ is surjective.
Then $G'=\{(\gamma\bullet x)x^{-1}\mid x\in X\}$.
\end{lem}

\begin{proof}
\leanok
Note that $G=IX$, $G'=\overline{[G,G]}$
and $[G,G]$ is generated by elements of form
$(\alpha x)(\beta y)(\alpha x)^{-1}(\beta y)^{-1}
=(\alpha\bullet x)(\alpha\beta\bullet x)^{-1}(\alpha\beta\bullet y)(\beta\bullet y)^{-1}$,
where $\alpha,\beta\in I$ and $x,y\in X$.
By taking $\alpha\in I$ to be the preimage of $\gamma\in\Gamma$, and $\beta=1$,
we know that ``$\supset$'' holds.

Note that RHS is a compact subgroup
(it is the image of a compact set,
$(\gamma\bullet x)x^{-1}(\gamma\bullet y)y^{-1}
=(\gamma\bullet xy)(xy)^{-1}$,
and $((\gamma\bullet x)x^{-1})^{-1}
=(\gamma\bullet x^{-1})x$).
Therefore, to prove ``$\subset$'', we only need to show that
$(\alpha\bullet x)x^{-1}$ is in RHS for all $\alpha\in I$ and $x\in X$.
Indeed, granting this, each generator of $[G,G]$ displayed above is a product of
two elements of RHS, since
$$(\alpha\bullet x)(\alpha\beta\bullet x)^{-1}
=\big((\alpha\bullet x)x^{-1}\big)\big((\alpha\beta\bullet x)x^{-1}\big)^{-1},
\qquad
(\alpha\beta\bullet y)(\beta\bullet y)^{-1}
=\big((\alpha\beta\bullet y)y^{-1}\big)\big((\beta\bullet y)y^{-1}\big)^{-1},$$
so $[G,G]\subset\text{RHS}$, and RHS is closed (being compact inside the
Hausdorff space $X$), whence $G'=\overline{[G,G]}\subset\text{RHS}$.

Note that $(\alpha\bullet x)x^{-1}$ only depends on the image $\sigma\in\Gamma$ of
$\alpha$, so it suffices to prove that
$$\Gamma_0:=\{\sigma\in\Gamma\mid(\sigma\bullet x)x^{-1}\in\text{RHS}
\text{ for all }x\in X\}$$
is all of $\Gamma$.

$\Gamma_0$ is a subgroup of $\Gamma$: it contains $1$; if $\sigma,\tau\in\Gamma_0$
then
$$(\sigma\tau\bullet x)x^{-1}
=\big((\sigma\bullet(\tau\bullet x))(\tau\bullet x)^{-1}\big)
\big((\tau\bullet x)x^{-1}\big)\in\text{RHS},$$
because RHS is a subgroup; and if $\sigma\in\Gamma_0$ then, putting
$y:=\sigma^{-1}\bullet x$,
$(\sigma^{-1}\bullet x)x^{-1}=\big((\sigma\bullet y)y^{-1}\big)^{-1}\in\text{RHS}$.

$\Gamma_0$ is closed in $\Gamma$: for each fixed $x\in X$ the map
$\Gamma\to X$, $\sigma\mapsto(\sigma\bullet x)x^{-1}$, is continuous by
Lemma \ref{conjugate-action-cont}, and RHS is closed in $X$; so $\Gamma_0$ is an
intersection of closed subsets of $\Gamma$.

Finally $\gamma\in\Gamma_0$ by the definition of RHS, so $\Gamma_0$ is a closed
subgroup containing the dense subgroup $\{\gamma^n\mid n\in\BZ\}$, i.e.
$\Gamma_0=\Gamma$.
\end{proof}

\begin{remark}
In {\Lean} (\texttt{Subgroup.commutator\_eq\_gammaSubOneG}) the subgroup $I$ is
not used, and the commutator subgroup itself, not only its closure, is shown to
equal RHS, which is closed (\texttt{Subgroup.isClosed\_gammaSubOneG}). The proof
replaces $I$ by the subgroup $J\subset G$ of elements whose image in $\Gamma$ is
a power of $\gamma$. This subgroup is dense, and its elements have the form
$g^kx$ with $g$ a fixed lift of $\gamma$ and $x\in X$. Powers of $g$ commute, so
the displayed expression of the commutator $[\alpha x,\beta y]$ holds for them;
that expression needs $\alpha\beta=\beta\alpha$. Together with the argument that
$\Gamma_0=\Gamma$, this gives $[a,b]\in\text{RHS}$ for $a,b\in J$. The same then
holds for all $a,b\in G$, because $J$ is dense, the commutator map is continuous
and RHS is closed.
\end{remark}

\subsection{The class group of $\BZ_p$-extension of a number field}

Let $K$ be a number field, $p$ be a prime,
$K_\infty/K$ be a $\BZ_p$-extension.

\begin{definition}
\label{p-primary-part}
\lean{CommGroup.primaryComponent,CommGroup.equivPrimeToComponentProdPrimaryComponent}
\leanok
If $M$ is a finite abelian group, $p$ is a prime, let $M(p)$ be the $p$-primary
part of $M$, which is the $p$-Sylow subgroup of $M$, or the subgroup of $M$
consisting of elements whose order is power of $p$.
By definition it is a subgroup of $M$, and is also canonically a quotient group of $M$.
\end{definition}

\begin{definition}
\label{Zp-ext-Ln}
\uses{Zp-ext-def}
\lean{MvZpExtension.Ln}
\leanok
For each $n\geq 0$ let $L_n$ be the
maximal unramified abelian $p$-extension of $K_n$,
i.e.~the largest extension of $K_n$ inside a fixed separable closure of
$K_\infty$ which is unramified at every place of $K_n$, abelian over $K_n$,
and whose Galois group over $K_n$ is a pro-$p$ group
(the \emph{$p$-Hilbert class field} of $K_n$).
Let $X_n:=\Gal(L_n/K_n)$.
\end{definition}

\begin{remark}
\label{Ln-not-exponent-p}
\textbf{Warning.}
An earlier version of this definition read ``the maximal unramified abelian
extension of $K_n$ of exponent $p$''. That reading is \emph{not} the one used
anywhere below, and with it Proposition \ref{Xn-isom-An} and the proof of
Theorem \ref{clgp-growth} would be false: if $L_n'$ denotes the maximal
unramified abelian extension of exponent $p$, then
$\Gal(L_n'/K_n)\cong A_n/A_n^p$, so for instance if $A_n\cong\BZ/p^2\BZ$ we get
$\ord_p\#\Gal(L_n'/K_n)=1$ while $\ord_p\#\Cl(K_n)=\ord_p\#A_n=2$.
The {\Lean} definition \texttt{MvZpExtension.Ln} is the maximal unramified
abelian $p$-extension (see \texttt{MvZpExtension.finrank\_Ln}, which asserts
$[L_n:K_n]=p^{\ord_p(h_{K_n})}$), i.e.~the one adopted here.
\end{remark}

\begin{lem}
\label{Ln-mono}
\uses{Zp-ext-Ln}
\lean{MvZpExtension.adjoin_Ln_le,MvZpExtension.Ln_mono}
\leanok
$K_{n+1}L_n\subset L_{n+1}$. In particular, $L_n\subset L_{n+1}$.
\end{lem}

\begin{proof}
\leanok
Since $K_{n+1}$ and $L_n$ are Galois over $K_n$,
the $K_{n+1}L_n$ is also Galois over $K_n$,
and the natural map
$\Gal(K_{n+1}L_n/K_{n+1})\to\Gal(L_n/K_n)$, $\sigma\mapsto\sigma|_{L_n}$,
is injective, with image $\Gal(L_n/L_n\cap K_{n+1})$.
In particular $K_{n+1}L_n/K_{n+1}$ is abelian and its Galois group is a
$p$-group, because $\Gal(L_n/K_n)$ is.

Moreover $K_{n+1}L_n/K_{n+1}$ is unramified at every place.
Indeed, let $w$ be a place of $K_{n+1}L_n$ and let $T_w\subset
\Gal(K_{n+1}L_n/K_{n+1})$ be its inertia subgroup.
Every $\sigma\in T_w$ acts trivially on the residue field of $w$ and preserves
$w$; hence its restriction $\sigma|_{L_n}\in\Gal(L_n/K_n)$ preserves the place
$w|_{L_n}$ and acts trivially on its residue field, i.e.~$\sigma|_{L_n}$ lies in
the inertia subgroup of $w|_{L_n}$ in $\Gal(L_n/K_n)$
(for an archimedean place, ``inertia'' is read as the decomposition subgroup of
the corresponding real or complex place, and the same argument applies).
That inertia subgroup is trivial since $L_n/K_n$ is unramified, and the
restriction map is injective, so $T_w=1$.

Therefore $K_{n+1}L_n$ is an unramified abelian $p$-extension of $K_{n+1}$,
and $K_{n+1}L_n\subset L_{n+1}$ by the maximality in Definition
\ref{Zp-ext-Ln}. In particular $L_n\subset K_{n+1}L_n\subset L_{n+1}$.
\end{proof}

\begin{lem}
\label{X-inf-is-proj-lim}
\uses{Zp-ext-L-inf,Ln-mono,Ln-K-Gal}
\lean{MvZpExtension.xinfContinuousMulEquivLimit,
MvZpExtension.isProP_Xinf',
MvZpExtension.mul_comm_Xinf}
There is a natural isomorphism of topological groups
$$X_\infty\xrightarrow{\ \sim\ }\varprojlim_n X_n,\qquad
\sigma\mapsto(\sigma|_{L_n})_{n\geq 0},$$
the transition maps on the right being
$X_{n+1}=\Gal(L_{n+1}/K_{n+1})\to\Gal(L_n/K_n)=X_n$,
$\sigma\mapsto\sigma|_{L_n}$.
In particular $X_\infty$ is a pro-$p$ abelian group.
\end{lem}

\begin{proof}
\emph{The map is well defined.}
Each $L_n$ is Galois over $K$ (Lemma \ref{Ln-K-Gal}), so any
$\sigma\in\Gal(L_\infty/K_\infty)$ maps $L_n$ into itself, and
$\sigma|_{L_n}$ fixes $L_n\cap K_\infty\supset K_n$ pointwise; hence
$\sigma|_{L_n}\in\Gal(L_n/K_n)=X_n$.
The restrictions are visibly compatible with the transition maps
(using $L_n\subset L_{n+1}$, Lemma \ref{Ln-mono}), so we get a group
homomorphism $X_\infty\to\varprojlim_nX_n$, which is continuous because each
$\sigma\mapsto\sigma|_{L_n}$ is continuous for the Krull topologies.

\emph{Injectivity.}
$L_\infty=\bigcup_nL_n$, so an element of $\Gal(L_\infty/K_\infty)$ restricting
to the identity on every $L_n$ is the identity.

\emph{Surjectivity.}
Let $(\sigma_n)_n$ be a compatible family.
Since $L_\infty=\bigcup_nL_n$ and the $L_n$ increase, the assignment
$\sigma(x):=\sigma_n(x)$ for $x\in L_n$ is a well-defined field automorphism of
$L_\infty$ (compatibility makes it independent of the chosen $n$).
It fixes $K_\infty=\bigcup_nK_n$ pointwise, because $x\in K_n$ implies
$\sigma(x)=\sigma_n(x)=x$ as $\sigma_n\in\Gal(L_n/K_n)$.
Hence $\sigma\in X_\infty$ and it maps to $(\sigma_n)_n$.

\emph{Homeomorphism.}
Both sides are compact Hausdorff (profinite) groups and the map is a continuous
bijection, hence a homeomorphism.
Each $X_n\cong A_n$ is a finite abelian $p$-group
(Proposition \ref{Xn-isom-An}), so $X_\infty$ is pro-$p$ abelian.
\end{proof}

\subsection{Ramification of primes in a $\BZ_p$-extension}

\begin{prop}[\cite{Was97}, Proposition 13.2,
\cite{Iwa59}, Lemma 7.1]
\label{p:unr-outside-p}
\uses{Zp-ext-def}
\lean{MvZpExtension.ramified_place_liesOver_basePrimeAbove_p,
MvZpExtension.exists_restrictNormalHom_pow_eq_one_of_liesOver_adicAbv,
MvZpExtension.inertiaSubgroup_eq_bot_of_fixes_Kn,
MvZpExtension.inertiaSubgroup_eq_bot_of_archimedean}
\leanok
If $K$ is any number field, $K_\infty/K$ is any $\BZ_p$-extension,
and $\fl$ is a prime of $K$ not above $p$
(in particular, an infinite place).
Then $\fl$ is unramified in $K_\infty/K$.
\end{prop}

\begin{proof}
\leanok
Let $D_\fl$ be the decomposition subgroup of $\fl$ in $\Gamma:=\Gal(K_\infty/K)\cong\BZ_p$,
which is a closed subgroup.
If $\fl$ is an infinite place then $D_\fl$ is finite, hence must be trivial.
In the following assume $\fl$ is a finite place.
Let $l=\chaR(\CO_K/\fl)\neq p$, then $K_\fl/\BQ_l$ is a finite extension,
and let $(K_\infty)_\fl:=\varinjlim(K_n)_\fl$, then
$D_\fl=\Gal((K_\infty)_\fl/K_\fl)$ is a subgroup of $\BZ_p$.

We have $K_\fl\subset K_\fl^{\mathrm{unr}}\subset K_\fl^{\mathrm{ab}}$,
and
$$
\Gal(K_\fl^{\mathrm{unr}}/K_\fl)\cong\widehat\BZ
=\prod_{q\text{ prime}}\BZ_q.
$$
So $K_\fl$ has at least one $\BZ_p$-extension, i.e. the unique unramified
$\BZ_p$-extension. If there are other $\BZ_p$-extensions of $K_\fl$,
then there exists a Galois extension of $K_\fl$ with Galois group
isomorphic to $\BZ_p^2$.

However, $\Gal(K_\fl^{\mathrm{ab}}/K_\fl^{\mathrm{unr}})$
doesn't have a quotient isomorphic to $\BZ_p$, because by
local class field theory,
$\Gal(K_\fl^{\mathrm{ab}}/K_\fl^{\mathrm{unr}})\cong\CO_{K_\fl}^\times\cong
(\text{a finite group})\times\BZ_l^{[K_\fl:\BQ_l]}$ which is a finite group
times a pro-$l$ group, obviously it doesn't have a quotient isomorphic to $\BZ_p$.
So there is only one $\BZ_p$-extension of $K_\fl$,
note that $(K_\infty)_\fl/K_\fl$ is either trivial or a $\BZ_p$-extension,
in both cases it must be contained in $K_\fl^{\mathrm{unr}}$.
\end{proof}

\begin{remark}
The {\Lean} proof does not use local class field theory. It uses tame inertia
instead
(\texttt{MvZpExtension.exists\_restrictNormalHom\_pow\_eq\_one\_of\_liesOver\_adicAbv}).
Let $\fl$ be a finite prime of $K$ not above $p$, let $w$ be a place of
$K_\infty$ above $\fl$, and let $\sigma$ be in the inertia subgroup
$I_w\subset\Gamma$. For each $n$, the restriction $\sigma|_{K_n}$ lies in the
inertia group, in $\Gal(K_n/K)$, of the prime $\fl_n$ of $K_n$ below $w$. Also
$(\sigma|_{K_n})^{p^n}=1$, because $[K_n:K]=p^n$. Since $p\notin\fl_n$, this
inertia element is tame. In an abelian extension of number fields, a tame
inertia element at a prime above $\fl$ is killed by $N(\fl)-1$
(\texttt{NumberField.pow\_card\_quotient\_sub\_one\_eq\_one\_of\_mem\_inertia}).
The reason is that it acts on the valuation ring of the completion trivially on
the residue field and commutes with a Frobenius element, which acts on the
residue field by $x\mapsto x^{N(\fl)}$. The exponent $N(\fl)-1$ does not depend
on $n$. So $\sigma^{N(\fl)-1}$ restricts to the identity on every $K_n$,
i.e.~$\sigma^{N(\fl)-1}\in\bigcap_n\Gamma^{p^n}=1$. Hence $\sigma=1$, because
$\Gamma\cong\BZ_p$ is torsion-free. Infinite places are treated as above:
$D_\fl$ is finite, hence trivial
(\texttt{MvZpExtension.inertiaSubgroup\_eq\_bot\_of\_archimedean}).
\end{remark}

\begin{definition}
\label{Zp-ext-totally-ramified}
\uses{Zp-ext-def}
A $\BZ_p$-extension $K_\infty/K$ is called totally ramified, if
all primes which are ramified in $K_\infty/K$ are totally ramified.
More explicitly, for any prime of $K$,
either it is unramified in $K_n/K$ for all $n$,
or it is totally ramified in $K_n/K$ for all $n$.
\end{definition}

\begin{lem}[\cite{Was97}, Lemma 13.3]
\label{exists-totally-ramified}
\uses{p:unr-outside-p,Zp-ext-totally-ramified,Zp-ext-def}
\lean{MvZpExtension.exists_inertiaSubgroup_ne_bot,
MvZpExtension.exists_totally_ramified,
MvZpExtension.RamifiedBasePlaceData.exists_common_shift,
MvZpExtension.RamifiedBasePlaceData.exists_isEquiv_orbitPlace}
If $K$ is any number field, $K_\infty/K$ is any $\BZ_p$-extension,
then $K_\infty/K$ is ramified at at least one place,
and there exists $e\geq 0$ such that the $\BZ_p$-extension $K_\infty/K_e$
is totally ramified (Definition \ref{Zp-ext-totally-ramified}).
\end{lem}

\begin{proof}
\emph{At least one place ramifies.}
Suppose not. Then every $K_n$ is an abelian extension of $K$ which is unramified
at every place of $K$ (including the archimedean ones), so $K_n$ is contained in
the Hilbert class field $H$ of $K$ by class field theory.
But $[H:K]=\#\Cl(K)$ is finite while $[K_n:K]=p^n$ is unbounded, a contradiction.

\emph{Existence of $e$.}
By Proposition \ref{p:unr-outside-p} only the (finitely many) primes of $K$ above
$p$ can ramify in $K_\infty/K$; let $\fp_1,\cdots,\fp_s$ ($s\geq 1$ by the above)
be those that do ramify.
For each $i$ fix a place $\fP_i$ of $K_\infty$ above $\fp_i$ and let
$I_i\subset\Gamma=\Gal(K_\infty/K)$ be its inertia subgroup; since $\Gamma$ is
abelian, $I_i$ does not depend on the choice of $\fP_i$.
Being an inertia subgroup, $I_i$ is a closed subgroup of $\Gamma\cong\BZ_p$,
and $I_i\neq 1$ because $\fp_i$ ramifies.
The nonzero closed subgroups of $\BZ_p$ are the $p^m\BZ_p$, so
$I_i=\Gamma^{p^{m_i}}$ for some $m_i\geq 0$.
Put $e:=\max_{1\leq i\leq s}m_i$, so that $\Gamma^{p^e}\subset I_i$ for every $i$.

We check that $K_\infty/K_e$ is totally ramified.
Let $\fq$ be a prime of $K_e$ and let $\fQ$ be a place of $K_\infty$ above it.
The inertia subgroup of $\fQ$ in $\Gal(K_\infty/K_e)=\Gamma^{p^e}$ is
$I(\fQ)\cap\Gamma^{p^e}$, where $I(\fQ)\subset\Gamma$ is the inertia subgroup of
$\fQ$ in $\Gamma$.
If $\fq$ lies above some $\fp_i$, then $I(\fQ)=I_i\supset\Gamma^{p^e}$, so the
inertia subgroup of $\fQ$ in $\Gamma^{p^e}$ is all of $\Gamma^{p^e}$; hence for
every $n\geq e$ the inertia subgroup of $\fq$ in $\Gal(K_n/K_e)$ is the whole
group, i.e.~$\fq$ is totally ramified in $K_n/K_e$.
If $\fq$ does not lie above any $\fp_i$, then $I(\fQ)=1$ and $\fq$ is unramified
in $K_n/K_e$ for every $n$.
This is precisely Definition \ref{Zp-ext-totally-ramified}.
\end{proof}

\subsection{Iwasawa's Theorem: totally ramified case}

Let $K$ be a number field, $p$ be a prime,
$K_\infty/K$ be a $\BZ_p$-extension which is totally ramified
(Definition \ref{Zp-ext-totally-ramified}).

\begin{lem}
\label{isom-of-totally-ramified}
\uses{Zp-ext-totally-ramified,Zp-ext-Ln,exists-totally-ramified}
\lean{IntermediateField.linearDisjoint_of_isUnramifiedEverywhere_of_inertiaSubgroup_eq_top',
MvZpExtension.exists_eventually_linearDisjoint_Ln_Kinf_of_ramified_of_finite}
Suppose $K_\infty/K$ is totally ramified
(Definition \ref{Zp-ext-totally-ramified}).
Then $K_{n+1}\cap L_n=K_n$. In particular,
the natural maps
$\Gal(K_{n+1}L_n/K_{n+1})\to\Gal(L_n/K_n)$ and
$\Gal(K_\infty L_n/K_\infty)\to\Gal(L_n/K_n)$
are isomorphisms.
\end{lem}

\begin{proof}
By Lemma \ref{exists-totally-ramified} at least one prime $\fp$ of $K$ ramifies
in $K_\infty/K$, and by assumption it is totally ramified, i.e.~for every
$m\geq 0$ the ramification index of $K_m/K$ at $\fp$ is $p^m=[K_m:K]$.
In particular, for $m\geq n$ there is a unique prime $\fp_n$ of $K_n$ above $\fp$,
and the ramification index of $K_m/K_n$ at $\fp_n$ is
$e(K_m/K_n)=p^{m-n}=[K_m:K_n]$.

Let $n\leq m$ and let $M$ be a field with $K_n\subset M\subset K_m$ and
$M\subset L_n$. Since $L_n/K_n$ is unramified, $M/K_n$ is unramified at $\fp_n$,
so $e(M/K_n)=1$ at $\fp_n$; by multiplicativity of ramification indices in
towers, $e(K_m/M)=p^{m-n}$ at the prime of $M$ below the chosen prime of $K_m$,
so $[K_m:M]\geq p^{m-n}=[K_m:K_n]$, forcing $M=K_n$.

Applying this with $M=K_m\cap L_n$ gives $K_m\cap L_n=K_n$ for all $m\geq n$;
in particular $K_{n+1}\cap L_n=K_n$, and, since
$K_\infty\cap L_n=\bigcup_{m\geq n}(K_m\cap L_n)$, also $K_\infty\cap L_n=K_n$.

Finally, $L_n/K_n$ is Galois, so for any extension $F/K_n$ inside a common
separable closure the natural map
$\Gal(FL_n/F)\to\Gal(L_n/L_n\cap F)$, $\sigma\mapsto\sigma|_{L_n}$, is an
isomorphism.
Taking $F=K_{n+1}$ and $F=K_\infty$ and using $K_{n+1}\cap L_n=K_\infty\cap L_n=K_n$
gives the two asserted isomorphisms.
\end{proof}

\begin{thm}[\cite{Was97}, Lemma 13.15, 13.17]
\label{Xn-isom-qout-of-totally-ramified}
\uses{isom-of-totally-ramified,p:unr-outside-p,exists-totally-ramified,
commutator-eq,p:nak,p:rank-growth,X-has-Gamma-action,Zp-ext-Ln,Zp-ext-L-inf,
Xn-isom-An}
\lean{MvZpExtension.xinfQuotientMulEquivOfPlace',
MvZpExtension.LinfFixedHH_eq_L0In,
MvZpExtension.YnIn_eq_topologicalClosure_closure_of_lifts,
MvZpExtension.moduleFinite_and_isTorsion_Xinf_Yn_of_generators}
Suppose $K_\infty/K$ is totally ramified
(Definition \ref{Zp-ext-totally-ramified}).
Then there exists a $\Lambda$-submodule $Y$ of $X_\infty$ of finite index,
such that for all $n\geq 0$,
$$
X_n\cong X_\infty/\nu_nY,
$$
where
$$
\nu_n:=\sum_{k=0}^{p^n-1}\gamma^k.
$$
In particular, $X_\infty$ is a finitely generated torsion $\Lambda$-module.
\end{thm}

\begin{proof}
The $Y\subset X_\infty$ is constructed as follows.
Let $\fp_1,\cdots,\fp_s$ be primes of $\CO_K$ which are (totally) ramified in $K_\infty$
(they are all above $\fp$ by Lemma \ref{p:unr-outside-p}).
For each $\fp_i$ fix a place of $L_\infty$ above it and
let $I_i\subset G$ be its inertia subgroup.
Since $L_\infty/K_\infty$ is unramified
and $K_\infty/K$ is totally ramified at $\fp_i$, we have $I_i\cap X_\infty=1$,
and $I_i\hookrightarrow G/X_\infty=\Gamma$ is surjective, hence bijective.
Therefore $G=I_iX_\infty=X_\infty I_i$.
For each $i$ let $\sigma_i\in I_i$ be the preimage of $\gamma\in\Gamma$,
then $\sigma_i$ is a topological generator of $I_i$.
For $i=2,\cdots,s$, let $a_i\in X_\infty$ be some element such that
$\sigma_i=a_i\sigma_1\in X_\infty I_1=G$.
Take $Y$ to be the closure of the $\Lambda$-submodule generated by
$a_2,\cdots,a_s$ and $\{(\gamma\bullet x)x^{-1}\mid x\in X_\infty\}$.

From now on we write $X:=X_\infty$ \emph{additively} as a $\Lambda$-module,
so that $(\gamma\bullet x)x^{-1}$ becomes $(\gamma-1)x=Tx$ and the subgroup
$\{(\gamma\bullet x)x^{-1}\mid x\in X\}$ becomes $TX$.
Thus $Y$ is the closed $\Lambda$-submodule of $X$ generated by $TX$ and
$a_2,\cdots,a_s$. Note that $\Lambda$ acts on $X/TX$ through $\Lambda/(T)=\BZ_p$
and that, $X$ being a pro-$p$ group, the closure of the subgroup generated by an
element $a\in X$ is $\BZ_pa$; hence $Y$ is also the closure of the
\emph{subgroup} generated by $TX$ and $a_2,\cdots,a_s$.

\emph{Step 1: $X_0\cong X/Y$.}
Let $H\subset G$ be the closed subgroup generated by the commutator subgroup
$G'$ and by the inertia subgroups of $G$ at all places of $L_\infty$.
A place of $L_\infty$ not lying above one of $\fp_1,\cdots,\fp_s$ is unramified
in $L_\infty/K$: it is unramified in $K_\infty/K$ by
Proposition \ref{p:unr-outside-p} and in $L_\infty/K_\infty$ because
$L_\infty/K_\infty$ is unramified (each $L_n/K_n$ is unramified, hence so is
$L_nK_\infty/K_\infty$), and ramification indices are multiplicative in towers.
The inertia subgroups at the places above $\fp_i$ are the $G$-conjugates of
$I_i$, and $H\supset G'$ is normal in $G$, so
$H=\overline{G'\langle I_1,\cdots,I_s\rangle}$.

We claim $L_0=L_\infty^H$.
The field $L_\infty^H$ is abelian over $K$ (because $G'\subset H$), unramified
over $K$ (because all inertia subgroups of $G$ lie in $H$), and
$\Gal(L_\infty^H/K)$ is a quotient of $G$, which is a pro-$p$ group ($G$ is an
extension of $\Gamma\cong\BZ_p$ by $X=\varprojlim_nX_n$, a projective limit of
finite abelian $p$-groups); hence $L_\infty^H\subset L_0$ by the maximality in
Definition \ref{Zp-ext-Ln}.
Conversely $L_0/K$ is abelian and unramified, so $G'\subset\Gal(L_\infty/L_0)$
and every inertia subgroup of $G$ is contained in $\Gal(L_\infty/L_0)$ (its image
in $\Gal(L_0/K)$ is an inertia subgroup of the unramified extension $L_0/K$,
hence trivial); therefore $H\subset\Gal(L_\infty/L_0)$ and
$L_0\subset L_\infty^H$. This proves the claim, and $X_0=\Gal(L_0/K)=G/H$.

By Lemma \ref{commutator-eq}, applied to the compact Hausdorff group $G$, the
closed abelian normal subgroup $X$ and the subgroup $I=I_1$ (which surjects onto
$\Gamma$), we have $G'=\{(\gamma\bullet x)x^{-1}\mid x\in X\}=TX$.
Since $\sigma_i=a_i\sigma_1$, the closed subgroup generated by $G'$ and
$I_1,\cdots,I_s$ equals the closed subgroup generated by $G'$, $\sigma_1$ and
$a_2,\cdots,a_s$, that is, $H=I_1Y$.
(Here $Y$ is normal in $G$, because $Y\supset G'$; and $I_1Y$ is compact, hence a
closed subgroup.)
Since $I_1\cap X=1$ and $Y\subset X$, we get $X\cap I_1Y=Y$: if $x=\tau y$ with
$x\in X$, $\tau\in I_1$, $y\in Y$, then $\tau=xy^{-1}\in X\cap I_1=1$.
Therefore
$$X_0=G/H=XI_1/YI_1\cong X/(X\cap YI_1)=X/Y .$$
In particular $X/Y\cong X_0$ is finite, i.e.~$Y$ has finite index in $X$.
We record for later use the identification
$$Y=X\cap I_1Y=X\cap H=X_\infty\cap\Gal(L_\infty/L_0)=\Gal(L_\infty/L_0K_\infty).$$

\emph{Step 2: $X_n\cong X/\nu_nY$ for all $n\geq 0$.}
Since $K_\infty/K$ is totally ramified at $\fp_i$, there is exactly one prime of
$K_n$ above $\fp_i$, and these $s$ primes are exactly the primes of $K_n$ which
ramify in $K_\infty/K_n$.
So Step 1 applies verbatim to the totally ramified $\BZ_p$-extension
$K_\infty/K_n$, whose Galois group $\Gamma^{p^n}$ has topological generator
$\gamma^{p^n}$, with the same places $\fP_i$, whose inertia subgroups in
$\Gal(L_\infty/K_n)$ are
$I_i\cap\Gal(L_\infty/K_n)=\overline{\langle\sigma_i^{p^n}\rangle}$.
It gives $X_n\cong X/Y_n$, where $Y_n$ is the closure of the subgroup of $X$
generated by $(\gamma^{p^n}-1)X$ and by $a_2^{(n)},\cdots,a_s^{(n)}$, the
elements defined by $\sigma_i^{p^n}=a_i^{(n)}\sigma_1^{p^n}$.

We compute $a_i^{(n)}$. From $\sigma_i=a_i\sigma_1$ one gets by induction on
$k\geq 1$
$$\sigma_i^k=\Big(\prod_{l=0}^{k-1}\sigma_1^la_i\sigma_1^{-l}\Big)\sigma_1^k
=\Big(\prod_{l=0}^{k-1}\gamma^l\bullet a_i\Big)\sigma_1^k,$$
so in additive notation $a_i^{(n)}=\nu_na_i$ with
$\nu_n=\sum_{l=0}^{p^n-1}\gamma^l$.
Moreover $(\gamma^{p^n}-1)X=\nu_n(\gamma-1)X=\nu_nTX$, and
$$\gamma\cdot(\nu_na_i)=\nu_na_i+\nu_n(\gamma-1)a_i
=\nu_na_i+(\gamma^{p^n}-1)a_i\in\nu_na_i+\nu_nTX,$$
so modulo $\nu_nTX$ the element $\nu_na_i$ is fixed by $\gamma$, and therefore
the closed $\Lambda$-submodule generated by $\nu_nTX$ and the $\nu_na_i$
coincides with the closure of the subgroup they generate.
Now $\nu_nY$ is compact, being the continuous image of the compact set $Y$,
hence closed, and it is the closed $\Lambda$-submodule generated by $\nu_nTX$ and
the $\nu_na_i$ (apply $\nu_n$ to the generators $TX$, $a_i$ of $Y$).
By what we just said this equals the closure of the subgroup generated by
$\nu_nTX$ and the $\nu_na_i$, which is $Y_n$.
Hence $Y_n=\nu_nY$, i.e.~$X_n\cong X/\nu_nY$.

\emph{Step 3: $X_\infty$ is a finitely generated torsion $\Lambda$-module.}
By Step 1, $X/Y$ is finite, and $Y/TX$ is topologically generated by the $s-1$
elements $a_2,\cdots,a_s$ as a $\BZ_p$-module.
Hence $X/TX$, an extension of the finite group $X/Y$ by $Y/TX$, is a finitely
generated $\BZ_p$-module, so by the pro-$p$ Nakayama lemma (Lemma \ref{p:nak})
$X$ is a finitely generated $\Lambda$-module.

Furthermore, $\nu_nY/\nu_nTX$ is a quotient of $Y/TX$, hence is generated by
$s-1$ elements as a $\BZ_p$-module, and $X/\nu_nY\cong X_n$ is finite
(Proposition \ref{Xn-isom-An}).
From $(\gamma^{p^n}-1)X=\nu_nTX$ we get the exact sequence
$$0\to\nu_nY/(\gamma^{p^n}-1)X\to X/(\gamma^{p^n}-1)X\to X/\nu_nY\to 0,$$
whence $\rank_{\BZ_p}\big(X/(\gamma^{p^n}-1)X\big)\leq s-1$ for all $n$.
By Lemma \ref{p:rank-growth} this rank is $rp^n+O(1)$ with
$r=\rank_\Lambda X$, so $r=0$ and $X$ is a torsion $\Lambda$-module.
\end{proof}

\subsection{Iwasawa's Theorem: general case}

Let $K$ be a number field, $p$ be a prime,
$K_\infty/K$ be a $\BZ_p$-extension.
Let $e\geq 0$ (Lemma \ref{exists-totally-ramified})
be such that the $\BZ_p$-extension $K_\infty/K_e$
is totally ramified (Definition \ref{Zp-ext-totally-ramified}).

\begin{thm}[\cite{Was97}, Lemma 13.18]
\label{Xn-isom-qout}
\uses{Xn-isom-qout-of-totally-ramified,exists-totally-ramified,Ln-K-Gal,
conjugate-action,weierstrass-division,Zp-ext-L-inf}
\lean{MvZpExtension.exists_eventual_Yn_generators,
MvZpExtension.exists_eventual_Yn_lambda_data_of_generators,
MvZpExtension.xinfInQuotientYnMulEquiv,
MvZpExtension.finite_quotient_YnIn,
MvZpExtension.moduleFinite_and_isTorsion_Xinf_Yn_of_generators}
There exists a $\Lambda$-submodule $Y$ of $X_\infty$ of finite index,
such that for all $n\geq e$,
$$
X_n\cong X_\infty/\nu_{n,e}Y,
$$
where
$$
\nu_{n,e}:=\sum_{k=0}^{p^{n-e}-1}\gamma^{kp^e}.
$$
In particular, $X_\infty$ is a finitely generated torsion $\Lambda$-module.
\end{thm}

\begin{proof}
By the choice of $e$ (Lemma \ref{exists-totally-ramified}) the $\BZ_p$-extension
$K_\infty/K_e$ is totally ramified.
Its Galois group is $\Gamma^{p^e}$ with topological generator
$\gamma_e:=\gamma^{p^e}$, its $m$-th layer is
$(K_e)_m=K_\infty^{(\Gamma^{p^e})^{p^m}}=K_{e+m}$, and the fields $L_{e+m}$,
$L_\infty$ and the group $X_\infty=\Gal(L_\infty/K_\infty)$ attached to it are
literally the same as those attached to $K_\infty/K$, since $L_n$ depends only on
$K_n$ (Definition \ref{Zp-ext-Ln}).

Applying Theorem \ref{Xn-isom-qout-of-totally-ramified} to $K_\infty/K_e$ we
obtain a submodule $Y$ of $X_\infty$, of finite index, over the Iwasawa algebra
$\Lambda_e:=\BZ_p[[\Gamma^{p^e}]]$, such that for all $m\geq 0$
$$X_{e+m}\cong X_\infty\Big/\Big(\sum_{k=0}^{p^m-1}\gamma_e^k\Big)Y .$$
Since $\sum_{k=0}^{p^m-1}\gamma_e^k=\sum_{k=0}^{p^m-1}\gamma^{kp^e}
=\nu_{e+m,e}$, writing $n=e+m$ this reads $X_n\cong X_\infty/\nu_{n,e}Y$ for all
$n\geq e$, as asserted.

\emph{$Y$ is a $\Lambda$-submodule.}
A priori $Y$ is only stable under $\Gamma^{p^e}$; we check that it is stable
under all of $\Gamma$.
By the construction in Step 1 of the proof of
Theorem \ref{Xn-isom-qout-of-totally-ramified} (applied to the base field
$K_e$), $Y=X_\infty\cap\Gal(L_\infty/L_e)=\Gal(L_\infty/L_eK_\infty)$.
Now $L_e/K$ is Galois by Lemma \ref{Ln-K-Gal}, hence $\Gal(L_\infty/L_e)$ is a
normal subgroup of $G=\Gal(L_\infty/K)$, and therefore so is the intersection
$Y=X_\infty\cap\Gal(L_\infty/L_e)$.
By Definition \ref{conjugate-action}, the action of $\Gamma=G/X_\infty$ on
$X_\infty$ is induced by conjugation in $G$, so the normal subgroup $Y$ of $G$ is
$\Gamma$-stable. Being moreover closed and a $\BZ_p$-submodule, $Y$ is a
$\Lambda$-submodule of $X_\infty$.

\emph{$X_\infty$ is finitely generated and torsion over $\Lambda$.}
Theorem \ref{Xn-isom-qout-of-totally-ramified} gives that $X_\infty$ is a
finitely generated torsion $\Lambda_e$-module.
Now $\Lambda$ is a free $\Lambda_e$-module of rank $p^e$: identifying
$\Lambda=\BZ_p[[T]]$ with $T=\gamma-1$, the subring $\Lambda_e$ is
$\BZ_p[[\omega_e]]$ with $\omega_e=\gamma^{p^e}-1$ a distinguished polynomial of
degree $p^e$, and Weierstrass division
(Proposition \ref{weierstrass-division}) shows that $1,T,\cdots,T^{p^e-1}$ is a
$\Lambda_e$-basis of $\Lambda$.
Hence a $\Lambda$-module is finitely generated over $\Lambda$ if and only if it
is finitely generated over $\Lambda_e$.
It is also torsion over $\Lambda$ if and only if it is torsion over $\Lambda_e$:
one direction is clear since $\Lambda_e\subset\Lambda$; conversely, if
$0\neq h\in\Lambda$ annihilates a module $M$, then, $\Lambda$ being a free
$\Lambda_e$-module of finite rank, $h$ satisfies a monic equation
$h^d+a_{d-1}h^{d-1}+\cdots+a_0=0$ with $a_i\in\Lambda_e$, which we may take of
minimal degree; then $a_0\neq 0$ (otherwise divide by $h$, which is legitimate as
$\Lambda$ is a domain) and $a_0=-h(h^{d-1}+\cdots+a_1)\in h\Lambda$ annihilates
$M$.
\end{proof}

\begin{remark}
The {\Lean} declarations listed formalize a variant of this theorem. Put
$Y_n:=\Gal(L_\infty/K_\infty L_n)\subset X_\infty$, so that
$X_\infty/Y_n\cong\Gal(K_\infty L_n/K_\infty)$. They prove that there are
$e'\geq 0$ and a $\Lambda$-submodule $Y=Y_{e'}$ of $X_\infty$, of finite index,
with $\nu_{n,e'}Y=Y_n$ for all $n\geq e'$. They also prove that $X_\infty$ is a
finitely generated torsion $\Lambda$-module. The identification of
$\Gal(K_\infty L_n/K_\infty)$ with $X_n$ (Lemma \ref{isom-of-totally-ramified})
is not formalized as an isomorphism. Only the equality of orders for all large
$n$ is proved, and that is all the proof of Theorem \ref{clgp-growth} needs.
\end{remark}

Apply Proposition \ref{coinvariant-growth-2} to above theorem,
we obtain Iwasawa's Theorem (Theorem \ref{clgp-growth}).

\begin{thm}[Iwasawa]\label{p:f-g-torsion2}
\uses{Zp-ext-L-eq-L,p:nak,p:rank-growth,p:unr-outside-p}
Suppose $K$ is any number field, and $K_\infty/K$ is any $\BZ_p$-extension.
Let $L_\infty$ be the maximal unramified abelian pro-$p$ extension of $K_\infty$,
let $X_\infty:=\Gal(L_\infty/K_\infty)$ which is a $\Lambda$-module,
where $\Lambda:=\BZ_p[[\Gamma]]$, isomorphic to $\BZ_p[[T]]$
by choosing a topological generator $\gamma$ of $\Gamma$,
and maps $T$ to $\gamma-1$. Then $X_\infty$ is a finitely generated torsion
$\Lambda$-module.
\end{thm}

\begin{proof}
Consider $\Gal(K_\infty/K_n)=\Gamma^{p^n}$ with topological generator
$\gamma^{p^n}$. Let $E_n$ be the maximal abelian extension of $K_n$
contained in $L_\infty$, so that $\Gal(L_\infty/E_n)=\Gal(L_\infty/K_n)'
=(\gamma^{p^n}-1)X_\infty$. Note that $X_\infty/TX_\infty\cong\Gal(E_0/K_\infty)$
is a finitely generated $\BZ_p$-module, so by Nakayama lemma
(Lemma \ref{p:nak}) we know that $X_\infty$ is finitely generated $\Lambda$-module.

Recall that if $r=\rank_\Lambda X_\infty$, then
$\rank_{\BZ_p}\left(X_\infty/(\gamma^{p^n}-1)X_\infty\right)=rp^n+O(1)$
as $n\to\infty$ (Lemma \ref{p:rank-growth}). So in order to prove
$X_\infty$ is torsion (i.e. $r=0$), we only need to prove
$\rank_{\BZ_p}\left(X_\infty/(\gamma^{p^n}-1)X_\infty\right)$ is bounded.

Let $\fp_1,\cdots,\fp_t$ be the primes of $K$ which are ramified in $K_\infty/K$.
Then $t$ is finite (by Proposition \ref{p:unr-outside-p}),
and number of primes of $K_\infty$ lying over $\fp_1,\cdots,\fp_t$
is also finite, because for each $i$, the index $[\Gamma:D_{\fp_i}]$
is finite. So let $s_n$ be the number of primes of $K_n$ which are
ramified in $K_\infty/K_n$, then $s_n$ is bounded.

Consider $E_n/K_n$. Recall that $L_n$ is the $p$-Hilbert class field
of $K_n$. Then $L_n\subset L_\infty$, $K_\infty\subset L_\infty$,
so $L_nK_\infty\subset E_n$. Let $I_1,\cdots,I_{s_n}$ be the inertia
subgroups of $\Gal(E_n/K_n)$ for the ramified primes.
For $1\leq j\leq s_n$, $I_j\cap\Gal(E_n/K_\infty)=\{1\}$,
because $E_n/K_\infty$ is unramified. Therefore $I_j$ maps injectively
to a closed subgroup of $\Gamma^{p^n}$
via the map $\Gal(E_n/K_n)\to\Gal(K_\infty/K_n)$,
in particular, $I_j$ is isomorphic to $\BZ_p$.

Now we come to the key point. Let $I:=I_1\cdots I_{s_n}\subset\Gal(E_n/K_n)$,

because $\Gal(K_\infty/K_n)=\Gamma^{p^n}$ is of $\BZ_p$-rank $1$.
Note that $\Gal(E_n/K_\infty)\cong X_\infty/(\gamma^{p^n}-1)X_\infty$,
so $\rank_{\BZ_p}\left(X_\infty/(\gamma^{p^n}-1)X_\infty\right)$ is bounded.
\end{proof}
